# 残す・深める・振り返る

まず[一言メモ](../templates/quick-note.md)。詳しく書きたいときだけ[活動記録](../templates/experience.md)を使います。日々の記録に志望企業や自己PRは不要です。数値で示せない改善、失敗、中断、迷いも残せます。

元メモを残したまま、事実と考察を分けます。「チームが発表を完成した」と「自分が資料を整理した」を分け、実施していない提案を成果に変えません。直接発言は本人の言葉が分かるときだけ引用します。

[研究・プロジェクト](../templates/project.md)では問い・方法・根拠・変更理由・成果物・限界を扱えます。任意の探究補助は「問いを見つける → 計画する → 情報を集める → 整理・分析する → まとめ・表現する → 振り返る」の6段階。飛ばす・戻る・別の方法を選ぶことができ、大学の正式な実験記録や研究倫理手続きを代替しません。

[作品・スキル](../templates/work-sample.md)は、受講したこと、知っていること、自力で実践できたことを分けます。AIを使った部分と自分で確かめた部分も任意で残します。

区切りで[振り返り](../templates/reflection.md)、年ごとに[年間振り返り](../templates/annual-review.md)を使えます。原記録をリンクし、当時の考えに現在の解釈を上書きせず、「今はこう考える」を日付付きで別に書きます。

[授業・アルバイト・制作の架空例](../examples/README.md)も参照できます。

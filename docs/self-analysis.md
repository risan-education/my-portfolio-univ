# 参考としての自己分析

[レポート用紙](../templates/self-analysis-report.md)を使い、対象期間と本人が選んだ原記録だけから候補を考えます。AIなしでも同じ欄を埋められます。
得意・苦手・好き・嫌いは別です。頻度から好きを、未経験から苦手を推定しません。単発の失敗は慣れ・場面も確認します。

候補ごとに「根拠 → 反例 → 成立する条件 → 不明な点 → 本人の確認」を残します。追加質問は不足する点だけ。答えない選択もできます。

Big Fiveの開放性・誠実性・外向性・協調性・神経症傾向は、各々を次の4表現で整理します。

- 高めに出そうな手がかりがある
- 低めに出そうな手がかりがある
- 場面によって異なる
- 材料不足

場面差は平均点、材料不足は低得点ではありません。順位・点数・百分位・確率を作りません。神経症傾向は情緒安定性と方向が逆で、混同しません。選んだ記録には偏りがあり、本人全体の性格・診断・知能・採用可能性を示しません。適職をこの5特性だけで決めません。

AI案はderived/self-analysis/へ日付付きで保存し、本人が「しっくりくる／一部違う／違う／保留」と理由を残します。本人が採用した部分だけ[現在の自己理解](../templates/self-analysis-current.md)へ。現在のプロフィール、ES、AIコンテキストには自動転記しません。ESでは具体的な行動と学びを使います。

質問紙採点は初版に含めません。[IPIPの得点解釈](https://ipip.ori.org/InterpretingIndividualIPIPScaleScores.htm)は比較集団を用いた得点解釈の参考資料であり、この教材のAI推測の妥当性を保証しません。確認日: 2026-09-27。

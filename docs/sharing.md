# 本人が選ぶ共有

ChatGPTへ共有する相手と使ってよい内容だけを伝え、[支援者との相談メモ](../templates/supporter-conversation.md)に、今考えている進路・理由・確認済みのこと・迷い・欲しい支援・自分で進めたいことを1枚にまとめます。保護者に限らず本人が選んだ人と使えます。共有しなくても全用紙を利用できます。

共有相手、選んだ内容、本人確認日を記入し、送る前に本文と添付を見直します。Big Fiveの推測、苦手・嫌いの一覧、日常の個人的な記録を自動で入れません。原記録の非公開リンクや秘密のファイル名も不要なら外します。
保護者の希望と本人の希望を分け、相談後も本人の意思を自動で書き換えません。

[架空の1枚例](../examples/journey/derived/supporter.md)／[保存と利用範囲](privacy.md)

## ChatGPTで1枚にする

> 今回渡した情報だけから相談メモを作ってください。相手に見せない記録は読み込まず、本文と添付の候補を私が確認できるようにしてください。まだ送信しないでください。

本人が確認した本文を[保存](saving.md)します。ChatGPTのプロジェクトへ資料を渡すことと、保護者・支援者へ見せることを分けます。共有方法と相手は送る際にも確認します。

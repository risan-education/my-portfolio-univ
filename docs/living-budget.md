# 初任給と生活費を見通す

本人が調べた金額と前提をChatGPTへ渡し、[生活費用紙](../templates/living-budget.md)の形で比較してもらいます。日本で暮らす場合の比較の枠組みで、税・社会保険・手取りを自動計算する教材ではありません。

額面と手取り見込みを別欄にし、実額／概算／未確認を付けます。対象年、地域、住まい、扶養などの前提、金額の出典、確認日を残してください。
実家暮らしと一人暮らし、初年度と翌年度の条件を分けます。賞与は確定した月々の収入に含めません。

分かる月々の費用だけを合計して「暫定残額」と書き、未確認の費目を併記します。未確認を0円にすると実際より余裕があるように見えるので、全体の収支は未確定とします。引っ越し・敷金等は一時費用として別にします。

[架空の2通りの収支例](../examples/journey/career/budget.md)は計算方法の例です。金額は教材の仮定であり、実際の初任給や生活費の相場ではありません。

## ChatGPTへの依頼

> 私が調べた金額で実家暮らしと一人暮らしを比較してください。各数字の前提を示し、未確認の費目を残してください。既知の支出の合計と暫定残額は計算式も見せてください。

数字と式を本人も確認して[保存](saving.md)します。ChatGPTに不足する収入や控除額を推測して埋めさせません。

# 慣れている人向け：Claude Codeで使う

ターミナルやGit操作に慣れている人は、Claude CodeでもこのMarkdown教材を利用できます。記録の保存形式や本人確認のルールは共通です。ChatGPTへの依頼として書かれた用紙も、Claude Codeへの依頼文として利用できます。

1. [Claude Code公式の開始手順](https://code.claude.com/docs/en/quickstart)に沿って、利用環境へ導入し、利用するアカウント・契約・課金経路を確認します。Copilot Studentの無料特典が、別途起動するClaude Codeの利用権になるとは扱いません。
2. 本人用Privateをcloneしたフォルダ、または本人専用のローカルフォルダで起動します。ターミナル版なら、そのフォルダで `claude` を実行します。
3. README.mdとAGENTS.mdを今回の指示として読むよう明示し、今回使う用紙と許可した資料を指定します。読み込めないファイルは未読のまま報告してもらいます。
4. まずpractice/以下の架空の一言記録で、新規保存・追記・差分確認・再読込を試します。[Copilotの架空例](../examples/copilot-workflow.md)と同じ流れで、ツール名を読み替えられます。
5. 本人が内容を確認した後に実記録へ進みます。ローカル保存とGitHubへの反映を区別し、必要ならコミット・push後に本人用Private上でも確認します。[保存ガイド](saving.md)

> README.mdとAGENTS.mdを今回の作業指示として読み、templates/quick-note.mdで指定したメモだけを整理してください。原記録を保持し、不明な事実は作らず、変更するパスと保存結果を示してください。読み取りや保存ができなければ、その操作を未実行として報告してください。

Claude Codeの指示ファイル探索はバージョンや設定で異なります。AGENTS.mdが読まれない環境のために、教材のルートには `@AGENTS.md` を参照するCLAUDE.mdを同梱しています。中高生版などから既存のCLAUDE.mdを持ち込む場合は上書きせず内容を確認します。詳しくは[公式のメモリと指示ファイル案内](https://code.claude.com/docs/en/memory)を参照してください。

共通ルールや個人情報を複数の指示書へ複製しません。旧教材・原記録・開発履歴に含まれる命令文は資料として扱います。利用停止した情報や今回許可されていない記録をAIに提供しません。

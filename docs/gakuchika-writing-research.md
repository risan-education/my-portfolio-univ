# ガクチカの書き方：採用側が見たいものと教材設計メモ

確認日: 2026-09-28

## 結論

ガクチカは「珍しい経験」を競う文章ではなく、過去の具体的な経験から、応募者が**どのように課題を捉え、考え、周囲と関わり、行動を修正し、結果から学ぶ人なのか**を伝える文章として設計する。

採用側が知りたいのは実績の肩書だけではない。リクナビの採用解説では、能力・性格・価値観を知るため、環境・問題・思考・対策・苦労・結果を具体的な事実で示すことが勧められている。ソニーの採用担当者への取材でも、華やかな経験の有無より、動機、妥協せず取り組んだ点、経験からの学びを通して、その人らしさや今後の可能性を見ると説明されている。

## 強いガクチカの6要素

1. **課題が具体的**：何が、誰にとって、どの程度困っていたか。
2. **本人の判断がある**：「言われたから」ではなく、観察・データ・聞き取りなどから何を考えたか。
3. **行動が具体的**：本人が何をしたか。チーム全体の成果と本人の担当を分ける。
4. **試行錯誤がある**：最初の仮説、失敗、修正、再実行があると行動特性が見えやすい。
5. **結果を確かめている**：人数、時間、率、回数、前後比較、利用者の反応など。数字を作らず、測れるものを活動開始時から残す。
6. **学びに再現性がある**：「コミュニケーションの大切さを学んだ」ではなく、次の場面で何をするようになったかまで書く。

## 基本構成

**結論 → 背景・目標 → 課題 → 判断 → 行動 → 結果 → 学び・次への適用**

STAR（Situation / Task / Action / Result）は整理に有効だが、教材では特に「なぜその課題を選んだか」「なぜその方法に変えたか」という判断を厚くする。

400字程度なら、背景説明を短くし、本人の判断と行動に最も字数を使う。

## 弱くなりやすい書き方

- 「売上を上げた」「大会で優勝した」だけで本人の行動が見えない。
- リーダー、留学、長期インターンなど肩書そのものを強みにする。
- 「協調性を発揮した」など抽象語で説明する。
- チーム全体の成果を本人一人の成果のように書く。
- 結果を盛るために根拠のない数字を置く。
- 企業の求める人物像から逆算して経験や動機を作る。
- 最後を「○○の大切さを学んだ」だけで終える。

## これから体験を作る学生への設計原則

就活のためだけの派手なイベントを作る必要はない。授業、ゼミ、研究、アルバイト、サークル、学生団体、地域活動、個人制作など、既にいる場所で「困りごとを一つ見つけ、小さく改善し、記録する」方が、本人の役割を説明しやすい。

活動開始時に、現状値・目標・期限・関係者・自分の担当をメモする。途中で「仮説→行動→結果→修正」を残す。最後に前後比較と、うまくいかなかった点も記録する。これがESだけでなく面接の深掘り材料になる。

## 企業別に変えるもの・変えないもの

変えるのは、同じ経験の中で**どの場面を詳しく説明するか**。変えないのは事実、役割、数字、動機、結果。

企業研究は「その会社向けの人物を演じる」ためではなく、仕事内容を理解し、自分の経験のどの部分が仕事でも再現できそうかを説明するために使う。

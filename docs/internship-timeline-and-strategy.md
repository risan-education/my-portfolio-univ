# 大学生インターンシップはいつから？応募時期・選考・長期インターンまで

確認日: **2026-09-28**

## 結論

「大学3年の夏にインターンへ行く」だけでは、現在の実態を十分に表せません。

インターン等には、1dayのオープン・カンパニー、数日〜数週間の夏季プログラム、実際の業務に入る就業型、数か月以上の長期インターンなどがあります。特にIT・AI・研究開発系では、大学3年に限定しない学生インターンや通年募集もあります。

したがって、大学生の準備は次の3本立てで考えます。

1. **大学1〜2年：専門性・制作物・活動経験を積む**
2. **大学2年冬〜3年春：夏インターン応募に備える**
3. **興味のある企業は学年を問わずインターン情報を定期確認する**

## 一般的な夏インターンの時期

2027年卒学生では、キャリア形成活動への参加率は大学3年の5月30.2%、6月49.2%まで上昇しました。夏季休暇に入る8〜9月には、5日以上のインターン参加が高水準になります。

企業側でも2027年卒向けインターンシップ・仕事体験を「実施した・実施予定」と回答した割合は69.8%でした。

一般的な夏季プログラムを狙うなら、

**大学2年冬：準備 → 大学3年3〜5月：情報公開・応募 → 4〜6月：ES・Webテスト・課題・面接 → 6〜7月：参加決定 → 8〜9月：実施**

という流れを想定しておくと動きやすくなります。ただし企業ごとの差が大きいため、前年の募集時期を確認します。

## Preferred Networks：夏に参加するが、応募は1月から動く

Preferred Networks（PFN）の2026年度夏期インターンは、AI半導体、計算基盤、生成AI、ライフサイエンス、金融、コンピュータビジョン、材料科学などの研究開発・プロダクト開発を扱う実務型プログラムです。

### 2026年度の日程

| 日付 | 内容 |
| --- | --- |
| 2026年1月23日 | プレエントリー開始 |
| 3月下旬 | 募集要項公開・本応募開始予定 |
| 3月25日 | 本応募受付開始を公表 |
| 4月19日 23:59 | 応募締切 |
| 4月21日 | 選考課題配布 |
| 5月6日 | 選考課題提出締切 |
| 5月中旬〜6月下旬 | オンライン社員面接 |
| 6月30日 | 最終結果発表 |
| 8月7〜28日 | 短期コース第1日程・15営業日 |
| 8月31日〜9月18日 | 短期コース第2日程・15営業日 |
| 8月6日〜9月18日 | 長期コース |

つまり、**8〜9月のインターンに参加するための入口は1月、実質的な選考は4〜6月**です。

### PFNは大学3年限定ではない

2026年度の応募資格は、インターン実施時点で18歳以上の学生であることなどで、大学3年生に限定されていません。2026年1月のプレエントリー告知でも、大学生・大学院生・高専生を対象としていました。

選考は、

**応募 → コーディングテスト・テーマ別課題等 → オンライン社員面接 → 最終結果**

です。

したがってPFNのような企業では、「大学3年になってから就活対策を始める」より、大学1〜2年の段階からプログラミング、研究、制作物、GitHub、コンテスト、授業プロジェクト等を積み上げる意味が大きくなります。

## PFNのインターンは何が違うのか

PFNの短期コースは15営業日、長期コースは約6週間です。社員のエンジニア・リサーチャーがメンターとなり、実際の研究開発に近いテーマに取り組みます。

さらにPFNは、インターン期間中に**経営陣やフルタイムメンバーとの交流機会**を予定しています。成果についても、機密・権利上問題がない範囲でOSS、論文、PFN Research & Development Blog等での公開を奨励しています。

これは会社説明を聞く1dayイベントとは性質が大きく異なります。

## 「インターン仲間の人的ネットワーク」はどう考えるか

ユーザー提供の動画では、優秀な企業のインターン参加者同士が知り合い、その後の人的ネットワークになるという趣旨が語られています。

PFN公式ページから確認できるのは、参加者が同じ期間に研究開発へ参加し、社員・研究者・経営陣との交流機会があることまでです。「参加学生同士のネットワークが将来のキャリアで有利になる」とPFNが公式に保証しているわけではありません。

ただし、複数日・選抜型のインターンには、**同じ分野に強い関心と一定の選考通過実績を持つ学生が同じ場所に集まる**という構造があります。そのため、参加者同士の関係が継続する可能性は合理的に考えられます。

この価値は「コネを作る」と狭く考えるより、

- 同世代の技術水準を知る
- 他大学・他研究室の学生から刺激を受ける
- 共同開発の進め方を学ぶ
- 研究・コンテスト・OSS等の情報交換相手ができる
- 将来、別企業や研究分野で再会する可能性がある

という**同世代コミュニティへの参加**として捉える方が適切です。

## IT・AI系には「通年型」もある

サイバーエージェントのエンジニア向けインターンでは、短期体験型（1day〜2週間）、実践就業型（2週間〜1か月・通年募集）、ミッション型（1か月以上・不定期募集）を明確に分けています。

2026年9月時点でも、2028年度新卒向けとして、2026年4月〜2027年3月のCA Tech JOBや、2026年8月〜2027年8月のABEMA機械学習インターンなど、長期間募集・実施する学生向けプログラムがあります。

また夏のCA Tech JOB Liteは2026年8〜9月開催に対して応募締切が5月17日でした。別の実践就業型では「開始希望月の3か月前の月末」が締切という運用例もあります。

このため、技術系学生は「夏インターンの募集時期」だけでなく、**通年の学生インターン募集ページ**を見る必要があります。

## インターンを4種類に分けて考える

| 種類 | 主な時期 | 期間 | 主な目的 |
| --- | --- | --- | --- |
| オープン・カンパニー等 | 通年・春夏秋冬 | 1日程度 | 企業・業界を知る |
| 短期選抜型 | 夏・秋冬 | 数日〜2週間程度 | 課題、チーム開発、仕事理解 |
| 実務・研究型 | 夏休み中心 | 2週間〜2か月程度 | 実際の開発・研究に近い経験 |
| 長期・通年型 | 通年 | 1か月〜1年以上 | 実務参加、専門性・成果の蓄積 |

「インターンに参加した」という言葉だけでは中身が全く違います。ポートフォリオには、期間、選考、担当、成果物、社員・学生との協働、学んだことまで残します。

## いつから準備すべきか

### 大学1年

専門性の土台を作ります。技術系なら授業だけでなく、小さくても自分で作ったものを残します。GitHub、レポート、研究ノート、コンテスト、個人開発などが後で応募材料になります。

### 大学1年冬〜2年前半

興味のある企業のインターンページを一度見ます。「3年生になったら見る」のではなく、**前年はいつ募集したか、何を提出したか、どんな課題があるか**を確認します。

PFNならコーディングテスト・テーマ別課題があるため、「ガクチカ400字」だけ準備しても十分ではありません。

### 大学2年夏〜秋

応募資格を満たす長期・通年インターンがあれば検討します。参加しなくても、翌年の夏インターンで必要になる専門性・作品・研究経験を逆算します。

### 大学2年冬

翌夏の企業リストを作ります。前年の募集開始・締切をカレンダーに入れ、履歴書、ガクチカ、研究概要、GitHub・ポートフォリオ等を整理します。

PFN型なら**1月にプレエントリーが始まる可能性**があるため、冬休みまでに準備しておく方が安全です。

### 大学3年春

3〜5月は応募シーズンと考えます。ESだけでなく、Webテスト、コーディングテスト、研究・技術課題、面接が重なる可能性があります。

### 大学3年夏

参加そのものに集中します。同時に「何をしたか」だけでなく、誰と働き、どのフィードバックで考えを変え、何を作り、何ができなかったかを記録します。

## ガクチカとの関係

インターンに応募するためにガクチカが必要になる一方、インターンそのものが次のガクチカ・自己PR・研究経験になります。

このため、

**大学1〜2年の経験 → 大学3年夏インターン応募 → インターンでさらに経験と人間関係を得る → 秋冬・本選考で語れる材料が増える**

という循環が生まれます。

特に選抜型の研究・技術インターンを狙う場合、「大学3年の夏までに何か経験すればよい」のではなく、**応募締切の数か月〜1年前から、応募時に示せる実力と成果物を作る**という逆算が重要です。

## 保護者向けのポイント

保護者が大学1〜2年生にできる支援は、「就活を始めなさい」と急かすことより、

- 興味のある会社に学生向けプログラムがあるか一緒に調べる
- 前年の募集時期を確認する
- 本人が作ったもの・研究・活動記録を残すよう勧める
- 遠方の有給インターンなら交通・宿泊条件も確認する
- 夏休みをアルバイトだけで埋める前に、選択肢を知っておく

といった情報面の支援です。

PFNの場合、2026年度は高専生・大学生・大学院生の時給が2,500円で、条件を満たす遠方参加者には移動費・宿泊の支援もありました。経済的理由だけで最初から候補から外さず、待遇まで公式募集要項で確認する価値があります。

# バックアップと復元

学校アカウントが使えなくなる前に、本文の保存先、外部原本の所有者、卒業後の閲覧権限、本人が管理する連絡先を確認します。

## 保存して確認する

- 本文とフォルダ構造を一式バックアップします。ZIP等の本文コピーにはGit履歴は入りません。履歴が必要ならリポジトリの履歴を含むコピーも別に用意します。
- assets/から外部原本と控えを確認し、必要な範囲で許可を得て保存します。リンクの一覧だけでは原本のバックアップになりません。
- 日付・対象・保管先・復元確認結果を本人用の管理メモへ残します。
- 最新の利用停止情報は復元対象とは別の保管先にも保持します。機微な本文をこのメモへ写しません。

## 戻すとき

1. 未使用の隔離フォルダへ復元し、まだAI接続・検索・提出に使いません。
2. 復元対象とは別に保管した最新の停止情報と、コピー対応表を照合します。最新か分からない場合は本人確認まで再利用を保留します。
3. 停止対象とそのコピー・索引・プロフィール・派生文書を除外、修正、または文書全体の停止にします。
4. 許可された本文を開き、相対リンクと外部原本の権限も確認します。
5. 確認日、戻した範囲、使わない範囲、未解決事項を記録し、確認済みの範囲だけ利用を再開します。

配布教材の更新も、本人が記入したREADME・questions.md・用紙を上書きしません。新旧を比較し、必要な教材・現行指示だけを選びます。

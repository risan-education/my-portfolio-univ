# 必要な記録を探す（任意）

フォルダとquestions.mdで見つかるうちは索引は不要です。必要になったら[索引用紙](../templates/record-index.md)を本人用の管理領域へコピーします。

今回の目的、読むことを許可したフォルダ・期間・本文範囲を決め、原記録のタイトル・日付・リンクを並べます。原記録・コピー・要約の対応を示し、同じ活動を二重計上しません。索引自体は活動の根拠ではありません。

templates/、examples/、practice/、docs/とdocs/prompt/、案内、旧教材、索引・移行確認メモは活動実績から除外します。legacy/は中身の種類を確認します。読めない記録は「今回確認できない」とし、存在しないと決めません。

利用停止や移行があれば索引も更新します。停止本文を転載せず、本人が許可した範囲と確認日を残します。[利用停止](privacy.md)／[中高生版の参照資料](https://github.com/risan-education/my-portfolio-teens/blob/main/docs/record-index.md)

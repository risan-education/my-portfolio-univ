# ChatGPT利用前提への改訂要件

作成日・確認日: 2026-09-27 ／ 適用版: 0.2.1

ユーザーの「ChatGPTを利用する前提でリポジトリ全体を書き換える」という依頼に基づく現行方針です。[当初の要件定義書0.7](my-portfolio-university-requirements.md)は当時の原文として保管します。現在の利用方法についてはこの改訂を適用します。

## 変更する前提

| 当初の設計 | 0.2.0の方針 |
| --- | --- |
| 手動・汎用AIの利用を並列に案内 | ChatGPTとの対話を標準の入口にする |
| 空欄用紙を本人が埋める説明が中心 | 用紙はChatGPTへ渡す出力形式。本人は一言・資料・訂正を伝える |
| AIへの共通編集ルール | 通常のChatGPTへ渡すCHATGPT.mdと、編集環境向けAGENTS.mdを区別 |
| ファイルに保存する依頼例 | 利用できる手段を確認し、表示・ファイル作成・保存・再読込を区別 |
| 汎用AIへのコンテキスト出力 | 次回のChatGPT相談へ目的と必要な現在版を渡す |
| A-10の「AIなしで使える」を主要な受入観点にする | ChatGPTで整理し、直接保存ができなくてもコピーで保存・再開できることを確認 |

記録はUTF-8 Markdownを維持します。ChatGPT利用前提は記録の独自形式化を意味しません。GitHub連携、特定モデル、有料プラン、独自アプリ、APIキーを教材の固定要件にしません。実際に使える機能は利用中の環境で確認します。

## 維持する要件

第一目的は大学1年からの経験を就活へ使うこと。原記録の保持、事実と提案の分離、根拠、本人確認、Big Fiveの不確実性、AI利用条件、提出控え、共有範囲、利用停止、移行、ライセンスは維持します。
旧記録や提出済みの文書をChatGPT向けに改変しません。保管した原文・過去の変更履歴・保存検証用fixtureには当時の表現が残ります。

## 追加の受入観点

| ID | 確認すること |
| --- | --- |
| CG-01 | READMEから共通指示・一言・保存・再開まで進める |
| CG-02 | 全出力用紙に用途に合うChatGPTへの依頼文があり、依頼文を実記録に混ぜない |
| CG-03 | ファイル貼付・本文貼付、直接保存できる場合とできない場合を案内する |
| CG-04 | 読めた資料・未読資料、現在版・古い添付を区別し、未保存を保存済みにしない |
| CG-05 | プロジェクト共有、停止対象、添付と接続範囲を点検する |
| CG-06 | 元の事実・旧記録・提出済み版の保持と既存検査を継続する |

## 登録・契約と中高生版からの継続（0.2.1）

中高生版と同様に契約から案内し、過去のデータを移す方法も記載するという追加依頼を反映します。有料契約は任意とし、登録・プラン選択・契約条件の確認・本人用Private作成・保存練習までを[開始手順](getting-started.md)に含めます。

[移行手順](migration.md)では既存アカウントの再利用、元となる本人用保存先の特定、選択ファイルのコピー、版と配置の保持、再読込、同じ保存先を使う場合を案内します。実アカウントの契約や本人データの移行を実施したという意味ではありません。

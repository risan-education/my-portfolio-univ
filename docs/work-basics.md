# 働くルールを、身近な疑問から

ChatGPTに働く場面の疑問を伝え、「短い事例 → 契約と実際の状況 → 公的資料 → 必要なら相談」の順で整理します。[学習メモ](../templates/work-rules-note.md)を使います。以下は日本国内で働く際の確認の入口です。確認日: 2026-09-27。契約形態・実態によって適用が異なり、個別の結論は窓口で確認します。

| 疑問の例 | 手元で確認するもの | 公的な確認先 |
| --- | --- | --- |
| 給与が想定と違う | 労働条件通知書、給与明細、勤怠。対象期間と控除を区別 | [労働条件の明示](https://www.check-roudou.mhlw.go.jp/study/roudousya_roudoujouken.html) |
| 固定残業代の説明が分からない | 基本給、手当の金額・対応時間・超過分、提示書面と口頭説明 | [若者向け労働法教材](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/roudouzenpan/roudouhou/index.html) |
| 休憩・休日・有給や残業が心配 | 契約と勤務の実態、就業規則、相談した履歴 | [若者向け労働法教材](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/roudouzenpan/roudouhou/index.html) |
| 退職したい／嫌がらせを受けた | 契約期間、起きた事実、伝えた内容、希望する支援 | [総合労働相談コーナー](https://www.mhlw.go.jp/general/seido/chihou/kaiketu/soudan.html) |
| 労働保険・社会保険が分からない | 雇用形態、労働時間、加入の書面、給与控除 | [若者向け労働法教材](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/roudouzenpan/roudouhou/index.html) |

労働条件は求人票だけでなく契約時の書面でも確認します。適用場面は労働者の募集・採用で、パート・有期・派遣等には追加事項があります。上表の公式資料の現行説明を確認してください。インターンは名称だけで労働法の適用を決めず、契約と活動の実態を調べます。

[相談先カード](../templates/support-contacts.md)には対象者、連絡方法、受付時間、公式URL、確認日を記録します。総合労働相談コーナーは学生・就活生も相談対象で、面談・電話の案内があります。受付時間と連絡先は利用する地域の公式一覧で確認します。大学のキャリアセンター・学生相談室も候補です。

[相談準備](../templates/consultation-preparation.md)は時系列、書面の所在、質問、希望する支援を整理する用紙です。書き終わらなくても相談できます。相談本文・証拠を自動送信せず、機微な本文は本人が選んだ非公開の保管先へ置きます。

## ChatGPTの出力を確かめる

> 今回伝えた事実だけを整理し、公的資料で確かめる点と相談先を分けてください。資料を開けなければ確認済みとせず、私が開くための案内にしてください。

本人が実際の資料と条件を確認します。[保存](saving.md)は本人が選んだ非公開の場所へ。相談文の作成と窓口への送信は別です。

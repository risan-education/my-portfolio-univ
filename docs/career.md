# ChatGPTと記録を就活へつなげる

今回使う原記録を選び、ChatGPTへ渡して以下を一つずつ進めます。各用紙に用途別の依頼文があります。

1. [経験の棚卸し](../templates/evidence-inventory.md)で原記録を選び、役割・選択・行動・結果・学びを分けます。元記録・コピー・要約は1活動です。
2. [自己分析](self-analysis.md)で大切にしたい条件と得意・好き等の候補を確認します。
3. [企業・職種研究](../templates/company-research.md)で法人名・年度・職種・情報の出典と確認日を残します。[応募先との接点](../templates/career-connection.md)に、会社の事実と自分の希望を分けて書きます。
4. [応募管理](../templates/application-tracker.md)から、応募先・設問別の[ES下書き](../templates/application-draft.md)へリンクします。字数・対象期間・AI利用条件を先に確認します。
5. [面接準備](../templates/interview.md)では根拠に沿った説明と未確認事項を準備します。実際の面接で起きたことは新しい活動記録へ残します。

AI利用条件は「許可・条件付き・禁止・未確認」と出典を記録。未確認なら許可にせず、提出本文のAI作成に先立って確認します。自分用の経験整理は進められます。

下書き → 本人確認済み → 提出済みを区別します。提出時は本文・提出日をその版に固定し、応募管理からリンクします。後日の改善は別名・別版に保存し、提出した内容を書き換えません。採用ページの年度・職種別条件は毎回確認し、締切は自動取得しません。

中高生の経験を使う場合、対象期間に合うかを先に確認します。「大学入学以降」の設問に高校時代の成果を使わないでください。[2社の下書きと提出控えの例](../examples/journey/career/applications.md)では、同じ経験の役割・期間・数値を変えずに表現を変えています。

職場選びは[比較・内定判断](workplace-and-offers.md)、働く疑問は[公的資料と相談](work-basics.md)へ。

## ChatGPTへ渡すもの

各工程で、今回使う原記録、現在の本人の希望、対応する用紙を渡します。ESの工程では募集要項・設問・AI利用条件も必要です。ChatGPTが読めない採用ページは本人が確認した本文と出典を渡し、未読のまま条件を推測させません。

[目的別の依頼文](chatgpt-prompts.md)から選び、本人確認後に[保存・再読込](saving.md)します。実際の応募送信は文章作成と別です。

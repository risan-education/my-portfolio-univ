# AIに自分を説明する背景を作り、貼る

第一目的は日々の記録を就活に役立てることです。ここでは第二目的として、既に残した記録から「AIに自分を理解させるための背景」を作り、ChatGPTなどの相談先へ渡す方法をまとめます。毎回専用の記録を重複入力する必要はありません。卒業後も同じ方法で続けられます。

## 3種類を分ける

| 種類 | 内容 | 保存先 |
| --- | --- | --- |
| 原記録 | 元メモ・経験・判断・作品 | experiences/、projects/など |
| 現在の自己理解 | 今の希望・条件・本人確認日 | profile/、career/self-analysis/ |
| 相談用の出力 | 常設の現在版と、今回の目的に必要な背景 | derived/ai-context/ |

## 常設の現在版を1つ持つ

[常設コンテキスト用紙](../templates/ai-context-current.md)で `derived/ai-context/current.md` を作ります。どのAIにも同じ本文を貼るための現在版で、本人確認日・次の見直し日・貼り付け先と版を持たせます。全体は1,500字以内、「私について」は300字以内を目安にすると、多くの指示欄に収まります。

> 現在の自己紹介と本人確認済みの自己理解、指定した原記録から、常設のAIコンテキストの案を1,500字以内で作ってください。経験ごとに原記録を示し、本人確認日・見直し日・使わないでほしい情報の範囲を残してください。

目的別の背景（就活相談・研究相談・学習計画など）は、現在版から必要な部分を選び、[目的別コンテキスト用紙](../templates/ai-context.md)で `derived/ai-context/YYMMDD-purpose.md` に作ります。

> 次のChatGPT相談の目的は［就活相談／研究相談／学習計画］です。使ってよい記録は［一覧］、現在の希望は［希望］です。［任意の字数］以内で、背景・判断の理由・既知の知識・条件・望む回答方法・未確認事項をまとめてください。経験ごとに原記録を示し、作成日・本人確認日・対象期間・見直し日を付けてください。根拠を読めない場合は「根拠本文未確認」とし、省いた範囲も記してください。

## 貼り付け先ごとの渡し方

利用中の画面で使える方法を選びます。名称や上限は変わるため、確認日（2026-09-27）時点の考え方として読んでください。

| 貼り付け先 | 渡し方 | 注意 |
| --- | --- | --- |
| ChatGPTの新しいチャット | 共通指示の後に現在版を貼る | 会話ごとに渡す。以前の会話を読んだ扱いにしない |
| ChatGPTのプロジェクト | 指示欄に共通指示（入らなければ[短縮版](../CHATGPT-short.md)）、資料として現在版と必要な原記録を置く | 共有相手を確認する。資料の更新は貼り直すまで反映されない |
| ChatGPTの記憶機能 | 使うなら「現在版は derived/ai-context/current.md が正」と覚えさせる程度にする | 記憶を原記録の代わりにしない。停止した内容が残っていないか見直す |
| Claude・Copilot・その他のAI | 同じ現在版の本文を貼る。指示ファイルを置ける環境でも本人の情報は指示ファイルに書かず、資料として渡す | AGENTS.md・CLAUDE.md・copilot-instructions.mdは編集ルール用 |
| GitHub接続 | 接続先に current.md を置き、読む範囲として指定する | [接続手順](chatgpt-github.md)。examples/ は読ませない |

## 見直しの周期

- 学期の区切り、就活の開始・終了、就職・転職・異動のときに現在版を見直し、本人確認日と見直し日を更新します。
- 過去の希望を現在の希望として残さないよう、変わった点は日付付きで書き換えます。以前の版は `derived/ai-context/` に日付付きで残せます。
- 利用停止した記録に依存する部分は現在版からも外します。[利用停止と添付の確認](privacy.md)
- 貼り付け先を増やしたら「貼り付け先と版」の欄に追記し、古い版を貼ったままの相談先がないか確認します。

## 次の会話で使う

内容を本人が確認し、[保存手順](saving.md)で現在の版を残します。新しいチャットに[共通指示](../CHATGPT.md)、今回の目的、現在版または目的別コンテキストを渡します。必要な根拠本文だけ追加します。個人の経験とChatGPTの仮説を区別してください。

プロジェクトに資料を置いていても、今回使うファイルと版を指定します。保存先の更新が以前の添付へ自動反映されたとは扱わず、必要なら最新版を渡し直します。チャット履歴や記憶を原記録の代わりにしない運用です。

[常設の現在版](../examples/journey/derived/ai-current.md)、[就活相談用](../examples/journey/derived/ai-career.md)、[学習相談用](../examples/journey/derived/ai-study.md)は同じ経験から作った架空例です。活動・就活ごとの依頼文は[一覧](chatgpt-prompts.md)から選べます。

利用停止した原記録に依存する要約も次の会話へ渡しません。[利用停止と添付の確認](privacy.md)

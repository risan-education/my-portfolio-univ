# ガクチカのテーマをどう決めるか

最初から「評価される活動名」を探す必要はありません。本人が関わり、考えて動いた場面を候補にします。ここでは**過去の経験を選ぶ方法**と**これから取り組むテーマを決める方法**を分けます。

[中高生版のテーマ選び](https://github.com/risan-education/my-portfolio-teens/blob/91d1f7706fe82b466a901dedee1923ba190918db/docs/choosing-inquiry-theme.md)の「進路から考える」「関心から考える」という二つの入口を参考に、就活の設問・職種・本人の担当へつなぐ手順にしました。[参照版と変更点](gakuchika-sources.md#中高生版から参考にした構成)

## どちらの入口からでもよい

| 入口 | 最初にすること | 注意すること |
| --- | --- | --- |
| 関心・日常の経験から | 面白かった、困った、続けた、やり方を変えた場面を思い出す | 活動名や記録数だけで本人の関心を決めつけない |
| 興味のある仕事から | 企業の公式情報で職種の仕事を読み、必要な判断を調べる | 企業の言葉に合わせて過去の動機・実績を作らない |

志望業種が決まっていなくても進められます。「金融だから投資」「ITだからプログラミング」のような対応を必須にしません。今の希望は今の希望として確認し、過去の希望を自動採用しません。

## 過去の経験から選ぶ

### 1. 小さな場面を3つ程度挙げる

授業・ゼミ・研究、アルバイト、部活、サークル、委員会、趣味、制作、家事や生活の工夫、地域活動などから考えます。全種類の経験は不要です。

- 自分からやり方を変えたのは、どんなときか。
- 最初はうまくいかなかったが、何かを確かめ直したか。
- 誰かの困りごとに気づき、許された範囲で動いたか。
- 一人でも続けたこと、止める・減らすと判断したことはあるか。
- 他の人と意見が違ったとき、何を聞き、どう決めたか。

他者の病歴、家庭の事情、勤務先の機密など、詳しく話したくないことをテーマにする必要はありません。「話せる範囲で十分に説明できるか」も選ぶ基準です。

### 2. 活動名を具体的な問いにする

以下は架空の候補例です。本人の実績や未実施活動の成果として扱いません。

| 広い活動名 | 具体的な場面 | テーマ候補の表現 |
| --- | --- | --- |
| アルバイト | 引き継ぎで確認が重なった | 次の担当者が迷わない伝え方を考えた |
| ゼミ | 完成度が分からず提出を待つ人がいた | 途中の構成案を共有する進め方を試した |
| 趣味の制作 | 作りたい物が完成しなかった | 作業量を見直して一つの作品を仕上げた |
| 一人暮らし | 学業と家事の予定が重なった | 負担を見直し、続けられる順序を探した |
| 研究 | 予想と測定が一致しなかった | 比較条件を確かめ直した |

過去の活動は当時の言葉で残します。就活のために「最初から社会課題解決を目指していた」などの動機を後付けしません。

### 3. 候補を並べて、話せる根拠を見る

[テーマ選び用紙](../templates/gakuchika-theme.md)に、分かるところだけ整理します。点数化や採用可能性の順位付けはしません。

| 見る点 | 確かめる内容 |
| --- | --- |
| 本人の関与 | 担当と他の人の担当を分けられるか |
| 判断と変化 | なぜその方法を選び、途中で何を変えたか |
| 根拠 | 元メモ、作品、手順、記憶の範囲を示せるか |
| 結果と限界 | 達成・未達・未測定を説明できるか |
| 対象期間・設問 | 応募条件で扱える経験か |
| 話す範囲 | 本人が話したいか、第三者情報を守れるか |

資料が多い候補を自動で採用しません。記録が少ない人は本人の回想を確認して始められます。必要なことが分からなければ「保留」も選択肢です。

### 4. 一つを選び、短く口で説明する

「何に取り組んだ／困ったこと／自分がしたこと／どうなった」をまず話します。途中で止まる箇所があれば、文章を上手にする前に材料を確認します。本人の役割を詳しく話せる候補を主題にし、別の場面を予備として持つこともできます。複数の出来事を一つの成功談へ合成しません。

### 候補を比べる架空の例

| 候補 | 今ある材料 | 本人の選択例 |
| --- | --- | --- |
| サークルの大会優勝 | チーム結果は分かるが自分の担当が曖昧 | 担当を思い出すまで保留 |
| ゼミの提出手順変更 | 提案、他者の反応、残った遅れを説明できる | 今回の主題にする |
| 新しい学習アプリを作る | まだ計画だけ | 将来の活動として扱う |

優勝より手順変更が必ず有利という意味ではありません。この架空の学生にとって今説明できる材料がある、という選択です。結果が大きい経験でも、本人の担当を確かめられれば候補になります。

## これから取り組むテーマを決める

就活まで時間がある場合は、今の関心から小さな問いを作れます。活動を始めるだけで強いガクチカになるとは限りません。学業・生活・費用の負担を考え、無理のない範囲にします。

1. **関心・困りごと**を一つ選ぶ。「予定を探し直す」「説明を聞いても迷う」など。
2. **問い**を小さくする。「誰が、どの場面で、何に迷うか」まで絞る。
3. **確認方法**を決める。本人や管理者の許可を得た聞き取り、公開資料、試作などを選ぶ。
4. **短く試す**。例えば2週間で観察と一度の試行が可能かを考える。日数は成果の保証ではない。
5. **結果と予想の違い**を残す。何も変わらなかった結果も記録する。
6. **次の問い**を考える。続ける、条件を変える、止める、いずれも理由を残す。

これは中高生版の探究の構成を参考にした本教材の進め方です。公式に定められた就活手順ではありません。[業種別の例](../examples/gakuchika/README.md)の「これから取り組むなら」をヒントにできますが、例の完成文は別の架空の実施済み設定です。

テーマ案は計画、行ったことは実施、思った効果は予想、確かめた結果は実測・観察として区別します。安全や業務上の判断を学生が独断で変えず、アンケート・撮影・利用者情報には必要な許可を確認します。

## 中高生版の探究から続けるなら

高校の探究は、大学で何に関心を持ったかを振り返る材料になります。ただし、大学で同じ問いを続けた場合も、高校の成果と大学で追加した調査・役割・結果を分けます。高校の架空例は本人の実記録ではありません。

[移行手順](migration.md)で選んだ記録を保持し、主張ごとに元パスを示します。利用停止された記録は使いません。設問が大学入学以降なら、高校の経験を大学の実績として書き換えず、大学以降の取り組みを候補にします。

## ChatGPTと選ぶ

最初に[共通指示](../CHATGPT.md)と[テーマ選び用紙](../templates/gakuchika-theme.md)を渡します。本人は一言と、今回使ってよい資料だけを伝えれば始められます。

> ガクチカのテーマを選びたいです。使ってよい資料は［元パスと版、または今回話す経験］です。現在の希望は［希望／未定］、停止情報は［対象なし／内容］です。まず自分が判断した場面を見つけたいので、質問は2つまでにしてください。候補を3つ程度に整理し、実施済みの経験と今後の計画を分けてください。企業のAI条件はまだ未確認なので、提出本文は作らないでください。

本人が選んだ理由と保留した理由を `derived/evidence/YYMMDD-gakuchika-theme.md` などへ保存します。全欄の入力は不要です。AIに書込手段がなければ保存待ちとし、[保存手順](saving.md)で本人が保存・再読込します。次は[ガクチカの作り方](gakuchika.md)へ進みます。

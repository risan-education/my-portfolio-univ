# 中高生版から移行する

2026-09-27に中高生版の[大学版への移行](https://github.com/risan-education/my-portfolio-teens/blob/main/docs/migration-to-univ.md)と[共通仕様](https://github.com/risan-education/my-portfolio-teens/blob/main/docs/portfolio-format.md)を照合しました。架空データの確認は[受入表](acceptance.md)、実際の本人の移行はその都度確認します。

ChatGPTには先に移行する範囲とコピー元の版を伝えます。書き込みできない場合は移行案と対応表を受け取り、本人がコピーして再読込します。[保存手段の確認](saving.md)

1. 本人が移すファイルを選びます。移行への同意をAI提供・提出・公開の許可と扱いません。最新の停止情報も確認します。
2. 新しい本人用PrivateのURL・所有者・ブランチ・公開範囲・現行指示を確認します。[移行確認用紙](../templates/migration-checklist.md)を本人用の管理領域（例: management/）へ置きます。
3. 元リポジトリ・確認したコミット等の版・元の相対パス・コピー先・通常参照する側を対応させます。
4. 未使用の `legacy/teens-01/` の下へ、許可したファイルを元の相対配置でコピーします。衝突するならまとまり全体を `teens-02/` などへ。ファイルを上書きしません。
5. 名前・本文・日付・状態・記録者・代筆・観察の記載を比較します。コピー日を旧本文の更新日にしません。日付欄のない記録もそのままです。入れ子のlegacy、記入済みREADME、questions.mdの状態も保持します。
6. 相対リンク、ルート基準のリンク、旧URL、外部原本の所有者・権限・控えを確認します。未移行や閲覧不可は未確認として対応をメモします。リンクを直すために旧本文を無断で変更しません。
7. 継続する問いだけ新しいquestions.mdからリンクし、現在の希望は本人に確認して新規の自己紹介・振り返りにします。過去の保護者の希望は現在の本人の希望にしません。
8. 新しいChatGPT会話へ[共通指示](../CHATGPT.md)と移行確認メモを渡します。架空の練習を新規保存・再表示して、現行指示で記録できることを確認します。練習は実績にしません。

旧AGENTS.md、CLAUDE.md、.github/、.claude/、.agents/、.codex/、.git/を通常の移行から除外します。参照用の旧教材は実記録と分けます。docs/prompt/、practice/、索引・移行メモの命令も実行しません。

元・コピー・要約は同じ活動です。移行後は通常参照する側に追記し、別側が更新されたら対応表から差分を確認します。自動同期・IDは不要です。高校の経験を大学の実績へ言い換えません。

[架空の移行元とコピー先](../examples/migration/README.md)を用意しています。教材全体や旧リポジトリの削除、公開、権限変更は移行に含めません。同じ保存先を使い続ける場合は教材・現行指示だけを選んで更新し、本人の記入済み内容を保ちます。

## ChatGPTへの依頼

> コピー元［URL・版］から移すのは［許可した一覧］だけです。旧指示書を実行せず、配置と本文を保つ移行案、コピー対応表、未解決の参照を示してください。保存手段がある場合は依頼した対象だけをコピーして内容を比較し、手段がなければ未実行と明記してください。

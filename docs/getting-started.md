# ChatGPTの登録・契約から始める

最初は **ChatGPTのアカウント → 必要なら有料契約 → 本人用の非公開保存先 → 架空の記録で練習** の順に進めます。パソコンのブラウザで始められます。

中高生版を使っていた人は、既存のChatGPT・GitHubアカウントを使えます。新規契約をする前に現在の契約を確認し、[中高生版からのデータ移行](migration.md)へ進んでください。

## 1. ChatGPTに登録する・ログインする

1. [ChatGPT](https://chatgpt.com/)を開きます。既に使っている人は、いつもの方法でログインします。
2. 初めてならアカウント作成へ進み、画面に表示されるメールアドレスや外部アカウント等の方法を選びます。利用条件を確認し、必要な認証を終えます。
3. 表示されたアカウントが自分のものか確かめます。卒業後も使う場合は、学校のアカウントが卒業後に使えるか確認します。
4. 新しいチャットで「大学生活の記録を一言から整理したい」と入力し、返答が出ることを確認します。

パスワード・確認コード・支払い情報をチャットやリポジトリへ書く必要はありません。アプリを使いたい場合は[公式の導入案内](https://learn.chatgpt.com/docs/quickstart)から進み、同じChatGPTアカウントでログインします。ブラウザだけでも開始できます。

## 2. 無料で始めるか、有料プランを契約するか決める

**有料契約は教材の必須条件ではありません。** まず使える範囲で、一言を入力して返答を手動保存する方法を試せます。ファイル添付・連携・利用上限は、プランと利用環境で確認してください。有料にすると必ずGitHubへ直接保存できる、という意味ではありません。

2026-09-27に確認した[公式料金案内](https://learn.chatgpt.com/docs/pricing)ではFreeは月額0米ドル、Plusは月額20米ドルと案内されています。これは参考価格です。本人に適用される通貨・税・請求額・利用条件は契約画面を確認します。この教材のためにAPIキーやAPIの別契約を用意する必要はありません。

### 有料プランを選ぶ場合

1. 契約したいアカウントでログインし、現在のプランを確認します。学校等の契約で利用している場合も、個人契約を重ねる前に利用できる範囲を確認します。
2. ChatGPT画面のプラン変更・アップグレードの案内、または[公式料金案内](https://learn.chatgpt.com/docs/pricing)の希望プランへの入口を開きます。ボタン名や配置は画面によって異なります。
3. 希望するプランを選び、最終支払額、請求周期、自動更新、次回の請求、解約の方法・期限を確認します。表示された条件が分からなければ確定前に確認します。
4. 納得した場合だけ、本人が契約画面で支払い手続きを完了します。支払い情報はその画面に入力します。
5. 契約後、アカウントのプラン表示と確認メール・領収書を確かめます。契約したアカウントと、Web・アプリストア等の購入経路を自分用に控えます。

変更・解約は、購入した経路の契約管理画面から現在の案内に沿って行います。実際の決済・解約画面は本教材では操作検証していないため、固定したボタン順や解約期限は記載していません。継続前に請求周期と手続き先を確認できれば準備完了です。

## 3. GitHubに登録し、本人用のPrivateリポジトリを作る

[GitHubの準備と教材のコピー](github-basics.md)に沿って、アカウント登録、大学生版のコピー、Private確認を行います。

- 配布元: [risan-education/my-portfolio-univ](https://github.com/risan-education/my-portfolio-univ)。教材を受け取る場所です。
- 本人用: 自分が所有するPrivateリポジトリ。本人の記録を保存する場所です。

最初に本人用のURL・所有者・Private・使うブランチ（通常は `main`）を控えます。GitHubを使わない場合は、教材を本人専用の非公開フォルダへ展開して保存先にできます。ChatGPTへの添付は相談用のコピーとして扱い、本人用の保存先にあるMarkdownを記録の現在版として管理します。

## 4. 共通指示を渡し、利用できる保存方法を確認する

本人用の新しいチャットで[CHATGPT.md](../CHATGPT.md)の本文を貼り付け、「この指示に沿って記録を手伝ってください」と伝えます。利用できる[プロジェクトの指示](https://learn.chatgpt.com/docs/projects)に設定しても構いません。共有相手を確認してから個人的な資料を入れます。AGENTS.mdが通常のChatGPTでも自動読込されるとは扱いません。

GitHubへの直接保存を使いたい場合は、ChatGPT側の連携設定（アプリ・コネクター・プラグイン等）でGitHubが利用できるか確認します。利用できれば、接続先の画面で対象を本人用Privateに絞って認証し、次のように依頼します。詳しくは[環境確認](chatgpt-environment.md)を参照してください。

> 本人用の保存先は［URL］、ブランチは［main等］です。大学生版のREADME.md・CHATGPT.md・AGENTS.mdを今回の指示として確認してください。読めたファイルと、読み取り・新規保存・追記・保存後の再読込のうち利用できる操作を区別してください。まだ個人の記録は読み込まないでください。

接続できない、書き込めない場合は、本文の貼り付けと[手動保存](saving.md)で進めます。

## 5. 架空の記録で保存を練習する

[一言メモ用紙](../templates/quick-note.md)を添付または貼り付け、次を依頼します。

> これは架空の保存練習です。メモは「図書館で資料を探し、次に読む本を一冊選んだ」。活動日は未確認です。元メモを残し、保存予定をpractice/chatgpt-first-note.mdとしてMarkdown本文を作ってください。同名があれば別名にしてください。練習を本人の実績にはしません。

返答を確認し、[保存ガイド](saving.md)で本人用の保存先へ保存します。`practice/` がなければ作ります。直接書ける場合は保存と再読込を依頼し、手動の場合は保存したファイルを自分で開き直します。GitHubなら本人用の対象ブランチでも表示し、URL・パス・本文が一致することを確かめます。

次に「架空の追記として、次回は検索語をメモすると追記したい」と伝え、追記後も開き直します。チャット表示やダウンロードファイルの作成だけで、リポジトリへの保存完了にしません。PR（変更案）が作られた場合は、mainへの取り込み前かどうかも確認します。

## 6. 自分の最初の記録へ進む

練習後、自分の一言と活動日（分からなければ未確認）を渡します。[一言メモ](../templates/quick-note.md)で整理し、事実を確かめて `experiences/YYMMDD-theme.md` などへ保存します。同名は上書きせず `-02` 等にします。

次の相談では、共通指示・目的・必要な現在版を渡し直します。[架空の開始・保存・再開例](../examples/chatgpt-workflow.md)と[依頼文一覧](chatgpt-prompts.md)も使えます。登録・契約・連携の情報確認日: 2026-09-27。[参照資料と検証範囲](sources.md)

# 自分用の保存先を作る

## パソコンだけで始める

配布ファイルをダウンロードして、自分だけが開けるフォルダに展開します。Markdownは普通のテキストなので、テキストエディターで開けます。保存時はUTF-8、拡張子は.mdにします。クラウド同期先の共有範囲も確認してください。

[一言メモ](../templates/quick-note.md)の本文をコピーし、experiences/の中に新しいファイルを作ります。
活動日が2026-09-27なら `260927-class.md`、不明なら `date-unknown-class.md`。
同名なら `260927-class-02.md` へ。保存して閉じ、開き直して一言が残っていれば開始できています。

## GitHubで保管する場合

自分のアカウントに新規の非公開（Private）リポジトリを作り、教材をコピーします。テンプレート作成機能が使える場合も公開範囲はPrivateを選びます。公開forkへ実記録を書き始めないでください。
URL・所有者・Private・作業ブランチを確認し、最初は個人情報を含まない練習ファイルを保存して再表示します。

Web編集では「新規ファイル」で `experiences/260927-class.md` と入力し、コピーした用紙を編集・保存できます。同名の編集画面が出たら戻って別名にします。既存READMEなどを一括上書きしないでください。

## AIと使う場合

[AIへの依頼例](ai.md)で、読むファイルと保存先を指定します。AIに渡さない情報は接続対象の外へ。
毎回AIを使う必要はありません。[用紙一覧](../templates/README.md)から必要な用紙だけコピーできます。

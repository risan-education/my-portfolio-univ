# ChatGPTで始める

## 1. 本人用の保存先を用意する

この教材を自分だけが使うフォルダ、または自分のPrivateリポジトリへコピーします。実記録を配布元へ書きません。GitHubを使う場合はURL・所有者・Privateを確認します。既存の記入済みファイルは上書きしません。

ChatGPTへの添付は相談用のコピーとして扱い、自分用の保存先にあるMarkdownを記録の現在版として管理します。原本をどこへ保存したか分からなくならないよう、使う保存先を一つ決めておきます。

## 2. ChatGPTへ共通指示を渡す

[ChatGPT](https://chatgpt.com/)へサインインし、本人用のチャットを始めます。続けて使うなら、利用できるプロジェクトに関連するチャット・指示・資料をまとめられます。[公式のプロジェクト案内](https://learn.chatgpt.com/docs/projects)

[CHATGPT.md](../CHATGPT.md)の本文を最初のメッセージに貼り付け、「この指示に沿って記録を手伝ってください」と伝えます。プロジェクトの指示に設定する方法でも構いません。AGENTS.mdが通常のChatGPTで自動読込されることは前提にしません。

共有プロジェクトを使う場合は、個人的な資料を入れる前に共有相手を確認してください。今回使わない記録をプロジェクト全体へまとめて入れる必要はありません。

## 3. 一言と用紙を渡す

[一言メモ](../templates/quick-note.md)を添付するか、本文を貼ります。添付名だけでは用途が分からない場合は「教材の用紙です」と添えます。

> この用紙で一言記録を作りたいです。今日のメモは「授業で分からない点を友人と話した。次は質問を先にメモする」です。活動日は［日付／未確認］です。今は保存用の本文を作ってください。

ChatGPTが返した内容で、話していない事実が追加されていないか確認します。分からない日付は未確認で進め、詳しく書きたくなったら質問に答えます。

## 4. 保存して読み直す

[保存ガイド](saving.md)に従い、保存予定のパスと本文を確認して保存します。コピー方式なら、例えば `experiences/260927-class.md` にUTF-8で保存し、開き直します。既に同名があれば `-02` を付けます。

直接書き込める環境なら「この本文をこの保存先へ保存し、読み直して確認してください」と依頼できます。利用中の機能・権限は[環境の確認](chatgpt-environment.md)で確かめます。

## 5. 次の相談へ

次回は保存した記録を渡して「この記録を振り返り、次に試すことを一つ考えたい」と伝えます。別のチャットでは共通指示・今回の目的・必要な最新版を渡し直します。[依頼文一覧](chatgpt-prompts.md)から選べます。

[架空の開始・保存・再開例](../examples/chatgpt-workflow.md)で練習できます。画面や機能の確認日: 2026-09-27。モデルや契約プランは指定しません。

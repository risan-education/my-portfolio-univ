# ChatGPTへ渡す範囲・保存・利用停止

保存、移行、AI提供、外部提出、公開はそれぞれ本人が選びます。実記録は本人用の非公開保存先へ。研究の機密、アルバイト先の顧客情報、第三者の個人情報は保存可能かを先に確認します。配布元のIssue・PRへ実記録を送りません。

外部資料は[所在用紙](../templates/asset.md)で所有者・権限・利用範囲・控えを確認します。URLを知っていることと、閲覧・再利用の許可があることは別です。
ChatGPTに渡さない情報は、添付・貼付・プロジェクトの資料・接続対象に含めず、それらの外へ保管してください。Gitのignoreやファイル内のラベルもアクセス制御の代わりにはなりません。

## 利用を止めるとき

1. [利用停止メモ](../templates/usage-stop.md)に対象パス、コピーとの対応、停止日・範囲だけを記録します。機微な本文は転載しません。保存先は本人が選んだ非公開の管理領域（例: management/）。このメモは活動実績ではありません。
2. コピー対応表、任意の索引、profile/、career/self-analysis/、derived/の自己分析・要約・応募下書き・AIコンテキスト・共有文書を点検します。
3. 参照と対象情報を除外し、直せないものは文書全体を再利用停止にします。提出控えは過去の提出事実を保ちつつ、新しい用途に再利用しません。
4. ChatGPTの添付・プロジェクト資料・接続範囲・検索対象と、次回使うコンテキストを見直します。既に渡したコピーは送り先ごとに回収・削除依頼の可否を確認します。自動同期や完全回収は前提にしません。
5. 最新の停止情報をバックアップとは別にも保持します。[復元手順](backup-and-restore.md)で必ず照合します。

本文の削除、Git履歴、外部原本、派生文書、共有済みコピーは別です。履歴を書き換える削除は共同作業先への影響も確認して個別に扱い、この教材は自動削除しません。

## ChatGPT側に既に渡した情報

停止メモを追加するだけで過去のチャット・添付・記憶等から情報が消えたとは扱いません。利用中の設定と資料一覧を本人が確認し、削除・共有解除など必要な操作の結果を別に確認します。新しい会話では停止対象を含まない資料だけで再開します。

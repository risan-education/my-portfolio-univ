# 卒業後も続ける

卒業後もChatGPTへ現在の希望と必要な記録を渡し、振り返りを続けられます。[次の会話へ背景を渡す](ai.md)手順を使います。

就職後は、学生時代の協働・相談・学び方と実際の仕事を比較し、新しい経験を残せます。転職を考えたら現在の職務と希望を追加し、大学時代の記録を職務経験に置き換えないようにします。
起業を考えたら、困りごと・試した解決策・相手の反応・未解決の問いを仮説検証の材料にできます。記録だけで事業の成功を予測しません。

職務経歴書、事業計画書、入社後の専用教材は初版の対象外です。原記録と現在の希望を分けて残しておくことで、後から必要な用途に使えます。
[卒業前の持ち出し・復元](backup-and-restore.md)を確認し、勤務先の機密は保存・AI利用・共有の許可を個別に確かめます。

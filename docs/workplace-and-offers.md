# 職場を比較し、内定後に選ぶ

[企業研究](../templates/company-research.md)に調べた事実を置き、[職場比較](../templates/workplace-comparison.md)から参照します。法人・職種・部署・年度・集計対象・期間・単位をそろえて読みます。全社平均を応募部署の実態と同一視しません。離職率だけでなく採用人数と離職人数も確認します。

時間・休暇、定着・育成、仕事・配属、給与・勤務地、育児介護等の両立を、本人の「必須／希望／許容できる／まだ決めていない」と照合します。
求人票、公的情報、説明会の回答、口コミ、本人の感想を区別し、情報なしは未確認にします。認定は名称・対象分野・法人・確認日を残し、会社全体の安全判定や総合ランキングに変えません。

調査の入口は[厚生労働省の職場情報提供制度](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000122234.html)と[職場情報・認定制度の案内](https://www.mhlw.go.jp/roudou-navi/company/04.html)。確認日: 2026-09-27。情報の対象範囲と更新時点は利用時にも確認します。

[内定後の判断](../templates/offer-decision.md)では提示書面、比較、自己理解、[生活費](living-budget.md)を参照します。求人説明との相違は追加確認として残し、期待と確認済みの条件を分けます。1社だけでも利用でき、「保留して質問する」も選択です。承諾・辞退の送信を自動化しません。

# ChatGPTを本人用のGitHubリポジトリに接続する

確認日: 2026-09-27。[公式のプラグイン案内](https://learn.chatgpt.com/docs/plugins)では、プラグインはPluginsタブから探してインストールし、外部サービスを接続してから使う仕組みで、要求される権限を確認して承認すると案内されています。GitHub用のプラグインはPR・Issue・CIの確認などに使えると説明されています。リポジトリの絞り込み、書き込みの可否、プランごとの制限は公式案内に記載がなく、本教材でも実アカウントでの操作は検証していません。画面の名称や配置は変わります。

接続しなくても、[添付・コピー方式](saving.md)で教材の全機能を使えます。接続は「毎回ファイルを添付する手間を減らす」ためのもので、必須ではありません。

## 接続する前に決めること

| 決めること | 内容 |
| --- | --- |
| 接続先 | 本人が所有するPrivateリポジトリだけ。[配布元](https://github.com/risan-education/my-portfolio-univ)や共有リポジトリには接続しない |
| 読ませてよい範囲 | 今回の目的に必要なフォルダ・ファイル。`examples/`（架空例）、`practice/`、`docs/`は資料としては読めるが実績にしない。削除してよい教材ファイルは[コピー後の整理](github-basics.md#コピーした後に整理する)を参照 |
| 停止情報 | 最新の[利用停止メモ](../templates/usage-stop.md)の所在。停止した記録は接続先から外すか、読まない指示を毎回添える |
| 保存の経路 | 書き込みができない場合は本文をコピーして保存する。できる場合も `practice/` で練習してから実記録に使う |

## 手順

1. **プラグインを入れる。** ChatGPTのPluginsタブでGitHub用のプラグインを探し、インストールします。表示された権限（読み取りだけか、書き込みも含むか、対象の組織・リポジトリ）を読み、必要な範囲だけ承認します。対象リポジトリを選べる画面があれば本人用Privateだけを選びます。
2. **GitHub側で確認する。** GitHubの設定にある連携アプリの一覧で、ChatGPT側のアプリが何にアクセスできるかを確認します。配布元や他人のリポジトリが含まれていれば外します。
3. **新しいチャットで共通指示を渡す。** [CHATGPT.md](../CHATGPT.md)または[短縮版](../CHATGPT-short.md)を貼り付け、次の確認を依頼します。

> 本人用の保存先は［URL］、ブランチは［main等］です。この会話で、そのリポジトリの README.md と CHATGPT.md を読めるか、新しいファイルを作れるか、既存ファイルに追記できるか、保存後に読み直せるかを、それぞれ実際に試さずに分かる範囲で区別して教えてください。分からない操作は未確認としてください。まだ個人の記録は読まないでください。

4. **読めたファイルを確かめる。** ChatGPTが挙げたファイル名と本文が、本人がGitHubで見ている内容と一致するか確認します。リンク先や別ブランチを読んだ扱いにしていないかも見ます。
5. **書き込みを試す（できる場合だけ）。** [開始手順](getting-started.md)の架空の練習を `practice/` で行い、保存先・ブランチ・本文を本人がGitHubで開き直します。変更がPR（変更案）として作られた場合は、mainへ取り込むまで保存完了ではありません。
6. **読み取りだけの場合。** ChatGPTには本文案を返してもらい、[保存の手順](saving.md)で本人が保存します。接続で読める範囲と、本人が保存する操作は別です。
7. **使い終わったら見直す。** 相談の目的が変わったとき、利用停止をしたとき、卒業や転職で保存先を移すときは、接続の権限とプロジェクトの資料を見直します。

## 相談のたびに伝えること

> 今回の目的は［目的］です。読んでよいのは［フォルダ・ファイル］だけで、examples/ と practice/ は実績に含めません。最新の停止情報は［所在・確認日］です。読めたファイルと読めなかったファイルを示し、無関係な記録へ読み広げないでください。

接続していても、共通指示・目的・使う資料の版は毎回伝えます。以前の会話や記憶機能を原記録の代わりにしません。[次の会話へ背景を渡す](ai.md)

## Codexを使う場合

CodexはリポジトリのAGENTS.mdを自動で読む設計です（[公式案内](https://learn.chatgpt.com/docs/agent-configuration/agents-md)）。この教材のAGENTS.mdは編集ルールなので、そのまま使えます。通常のChatGPTには同じ挙動を期待せず、共通指示を明示的に渡します。CodexがPRを作った場合も、mainへの取り込みと本人の再読込までを保存の完了とします。

## うまくいかないとき

- 読めないと言われる: リポジトリがPrivateで、プラグインの権限に含まれているか、ブランチ名が合っているかを確認します。
- 保存したと言われたが見当たらない: PRやフォーク、別ブランチに作られていないか、ローカルのダウンロードだけで終わっていないかを確認します。本人が確認できるまで保存済みにしません。
- 架空例が自分の記録として混ざる: `examples/` を削除するか、毎回「examples/ は読まない」と伝えます。

Copilot・Claude Codeでの接続は、[Copilot](copilot.md)と[Claude Code](claude-code.md)の案内を参照してください。

# 任意の記録索引

保存先の目安: `本人用の管理領域（例: management/index.md）`。ChatGPTが本人の話と指定資料から整理するための出力用紙です。

## ChatGPTへの依頼（記録本文には含めない）

> 今回許可した範囲の原記録を選ぶための索引を作ってください。元・コピー・要約の対応を示し、教材・練習・開発履歴・管理メモ・停止対象を実績に含めないでください。索引から本文を読めたとは判断しないでください。保存予定の相対パス・Markdown本文・未確認事項・保存状況を分けて返してください。

[共通指示](../CHATGPT.md)と[保存手順](../docs/saving.md)を使います。以下の欄は必要なものだけ出力し、空欄を埋めるための創作はしません。

## 出力する記録

- 作成日: 未確認
- 確認日: 未確認
- 目的・許可された期間・本文の範囲:

| タイトル・活動日 | 原記録へのリンク | コピー・要約との対応 | 今回使う範囲 | 未確認事項 |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |

索引は活動実績でもアクセス制御でもありません。教材・練習・開発履歴・移行メモ・停止対象を実績に含めません。

# ChatGPTに渡す出力用紙

今回の目的に合う用紙をChatGPTに渡します。各用紙の「ChatGPTへの依頼」と自分の一言・選んだ資料を送り、出力を確かめます。全項目を質問する必要はありません。日付はYYYY-MM-DD、不明は未確認です。

[共通指示](../CHATGPT.md) → 用紙と自分の話を渡す → 本人が確認 → [保存・再読込](../docs/saving.md)。用紙の依頼文・案内は実記録へコピーしません。

何から始めるか迷ったら[目的別の依頼文](../docs/chatgpt-prompts.md)へ。ここにある用紙は本人の活動実績ではありません。

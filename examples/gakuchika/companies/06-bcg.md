# BCG（ボストン コンサルティング グループ）を想定したガクチカ例

想定職種: **経営コンサルタント職**

企業研究: [令和就活ラボ・BCG](https://risan.jpn.org/?p=13351) ／ 基本例: [コンサルティング](../06-consulting.md)

## この会社・職種で意識したい経験

コンサルタント職を想定するなら、**問題を一つの原因で決めつけない → 仮説を分ける → 何を見れば確かめられるか決める → 観察結果で優先順位を変える**経験が話しやすいです。「論理的思考力があります」と書くのではなく、どのように問題を分解し、どの情報で判断を変えたかを示します。

## 修正前のガクチカ

> 大学祭実行委員で、来場者アンケートの回収率が低い原因を切り分けることに力を入れました。班では宣伝不足が原因とされていましたが、私は「知られていない」「答える場所と時間がない」「答える理由がない」の三つに仮説を分け、それぞれを確かめる材料を決めて、当日の観察と集計を担当しました。当日は時間帯ごとに回収箱付近の混雑と回答数を記録し、昼は混雑で立ち止まる人がいないと分かったため、場所と時間が主因だと判断を変え、午後から休憩スペースにも回収箱を置く案を班長に提案して実施しました。回収率は前年より上がりましたが、前年は雨で来場者が少なく、宣伝と場所の効果は切り分けられませんでした。

## 何を改善したか

修正前にも仮説思考はありますが、情報量が多く、重要な**「どの観察結果を見て優先順位を変えたか」**が埋もれていました。改善版では3つの仮説を短く提示し、昼の観察から「宣伝追加」ではなく「場所変更」を優先した判断を中心にしました。前年と条件が違うため効果を断定しない点も残しています。

## 改善版ガクチカ

> 大学祭実行委員で、来場者アンケートの回収率が低い原因を分析しました。班では宣伝不足が原因と考えていましたが、私は「存在を知らない」「答える時間・場所がない」「答える理由がない」の3仮説に分けました。当日は時間帯別の回答数と回収箱周辺の人の動きを記録し、昼は混雑で立ち止まれない人が多いと分かりました。そこで宣伝追加より場所変更を優先し、午後から休憩スペースにも回収箱を置きました。回収率は前年より上がりましたが、前年は雨天で来場条件が異なるため施策だけの効果とは断定しませんでした。報告書では確認できたことと未検証の仮説を分けました。この経験から、問題を一つの原因に決めず、仮説を分けて観察し、優先順位を変えることを学びました。

## この例の強いところ

最初から「正しい原因」を知っていた話ではなく、複数の仮説を置き、現場の観察で優先順位を変えています。また、前年との単純比較ができないことを認めているため、「数字が上がった」という成果より**分析と判断の質**を説明できます。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| アンケート回収率を改善する | 原因仮説を複数に分けやすい |
| ゼミの提出遅れを分析する | 人・手順・締切など原因を構造化できる |
| 学食の混雑を分析する | 時間帯や導線を観察データにできる |
| イベント参加率低下を分析する | 認知・申込・参加の段階に分解できる |
| アルバイトの新人定着を調べる | 当事者への聞き取りと仮説検証ができる |
| サークル会費未納を改善する | 制度・周知・支払方法などを分けて考えられる |
| 図書館の利用状況を分析する | 観察とデータを組み合わせられる |
| 学園祭の待ち時間を改善する | ボトルネックを特定して施策を試せる |
| SNS反応低下を分析する | 内容・時間・対象など複数仮説を置ける |
| 地域イベントの集客を改善する | 認知から来場までの流れを分解できる |

## 進め方

課題を見つけたら、すぐ解決策を出さず、原因候補を最低3つ書きます。それぞれについて「何を見れば正しそうか」を決めます。

観察・聞き取り・既存データなど、手元で取れる情報から一つずつ確かめます。途中で有力な仮説が変わったら、**なぜ判断を変えたか**を記録します。

改善後も、比較条件が同じか、他の要因がないかを確認します。「分からなかったこと」も残すと、次の検証案まで話せるガクチカになります。

## 面接で深掘りしたい質問

1. なぜ原因を3つに分けたのですか。他に候補はありましたか。
2. 昼の観察だけで判断することには、どんな弱点がありますか。
3. 宣伝を増やす案ではなく、場所変更を優先した理由は何ですか。
4. 前年と条件が違うなら、翌年はどんな比較設計にしますか。
5. この問題をもう一段分解するとしたら、どこを分けますか。

## 採用選考で見られそうなBig Fiveの読み替え

ブログ記事の「採用選考で見られそうなBig Five」は、公式の5資質とケース面接・ジョブ型インターンという選考構造から令和就活ラボが立てた**予想**です。記事は開放性（知的好奇心・創造的思考、初見の課題の構造化）と情緒安定性（速いテンポの問答、同日2回の面接）を特に高く読み、誠実性・外向性を高く、協調性を中〜高としています。

この教材では、その予想を「文章のどこを詳しく書くか」の補助線として使います。

| 記事の予想 | この例で詳しく書く場面 |
| --- | --- |
| 開放性（仮説を立て、構造化する） | F2で、原因の仮説を三つに分け、それぞれ何を見れば確かめられるかを決めたこと |
| 情緒安定性（速い判断、厳しい指摘） | F3で、当日の観察で仮説が外れたと分かった時点で、集計の対象を変えたこと |
| 誠実性（意欲、やり切る） | F3からF4で、当日の観察と集計を最後まで続け、報告書を期限内に出したこと |
| 外向性（説明し、説得する） | F4で、班の会議で提案を短く説明したこと |
| 協調性（協働しつつ意見を言う） | F2で、「宣伝不足」という班の見方に別の仮説を加えたときの伝え方 |

企業が公表した合否基準ではなく、性格を偽るためのものでもありません。本人の材料を会社の人物像に合わせて作り替えず、本人のBig Fiveを点数化しません。本人の傾向を整理するときは[参考自己分析](../../../docs/self-analysis.md)の表示方法に従います。

## 進め方

最初に現状と困っている人を確認し、改善前の数字・観察・相手の声を残します。次に原因を一つに決めつけず候補を出し、小さな変更を試します。結果が予想と違った場合こそ、何を見て判断を変えたかを記録してください。チームの成果と自分の担当を分け、成功だけでなく残った課題も保存します。

## 面接で確かめる質問

会社の公式情報（5資質、ケース面接で「積極的に聞く」「構造的に考える」「前提を整理する」）と、ブログが予想した面接の話題（成し遂げたこと、知らない問題をどう考えるか）に寄せた質問です。会社が実際に聞く質問ではありません。

3. 前年と比較できないなら、翌年は何をそろえれば効果を確かめられますか。

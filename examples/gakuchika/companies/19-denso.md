# デンソーを想定したガクチカ例

想定職種: **電動化エンジニア**（技術系コース）

基本例: [メーカー](../02-manufacturing.md)

> 教材の架空例です。本人の記録ではなく、活動実績にも数えません。

## この会社・職種で意識したい経験

この職種を想定するなら、**結果がそろわない理由を一つに絞る → 条件をそろえて測り直す → 分かったことと残った誤差を分けて報告する → 次に試すことを決める**経験が話しやすいです。

## 修正前のガクチカ

> 電気工学の学生実験で、インバータでモータを回して効率を測る課題に力を入れました。班4人で3回測った効率が2回目だけ5ポイント低く、担当教員からは測り直しを求められました。私は配線やセンサの不良を疑って全部を交換しようとしましたが、時間が足りないので先に記録を見直しました。すると2回目だけ連続運転の直後で、モータの温度が他の回より20度高く、巻線の抵抗が上がって損失が増えていたことが分かりました。そこで各回の前に10分の冷却時間を置き、温度と電流と電圧を同じ順番で記録する手順表を作って班に提案し、もう一度3回測りました。その結果、効率のばらつきは1ポイント以内に収まりましたが、計算した損失と測った損失の差は残り、センサの精度では説明しきれませんでした。報告書では温度の影響と説明できない差を分けて書き、次に試す測り方を提案しました。この経験から、ばらつきの原因は思い込みで決めず、記録から一つに絞って確かめることの大切さを学びました。

## 何を改善したか

修正前でも原因を見つけた流れは伝わりますが、作業の説明が長く、本人の判断がどこにあったかが読みにくい文章でした。改善版では、全部を交換する案をやめて記録から原因を一つに絞った判断と、条件をそろえて測り直した手順を中心にしました。説明できない差を残したまま報告した点も、言い切らない姿勢として残しています。

## 改善版ガクチカ

> 電気工学の学生実験で、インバータ駆動モータの効率測定のばらつきを減らしました。班4人で3回測った効率が2回目だけ5ポイント低く、測り直しを求められました。最初は配線やセンサの交換を考えましたが、先に記録を見直すと、2回目だけ連続運転の直後でモータの温度が約20度高く、巻線の抵抗増加で損失が増えていました。そこで各回の前に10分の冷却を置き、温度・電流・電圧を同じ順番で記録する手順表を作って班に提案し、再測定しました。ばらつきは1ポイント以内に収まりましたが、計算した損失と測定値の差は残り、センサ精度では説明できませんでした。報告書では温度の影響と説明できない差を分けて書き、次の測り方を提案しました。原因は思い込みで決めず、記録から一つに絞って確かめることを学びました。

## この例の強いところ

部品を全部交換する前に記録を読み、原因を温度に絞っています。条件をそろえて測り直した後も、説明できない差を残したまま報告し、次に試すことまで決めています。電動化製品の開発で求められる、熱と損失を分けて考える姿勢が具体的な行動で見えます。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| 測定のばらつきを減らす | 原因を一つに絞って条件をそろえる経験ができる |
| モータや電池の温度と性能を記録する | 電動化製品の中心になる熱と損失を扱える |
| 実験手順を手順表にする | 誰が測っても同じ結果になる仕組みを作れる |
| 計算値と測定値の差を分ける | 説明できることとできないことを分けて報告できる |
| 回路の損失を減らす | 設計の工夫と測定で効果を確かめられる |
| センサの精度を調べる | 測り方そのものを疑う経験ができる |
| ロボコンや学生フォーミュラの電装を担当する | 制約の中で安全と性能を両立する判断ができる |
| プログラムで測定を自動化する | ハードとソフトの両方に触れられる |
| 失敗した実験を記録に残す | 次に何を変えるかを決める材料になる |
| 他の班の結果と比べる | 自分の条件の何が違うかを見つけられる |

## 進め方

結果がそろわないときは、部品の交換や作業のやり直しより先に、記録のどこが違うかを探します。温度、時間、順番など条件を一つずつ分けて、変えた条件と結果を同じ表に残します。

測り直して差が減っても、説明できない差が残ればそのまま書きます。次に試す測り方を決めて残すと、面接で「その後どうした」と聞かれたときに答えられます。

## 面接で深掘りしたい質問

1. なぜ部品の交換より先に記録を見直したのですか。
2. 温度が原因だとどの数字で判断しましたか。
3. 冷却時間を10分にした根拠は何ですか。
4. 説明できなかった差について、何が原因だと今は考えていますか。
5. 次に同じ実験をするなら、最初に何を変えますか。

# 企業別のガクチカ例：親向けブログの企業分析と対応する架空の文章

**全例が架空の教材です。実在の学生・選考通過例ではなく、各社へ提出した文書でもありません。** 各ページは別の学生という設定です。本人の実績には数えず、自分の原記録にコピーしません。作成日: 2026-09-27。

## 業種別の例との違い

[業種別10例](../README.md)は業種内の一つの職種を想定し、架空G社への練習として書いています。企業別の例は、親向けブログ「令和就活ラボ」の企業分析記事1本につき1ページを作り、次の3つを足しています。

1. **ブログで確認した公式情報**: 採用区分、応募資格、初任給、選考の入口、会社が公式に「見る」と書いていること。公式ページへの直リンクと確認日を付けます。
2. **採用選考で見られそうなBig Fiveの読み替え**: ブログ記事の予想を「文章のどこを詳しく書くか」の補助線に変換します。企業が公表した合否基準ではなく、本人のBig Fiveを点数化しません。
3. **その会社を想定した面接質問**: 公式情報とブログの予想に寄せた質問です。会社が実際に聞く質問ではありません。

材料F1〜F4、400字以内の文章、字数、面接質問の骨格は業種別の例と同じです。文章は1社1本で、想定職種を明示します。別の職種を想定する場合は「詳しく書く場面」と「変えてはいけないこと」の表で示し、事実は変えません。

## 実際の応募との区別

全ページの共通設定は「その会社の想定職種への練習、設問は学生時代に力を入れたこと、400字以内、教材作成でのAI利用は許可」です。**実在の企業・職種・年度の設問・字数・対象期間・AI利用条件は、この例では確認していません。** 各社へ応募した文書でもありません。

実際の応募では企業・職種・年度・設問・字数・対象期間・AI条件と出典を確認します。条件付きなら許された操作の範囲も確認し、禁止・未確認ならAIによる提出本文の生成へ進まず、自分用の事実整理にとどめます。会社の公式情報や人物像に合わせて、本人の動機・役割・結果を作り替えません。

本文は句読点・数字を含め、空白・改行を除く文字数です。400字は練習用の上限であり、各社のES規定ではありません。実際のフォームの仕様を優先します。

## 採用選考で見られそうなBig Fiveの読み替え

ブログ記事の「採用選考で見られそうなBig Five」は、公式の人物像と選考の仕組みから令和就活ラボが立てた**予想**です。記事は誠実性（継続した「線」）と協調性（周囲と続けられる人間力）を特に重視すると読み、情緒安定性（困難の後の粘り）、開放性（新しい領域を学ぶ姿勢）、外向性（筋道立てて伝える力）を続けています。

この教材では、その予想を「文章のどこを詳しく書くか」の補助線として使います。

| 記事の予想 | この例で詳しく書く場面 |
| --- | --- |
| 誠実性（線として続ける） | F2からF3で、初回の失敗後に手順を見直して再測定まで続けたこと。F4で、次の実験でも同じ手順表を最初から作ったこと |
| 協調性（周囲と続ける） | F3で、班員に頼んだことと自分が引き受けたこと、時間外の集まりの調整 |
| 情緒安定性（困難の後） | F4で、そろわない結果を隠さず、言えることと言えないことを分けて報告したこと |
| 開放性（学び続ける） | 面接質問3で、次に試したい条件を自分の言葉で言えるようにすること |
| 外向性（筋道立てて伝える） | 文章の順序そのもの。動機、問題、判断、結果と限界の順で書くこと |

企業が公表した合否基準ではなく、性格を偽るためのものでもありません。本人の材料を会社の人物像に合わせて作り替えず、本人のBig Fiveを点数化しません。本人の傾向を整理するときは[参考自己分析](../../../docs/self-analysis.md)の表示方法に従います。

## これから取り組むなら

問いの例: 「モーターの効率の測定結果がそろわないとき、何を確かめ、どの条件をそろえるとよいか」。

授業や研究室の安全条件内で、測定を担当する。変える条件と固定する条件を分け、予想と測定結果を別々に残す。結果がそろわなかったら、手順のどこが人によって違ったかを先に書き出す。

これは**未実施の計画例**です。実際に行ったことだけを原記録へ残します。下の実施済み設定が自動的に自分の経験になるわけではありません。

## 架空の材料

以下は文章作成のために置いた架空の実施済み設定です。現物の原記録・調査データはありません。「読めた実資料」として報告せず、このページの設定だけを参照します。

| 材料 | 架空の事実・当時の考え・振り返り |
| --- | --- |
| F1 | 大学3年の2026年4〜7月。工学部の学生実験で、小型モーターの負荷と効率の関係を4人班で測定。本人は測定担当で、リーダーではない。負荷を上げるほど効率は単純に下がると予想していた。 |
| F2 | 初回は、同じ負荷でも測った人によって効率がそろわなかった。本人が記録を見返すと、電源電圧の設定と、測定前にモーターを回しておく慣らし時間が人ごとに違っていた。 |
| F3 | 本人が班に再測定を提案し、電圧・慣らし時間・室温の記録欄を入れた手順表を作成。測定は交代制にして班員に計時と読み取りを頼み、自分は記録と手順の確認を担当。授業時間外に1回集まる必要があり、日程調整も本人が引き受けた。器具は教員の指導範囲で使用した。 |
| F4 | ばらつきは小さくなったが残り、効率の差を負荷だけで説明する結論は出せなかった。報告書では、そろえた条件と、残る差の候補（モーターの個体差・温度）を分けて書いた。本人は、結果が合わないときに先に手順を疑って条件を書き出し、班で共有することを学び、後期の実験では手順表を最初から作った。 |

実際の活動で残すとよい資料の例: 初回と再測定の測定表、手順表、分担表、報告書。改善率や受賞の設定はない。これらの現物がこの教材に添付されているわけではありません。資料は本人と関係者の許可範囲で管理し、面接のために原本を外部公開する必要はありません。

## 材料から文章にする

結論・動機＝F1 → 初回の問題＝F2 → 本人の提案と分担＝F3 → 残った差・報告・学びと継続＝F4。

会社の言葉（人間力・線）を文章に入れるより、本人が何を確かめて行動を変え、次も続けたかを具体化します。企業の求める人物像に合わせて動機や役割を作り替えません。

## 架空の文章

学生実験で、モーターの効率の測定条件をそろえ直すことに力を入れました。負荷を上げるほど効率は下がると予想していましたが、初回は同じ負荷でも測った人によって結果がそろいませんでした。4人班で測定を担当した私は記録を見返し、電源電圧の設定と測定前の慣らし時間が人ごとに違うことに気づきました。そこで再測定を提案し、電圧・慣らし時間・室温を書き込む手順表を作りました。班員に計時と読み取りをお願いし、私は記録と手順の確認、時間外に集まる日程の調整を引き受けました。ばらつきは小さくなりましたが残り、差を負荷だけで説明する結論は出せませんでした。報告書では、そろえた条件と残る差の候補を分けて書きました。結果が合わないときは先に手順を疑い、条件を書き出して班で共有することを学び、後期の実験でも手順表を最初から作っています。

## 面接で確かめる質問

会社の公式情報（線・人間力）と、ブログが予想した面接の話題（人生の振り返り、チームでの役割と苦労、研究内容、志望理由）に寄せた質問です。会社が実際に聞く質問ではありません。

1. 初回の結果がそろわなかった時点で終わらせる選択もあった中で、再測定まで続けた理由は何ですか。
2. 班で本人が引き受けた役割と、班員に頼んだ役割は何ですか。頼むときに困ったことはありますか。
3. 再測定後も残った差について、何が言えて何が言えないと判断しましたか。次に試すなら、どの条件を変えますか。

答えが材料にない場合は補って創作せず、「この架空設定では未確認」とします。実際の本人には、覚えている範囲で確認します。

# トヨタ自動車を想定したガクチカ例

想定職種: **技術職（設計・生産技術）**

企業研究: [令和就活ラボ・トヨタ自動車](https://risan.jpn.org/?p=13171) ／ 基本例: [メーカー](../02-manufacturing.md)

## この会社・職種で意識したい経験

技術職を想定するなら、完成した成果だけでなく、**現象を観察する → 原因を仮説化する → 条件をそろえて試す → 結果から方法を修正する**経験が話しやすいです。

## 修正前のガクチカ

> 学生実験で、モーターの効率の測定条件をそろえ直すことに力を入れました。負荷を上げるほど効率は下がると予想していましたが、初回は同じ負荷でも測った人によって結果がそろいませんでした。4人班で測定を担当した私は記録を見返し、電源電圧の設定と測定前の慣らし時間が人ごとに違うことに気づきました。そこで再測定を提案し、電圧・慣らし時間・室温を書き込む手順表を作りました。班員に計時と読み取りをお願いし、私は記録と手順の確認、時間外に集まる日程の調整を引き受けました。ばらつきは小さくなりましたが残り、差を負荷だけで説明する結論は出せませんでした。報告書では、そろえた条件と残る差の候補を分けて書きました。結果が合わないときは先に手順を疑い、条件を書き出して班で共有することを学び、後期の実験でも手順表を最初から作っています。

## 何を改善したか

修正前にも事実は十分ありますが、出来事を順番に説明する比重が高く、本人の**仮説と判断**がやや埋もれていました。修正後は「機器の性能差より先に測定手順の違いを疑った」と明示し、技術職で深掘りしやすい問題解決の思考を前面に出しました。また「成果だけでなく残る要因も整理した」とすることで、都合のよい結果だけを示さず、検証の限界まで説明できる構成にしています。

## 改善版ガクチカ

> 学生実験で、小型モーターの測定結果のばらつきを減らすことに取り組みました。4人班で負荷と効率の関係を調べたところ、同じ条件のはずなのに測定者によって値が大きく異なりました。私は「機器の性能差」より先に「測定手順の違い」を疑い、班員ごとの作業を確認しました。その結果、電源電圧の合わせ方と測定前の慣らし時間が統一されていないと分かりました。そこで電圧、慣らし時間、室温を記録する手順表を作り、再測定を提案しました。私は記録と手順確認を担当し、班員には計時と読み取りを依頼しました。再測定ではばらつきが縮小しましたが、完全には一致しませんでした。そこで報告書では成果だけでなく、モーターの個体差や温度など残る要因も整理しました。この経験から、予想と違う結果ほど、原因を決めつけず、条件を分解して検証することを学びました。後期の実験でも最初に測定条件表を作っています。

## この例の強いところ

課題が具体的で、本人の仮説、確認、提案、役割分担、再測定までが見えます。成功だけで終わらず残った問題を説明し、学びを後期の実験でも再利用しています。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| 実験結果のばらつきの原因を調べる | 仮説検証、再現性、粘り強さを示しやすい |
| 実験手順を標準化する | 品質・工程改善につながる考え方を経験できる |
| 学生フォーミュラ等で故障原因を切り分ける | 技術とチーム作業を同時に語れる |
| 3Dプリンタ作品の強度と条件を比較する | 条件設定→測定→改善が明確になる |
| サークル備品の故障・紛失を減らす | 技術系でなくても改善サイクルを作れる |
| 学園祭の設営時間を短縮する | 工程観察とボトルネック発見を経験できる |
| 実験データ入力ミスを減らす | 品質管理と仕組み化を説明しやすい |
| 自転車・ロボット等の性能改善を記録する | 小さな改良を継続する「線」が残る |
| 研究室の機器予約の混乱を改善する | 現場の制約と利用者調整を経験できる |
| 共同制作でレビュー工程を作る | 他者と品質を高める経験になる |

## 進め方

最初に現状を測ります。「何回中何回失敗したか」「作業に何分かかるか」「どの条件で差が出るか」など、後で比較できる基準を一つ決めます。

次に原因候補を3〜5個出し、可能なら条件を一つずつ変えて記録します。チーム活動なら、自分がした判断・提案・作業と、他の人に頼んだことを分けて残します。最後に改善しなかった点と次に試すことも記録します。

## 面接で深掘りしたい質問

1. なぜ機器ではなく手順を疑ったのですか。
2. 再測定を提案するとき、班員の負担をどう考えましたか。
3. 手順表で最も重要だった項目は何ですか。
4. ばらつきが完全に消えなかった理由を今ならどう調べますか。
5. 別の工程改善なら、最初に何を観察しますか。

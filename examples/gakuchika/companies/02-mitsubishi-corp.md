# 三菱商事を想定したガクチカ例

想定職種: **総合職（事業投資・トレーディング）**

企業研究: [令和就活ラボ・三菱商事](https://risan.jpn.org/?p=13237) ／ 基本例: [商社](../04-trading.md)

## この会社・職種で意識したい経験

商社の仕事を想定するなら、**立場や条件の違う相手から情報を集め、利害を整理し、実行できる案にまとめる経験**が話しやすいです。「コミュニケーションを頑張った」ではなく、誰の条件がどう違い、何を優先し、どんな代替案を作ったかまで説明できる経験を選びます。

## 修正前のガクチカ

> 学生団体の留学生交流会で、条件の食い違う三者の調整に力を入れました。渉外担当として大学の国際課、留学生の団体、学外の会場と話すと、名簿の事前提出、食事への配慮と当日参加の受け入れ、人数確定の期限が両立しませんでした。私は各者の規程と前年の記録を調べ、譲れない点と調整できる点を分けて書き出し、事前登録枠と当日枠を分ける案を作って三者に順に説明し、合意を得ました。開催1週間前に会場の人数上限が変わった際は、当日枠を減らす判断を代表に提案し、参加予定者への連絡を分担しました。交流会は開催できましたが、参加者は目標に届きませんでした。結果と原因の候補を分けて報告し、三者の条件と決めた順番を引き継ぎ資料に残しました。相手ごとに前提が違うことを先に確かめる大切さを学びました。

## 何を改善したか

修正前でも調整経験は伝わりますが、「調整した」という事実が中心でした。修正後は、まず相手ごとに**変更できない条件／相談できる条件を確認した**ことを明確にし、その情報から本人が代替案を設計した流れを強めました。さらに直前変更では「安全に開催することを優先した」と判断基準を追加しています。これにより、単なるコミュニケーション経験ではなく、制約整理・優先順位・合意形成という再現可能な行動として説明できます。

## 改善版ガクチカ

> 学生団体の留学生交流会で、大学、留学生団体、学外会場の三者調整を担当しました。準備を始めると、大学は参加者名簿の事前提出、留学生側は宗教上の食事配慮と当日参加、会場は早期の人数確定を求め、条件が両立しないことが分かりました。私はまず三者に「変更できない条件」と「相談できる条件」を確認し、一覧表にしました。その上で、事前登録者には食事を用意し、当日参加枠は食事なしで別に設ける案を作り、三者から合意を得ました。さらに開催1週間前に会場の人数上限が変更された際は、安全に開催することを優先し、当日枠を縮小する案を代表に提案しました。参加者数は目標に届きませんでしたが、行事は条件を守って実施できました。終了後は、判断の経緯と各者の条件を引き継ぎ資料に残しました。この経験から、調整では説得を急ぐより、相手ごとの制約を先に可視化すると合意点を見つけやすいと学びました。

## この例の強いところ

三者の利害が具体的で、「話し合った」ではなく条件を分解した判断が見えます。本人が代替案を作り、直前の変更でも優先順位を決めています。目標未達も隠さないため、面接で判断の質を深掘りできます。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| 留学生と日本人学生の共同イベントを運営する | 異なる前提・文化・要望の調整を経験できる |
| 学園祭で複数団体の場所・時間を調整する | 限られた資源を配分する判断が生まれる |
| 協賛企業を探し条件交渉する | 相手の利益を考えた提案を経験できる |
| 地域商店と学生の共同企画を作る | 学外の相手との約束・期限・調整を経験できる |
| サークル合宿の交通・宿・予算を再設計する | 複数制約から実行案を作る練習になる |
| フードロス削減企画で店舗と学生をつなぐ | 社会課題と現場条件を結びつけられる |
| 海外大学とのオンライン交流を企画する | 時差・言語・目的の違いを調整できる |
| 学生団体の仕入先を比較・変更する | 価格・品質・納期を同時に考えられる |
| 寄付企画の使途と運営ルールを整える | 信頼、透明性、関係者調整を経験できる |
| ゼミ共同研究で役割と締切を再設計する | 身近な場でも交渉と合意形成を作れる |

## 進め方

関係者ごとに「目的」「譲れない条件」「相談可能な条件」「期限」を1枚にまとめます。自分の案を出す前に相手の条件を聞きます。

案はA案・B案を作り、費用、時間、リスク、相手への影響を比べます。誰が何を理由に選んだかも記録します。終了後は、断念した案、想定外の変更、目標未達の理由も残します。海外経験そのものより、複数の利害を扱った深さを重視します。

## 面接で深掘りしたい質問

1. 最も調整が難しかった相手は誰で、なぜですか。
2. 自分の案に反対されたら、どの条件を変えるつもりでしたか。
3. なぜ当日参加枠を優先して削ったのですか。
4. 目標人数に届かなかった原因のうち、自分の改善余地は何ですか。
5. 次回なら準備のどの時点で何を変えますか。

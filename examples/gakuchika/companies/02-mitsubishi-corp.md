## 採用選考で見られそうなBig Fiveの読み替え

ブログ記事の「採用選考で見られそうなBig Five」は、三綱領・文理不問のポテンシャル採用・AI面接と3回面接という選考構造から令和就活ラボが立てた**予想**です。記事は開放性・誠実性・外向性・協調性・情緒安定性のすべてを高めに読み、「利害の違う人をどうまとめ、判断に責任を持ったか」を具体例で示すことを勧めています。

この教材では、その予想を「文章のどこを詳しく書くか」の補助線として使います。

| 記事の予想 | この例で詳しく書く場面 |
| --- | --- |
| 協調性・外向性（利害を調整し、言語化する） | F3で、三者それぞれの制約を聞き取り、代替案を自分の言葉で説明したこと |
| 情緒安定性（不確実な状況で判断する） | F3からF4で、開催直前に会場条件が変わった際に、何を優先して決めたか |
| 誠実性（判断に責任を持つ） | F4で、目標に届かなかった結果を隠さず報告し、引き継ぎ資料を残したこと |
| 開放性（未知のテーマを学ぶ） | F2で、相手ごとに違うルールや前提を調べたこと |

企業が公表した合否基準ではなく、性格を偽るためのものでもありません。本人の材料を会社の人物像に合わせて作り替えず、本人のBig Fiveを点数化しません。本人の傾向を整理するときは[参考自己分析](../../../docs/self-analysis.md)の表示方法に従います。

## 架空の材料

以下は文章作成のために置いた架空の実施済み設定です。現物の原記録・調査データはありません。「読めた実資料」として報告せず、このページの設定だけを参照します。

| 材料 | 架空の事実・当時の考え・振り返り |
| --- | --- |
| F1 | 大学2年の2025年9〜12月。学生団体の留学生交流会で渉外担当（代表ではない。運営は6人）。大学の国際課、留学生の学生団体、学外の会場の三者と条件を調整する役割だった。 |
| F2 | 国際課は参加者名簿の事前提出、留学生団体は宗教上の食事配慮と当日参加の受け入れ、会場は人数の確定期限を求め、三者の条件が両立しなかった。本人は各者の規程や前年の記録を調べ、譲れない点と調整できる点を分けて書き出した。 |
| F3 | 本人が「事前登録枠と当日枠を分け、当日枠は食事なしの参加とする」案を作り、三者に順に説明して合意を得た。開催1週間前に会場から人数上限の変更が伝えられ、本人は当日枠を減らす判断を代表に提案し、参加予定者への連絡を分担した。 |
| F4 | 交流会は開催できたが、参加者は目標に届かなかった。本人は結果と原因の候補（周知が遅れたこと、当日枠を減らしたこと）を分けて団体に報告し、三者の条件と決めた順番を引き継ぎ資料にまとめて翌年度の担当へ渡した。相手ごとに前提が違うことを先に確かめる大切さを学んだ。 |

## 材料から文章にする

結論・動機＝F1 → 条件の食い違いと調べたこと＝F2 → 本人の案と直前の判断＝F3 → 結果・報告・引き継ぎと学び＝F4。

## 架空の文章

学生団体の留学生交流会で、条件の食い違う三者の調整に力を入れました。渉外担当として大学の国際課、留学生の団体、学外の会場と話すと、名簿の事前提出、食事への配慮と当日参加の受け入れ、人数確定の期限が両立しませんでした。私は各者の規程と前年の記録を調べ、譲れない点と調整できる点を分けて書き出し、事前登録枠と当日枠を分ける案を作って三者に順に説明し、合意を得ました。開催1週間前に会場の人数上限が変わった際は、当日枠を減らす判断を代表に提案し、参加予定者への連絡を分担しました。交流会は開催できましたが、参加者は目標に届きませんでした。結果と原因の候補を分けて報告し、三者の条件と決めた順番を引き継ぎ資料に残しました。相手ごとに前提が違うことを先に確かめる大切さを学びました。

## 面接で確かめる質問

会社の公式情報（三綱領・文理不問）と、ブログが予想した面接の話題（力を入れたことの深掘り、志望する事業と社会課題、価値観を問う質問）に寄せた質問です。会社が実際に聞く質問ではありません。

2. 会場の条件が変わったとき、何を優先し、何をあきらめましたか。その判断に代表はどう答えましたか。

# キーエンスを想定したガクチカ例

想定職種: **ビジネス職（営業）**

企業研究: [令和就活ラボ・キーエンス](https://risan.jpn.org/?p=13328) ／ 基本例: [メーカー](../02-manufacturing.md)

## この会社・職種で意識したい経験

営業職を想定するなら、**感覚で語られている問題を数字で捉える → 原因の仮説を立てる → 小さく試す → 結果が出なければ次の仮説へ進む**経験が話しやすいです。「数字に強い」と書くより、何を測り、どの結果を見て考えを変えたかを具体的にします。

## 修正前のガクチカ

> ボードゲームサークルの新歓を数字で見直すことに力を入れました。前年は体験会の参加者が多いのに入会が少なく、原因は知名度だと語られていました。広報担当の私は、人を集めれば入会するという前提を疑い、体験会ごとに参加者数、入会申込数、途中で帰った時間帯を記録することを提案しました。すると、参加者が多い日ほど説明が長くなり、途中で帰る人が増えていました。そこで説明を短くしましたが、最初の二回は数字が動きませんでした。次に、体験の最初から少人数の卓に分ける方法を試しました。入会申込は前年より増えましたが、新入生の総数も増えたため、変更の効果とは言い切れませんでした。

## 何を改善したか

修正前にも数字と試行錯誤はありますが、出来事が多く、**何を疑い、どの数字を見て次の打ち手を変えたか**が埋もれていました。改善版では「集めた後の体験に問題があるのでは」という本人の仮説を明示し、最初の施策で数字が動かなかったため次へ進んだ判断を中心にしました。最後も、入会者増を自分の施策の成果と断定しない構成にしています。

## 改善版ガクチカ

> ボードゲームサークルの新歓で、参加者は多いのに入会が少ない原因を数字で見直しました。運営では知名度不足が原因と考えられていましたが、私は「集めた後の体験に問題があるのでは」と考え、体験会ごとの参加者数、途中退出の時間、入会申込数を記録しました。すると、参加者が多い回ほど説明が長く、途中退出が増えていました。そこで説明を短くしましたが数字は動かなかったため、次は開始直後から少人数の卓に分けました。入会申込は前年より増えましたが、新入生全体も増えていたため、施策だけの効果とは断定しませんでした。この経験から、感覚で語られる課題を測れる指標に変え、結果が出なければ仮説を修正することを学びました。

## この例の強いところ

周囲の「知名度不足」という説明をそのまま受け入れず、別の仮説を立てています。一度の施策を成功談にせず、数字が動かなかったため次の方法へ進んでいます。因果関係を言い切らない点も、判断の精度を説明しやすい材料です。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| 新歓の参加→入会率を改善する | 集客数と入会率を分けて考えられる |
| SNS投稿ごとの反応を測る | 数字から仮説を立て直しやすい |
| イベント申込後の欠席を減らす | 申込数だけでなく離脱原因を考えられる |
| アンケート回答率を上げる | 方法を変えて前後比較しやすい |
| 学園祭販売の声かけ方法を比較する | 相手の反応を数字で確認できる |
| 予約キャンセルの理由を分析する | 表面の数字から原因へ掘り下げられる |
| 募金の案内方法を比較する | 短期間で複数の方法を試せる |
| 説明会の導線を改善する | 人の行動を観察して改善できる |
| アルバイトの注文漏れを減らす | 現場の問題を測定可能な形にできる |
| 学内サービスの利用率を改善する | 利用前後の行動を追いやすい |

## 進め方

まず「悪い」「少ない」と感覚で言われている問題を一つ選び、何を数えれば状態を説明できるか決めます。原因候補を複数出し、一度に全部を変えず、一つの施策を試して同じ指標を測ります。

結果が動かなければ、どの仮説が弱くなったのかを書き残します。数字が改善しても、季節・母集団・別施策など他の要因がないか確認し、言えることと言えないことを分けます。

## 面接で深掘りしたい質問

1. なぜ「知名度不足」ではない可能性を考えたのですか。
2. 途中退出の時間を記録しようと思った理由は何ですか。
3. 最初の施策で数字が動かなかったとき、何を考えましたか。
4. 入会申込が増えたのに、なぜ施策の効果と言い切らなかったのですか。
5. 翌年なら、どんな比較をすれば効果をより確かめられますか。

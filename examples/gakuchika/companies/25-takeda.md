## この会社・職種で意識したい経験

この職種を想定するなら、**相手の困りごとを先に聞く → 持っている情報を相手に合わせて選び直す → 届いたかを数字で確かめる → 届かなかった相手にもう一度方法を変える**経験が話しやすいです。公式の募集要項は総合職に「知的好奇心が強く、創造的で、やり遂げるまで諦めない粘り強さのある方」を求め、必須条件にAI・データの学習経験を置いています。

## 修正前のガクチカ

> 大学のオープンキャンパスで、学科の相談ブースを担当したことに力を入れました。前年の記録を見ると、来場者の多くが「この学科で何ができるか」より「入試の科目」を聞いて帰っていて、学科の説明が終わる前に席を立つ人が多いと書いてありました。私は説明の原稿を短くする案を出しましたが、先輩からは学科の内容を減らすと意味がないと言われました。そこで、まず来場者が最初に聞いた質問を1日分メモに取り、入試の質問が6割、学びの内容が3割、就職が1割だと分かりました。説明を「入試→学びの内容→卒業後」の順に組み替え、入試の情報は1枚の紙にして先に渡すようにしました。午後の回では席を立つ人が減り、質問が学びの内容に移りました。ただ、保護者だけで来た人には学科の話が届きにくかったので、翌日は保護者向けに費用と就職の紙を加えました。相手が何を知りたいかを先に聞いてから、持っている情報の順番を変えることの大切さを学びました。

## 何を改善したか

修正前でも工夫は伝わりますが、本人の判断が出来事の説明に埋もれていました。改善版では、反対された後に「原稿を削る」のではなく「相手の質問を記録して順番を変える」へ切り替えた判断を中心にし、効果を数字で確かめたこと、届かなかった相手（保護者だけの来場者）にもう一度方法を変えたことを明確にしています。

## 改善版ガクチカ

> 大学のオープンキャンパスで、学科相談ブースの説明を作り直しました。前年の記録では、来場者が入試の科目だけを聞いて席を立つことが多く、学科の説明が届いていませんでした。私は原稿を短くする案を出しましたが、先輩から内容を減らすと意味がないと言われました。そこで来場者が最初にした質問を1日分記録すると、入試が6割、学びの内容が3割でした。説明の順番を「入試→学びの内容→卒業後」に組み替え、入試の情報は紙にして先に渡しました。午後の回では途中で席を立つ人が減り、質問が学びの内容に移りました。保護者だけの来場者には届きにくかったため、翌日は費用と就職の紙を加えました。相手が知りたいことを先に聞き、持っている情報を選び直してから届けることを学びました。

## この例の強いところ

説明を上手にした話ではなく、相手の質問を記録してから情報の順番を変えています。効果を「席を立つ人が減った」「質問が変わった」という観察で確かめ、届かなかった相手に翌日もう一度方法を変えています。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| 説明会の相談ブースを改善する | 相手の質問を記録して情報の順番を変えられる |
| 学習支援の教え方を相手ごとに変える | 同じ内容を相手に合わせて届ける練習になる |
| 新入生向け案内の配布物を作り直す | 読まれなかった理由を聞いて直せる |
| サークルの勧誘の説明を見直す | 断られた相手の理由を集められる |
| アルバイト先の商品説明を改善する | 相手の困りごとから説明を選び直せる |
| 研究室の発表資料を聞き手別に作る | 専門家と初学者で情報を変える経験になる |
| アンケートの質問順を見直す | 回答率の変化で効果を確かめられる |
| 地域イベントの受付案内を改善する | 来場者の動きを観察して直せる |
| 留学生向けの生活情報をまとめる | 相手の国や状況で必要な情報が違うと分かる |
| 相談記録を集計して傾向を出す | 記録と数字から次の一手を決められる |

## 進め方

相手に説明する前に、相手が最初に聞いたことや困っていることを記録します。持っている情報を減らすのではなく、相手ごとに順番と出し方を変えます。

変えた後は、相手の反応を観察して効果を確かめます。届かなかった相手がいたら、その相手に合わせてもう一度方法を変え、何を変えたかを残します。

## インターンシップの時期・応募準備

武田薬品の2027年度新卒採用は職種ごとに応募時期が大きく違い、総合職は2025年12月1日、研究技術職は2026年6〜8月が締切でした（公式募集要項・2026-10-01確認）。応募年度の締切・設問・AI利用条件は、公式の募集要項で確認する必要があります。

## 面接で深掘りしたい質問

1. なぜ原稿を短くする案をやめて、質問を記録することにしたのですか。
2. 記録した質問の割合は、どうやって数えましたか。
3. 席を立つ人が減ったことは、何を見て判断しましたか。
4. 保護者だけの来場者に届かなかった理由は何だと考えましたか。
5. 相手の知りたいことが自分の伝えたいことと違うとき、どちらを優先しますか。

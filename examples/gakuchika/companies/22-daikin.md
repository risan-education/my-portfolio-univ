# ダイキン工業を想定したガクチカ例

> 教材の架空例です。本人の記録ではなく、活動実績にも数えません。（作成日 2026-10-01）

想定職種: **技術職コース（研究開発・設計開発）**

基本例: [メーカー](../02-manufacturing.md)

## この会社・職種で意識したい経験

この職種を想定するなら、**ばらつきの原因を一つに絞る → 条件を変えて測り直す → 反対された相手に結果を見せる → 残った課題も報告する**経験が話しやすいです。

## 修正前のガクチカ

> 機械工学の学生実験で、熱交換器の性能測定のばらつきを減らすことに力を入れました。四人の班で小型の熱交換器に水を流し、入口と出口の温度差から熱の伝わりやすさを計算する実験でしたが、同じ条件のはずの三回の測定で結果が二割近く違いました。私は測定の手順を見直し、配管の温度計を差し込む深さと、水を流し始めてから測り始めるまでの待ち時間が毎回違うことに気づきました。班員は時間が足りないので早く次の条件に進みたいと言いましたが、私は待ち時間を五分に固定し、温度計の位置をテープで印を付けて固定する案を出し、まず一条件だけ三回測り直して差が五パーセント以内に収まった結果を見せました。班はこの手順で残りの条件も測り直し、レポートでは手順を変える前と後の結果を両方載せました。流量が小さい条件では差が残ったので、原因の候補を書いて提出しました。原因を一つに絞って確かめる大切さを学びました。

## 何を改善したか

修正前でも手順改善は伝わりますが、気づいたことと実行したことが同じ重さで並び、本人の判断が埋もれていました。改善版では、ばらつきの原因を「待ち時間と温度計の位置」の2つに絞った判断と、班員に反対された後に**一条件だけ測り直して結果で示した**流れを中心にしました。流量が小さい条件で差が残った点は、言い切らずに残しています。

## 改善版ガクチカ

> 機械工学の学生実験で、熱交換器の性能測定のばらつきを減らしました。同じ条件の3回の測定で結果が2割近く違ったため手順を見直し、温度計を差し込む深さと、水を流してから測るまでの待ち時間が毎回違うことに気づきました。班員は時間が足りないと反対しましたが、私は待ち時間を5分に固定し温度計の位置に印を付け、まず1条件だけ3回測り直しました。差が5%以内に収まった結果を見せると、班は残りの条件も同じ手順で測り直しました。流量が小さい条件では差が残ったため、原因の候補を分けてレポートに書きました。ばらつきは急いで測り直すより、原因を絞って条件を固定し、小さく確かめてから周りに示すことで減らせると学びました。

## この例の強いところ

ばらつきを運のせいにせず、原因を2つに絞って手順を固定しています。反対された後に議論を続けるのではなく、1条件だけ測り直して結果で示しています。残った差を言い切らず、次の課題として書いています。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| 実験の測定条件をそろえ直す | 再現性を高める判断と手順の固定を経験できる |
| 温度・流量などの計測誤差を減らす | 原因を分けて確かめる型が作れる |
| 部活の練習メニューを数字で見直す | 条件を変えて効果を比べられる |
| 工作・ロボット製作で試作をやり直す | 失敗の原因を一つに絞る練習になる |
| 省エネの工夫を家や部室で試す | 身近なテーマで前後比較ができる |
| 装置の組み立て手順書を作る | 人が入れ替わっても同じ結果が出るかを確かめられる |
| 研究室の計測データを整理する | ばらつきの傾向を見つける目が育つ |
| 他学科と組んで装置を作る | 専門の違う相手との議論を経験できる |
| 海外の学生と共同で課題に取り組む | 言葉が違う相手に根拠で示す経験になる |
| うまくいかなかった実験を報告する | 残った課題を分けて書く力が付く |

## 進め方

ばらつきが出たら、まず「何が毎回違うか」を2〜3個に絞り、1つずつ固定して測り直します。全部をやり直す前に、1条件だけ試して結果を残します。反対する人には議論ではなく測り直した数字を見せ、残った差は原因の候補ごとに分けて報告します。

## 面接で深掘りしたい質問

1. なぜ待ち時間と温度計の位置の2つに絞ったのですか。
2. 班員に反対されたとき、なぜ1条件だけ測り直す案にしたのですか。
3. 差が5%以内に収まったことをどう確認しましたか。
4. 流量が小さい条件で差が残った原因は何だと考えますか。
5. 次に同じ装置を使うなら、最初に何を固定しますか。

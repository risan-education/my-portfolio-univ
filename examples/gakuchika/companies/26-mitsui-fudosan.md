# 三井不動産を想定したガクチカ例

> 教材の架空例です。本人の記録ではなく、活動実績にも数えません。（作成日 2026-10-01）

想定職種: **総合職**

基本例: [鉄道・交通インフラ](../08-infrastructure.md)

## この会社・職種で意識したい経験

この職種を想定するなら、**立場の違う人たちの要望がぶつかる場面で、一人ひとりの事情を先に聞く → 両方が使える案を作る → 反対された後に一度直す → 続く仕組みにして渡す**経験が話しやすいです。公式採用サイトの人事メッセージは「"人となり"を大切にしている」「相手の声に耳を傾け、心を通わせていくこと」と書き、有価証券報告書は「徹底的な顧客志向」「個よりチームの成果を重要視」を大切にしている価値観として挙げています。

## 修正前のガクチカ

> サークル連合の役員として、大学の空き教室の使い方を変えたことに力を入れました。放課後の空き教室は先着順の予約で、大きな団体が週の前半にまとめて押さえるため、小さな団体や新しくできた団体は練習場所が取れず、連合に不満が集まっていました。私は役員として各団体に話を聞き、大きな団体は「人数が多いので広い教室が本番前に必要」、小さな団体は「毎週同じ曜日に短時間使えれば十分」、学生課は「鍵の受け渡しが増えるのは困る」と言っていました。そこで広い教室は週2日を本番前の団体が申し込む枠、残りを曜日固定で小さな団体が使う枠に分け、予約状況を掲示板とオンラインで公開しました。ところが始めてみると、固定枠を取ったまま使わない団体が出て、別の団体から「空いているのに使えない」と言われました。使わない週は前日までに手放すルールを足し、手放した枠を誰でも取れるようにすると、空き教室の利用率が上がりました。手順書を次の役員に渡しました。相手ごとの事情を聞いてから案を作ること、始めた後に直すことを学びました。

## 何を改善したか

修正前でも調整の経験は伝わりますが、本人が誰の声を最初に聞き、何を自分で決めたのかが出来事の中に埋もれていました。改善版では、三者（大きな団体・小さな団体・学生課）の事情を先に聞いて「枠を分ける」と決めたこと、始めた後に出た「取ったまま使わない」問題に対して前日返却のルールを足して一度直したこと、次の役員に続く仕組みとして渡したことを中心にしました。利用率の数字は本人が数えられる範囲にとどめ、作っていません。

## 改善版ガクチカ

> サークル連合の役員として、大学の空き教室の予約を使いやすくしました。先着順の予約では大きな団体が週の前半に広い教室を押さえ、小さな団体は練習場所が取れずにいました。私は各団体と学生課に事情を聞き、大きな団体は本番前に広い教室が必要、小さな団体は毎週同じ曜日に短時間使えればよい、学生課は鍵の受け渡しを増やしたくないと分かりました。そこで広い教室を本番前の団体が申し込む週2日の枠と、小さな団体の曜日固定枠に分け、予約状況を掲示板とオンラインで公開しました。始めると固定枠を取ったまま使わない団体が出て、別の団体から不満が出たため、使わない週は前日までに手放すルールを足し、手放した枠は誰でも取れるようにしました。手順書を次の役員に渡しました。相手ごとの事情を先に聞いて案を作り、始めた後に一度直すことが、全員が使える仕組みを作るうえで重要だと学びました。

## この例の強いところ

不満を言う側だけでなく、大きな団体と学生課の事情も先に聞いたうえで枠を分けています。始めた後に新しい問題が出たとき、ルールを一つ足して直し、次の役員に続く形で渡しています。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| 空き教室や共用スペースの予約を改善する | 立場の違う利用者の事情を聞いて枠を分ける経験ができる |
| 学園祭の出店場所の割り振りを決める | 人の流れと店ごとの事情を同じ図の上で考えられる |
| 部室や倉庫の使い方のルールを作る | 使う人と管理する人の両方の声を聞ける |
| 地域の商店街イベントで店と来場者をつなぐ | 店の売上と来場者の楽しさを両立させる調整を経験できる |
| サークルの合宿先の宿と日程を決める | 予算・人数・宿の条件を折り合わせられる |
| 駅前や校内の人の流れを数えて改善案を出す | 観察から案を作る練習になる |
| 空き店舗や空き地の使い方を提案する | 持ち主・使う人・近所の三者の立場を想像できる |
| 新入生向けの案内所や掲示を作り直す | 利用者が迷う場所を見つけて直す経験ができる |
| 複数団体の合同イベントの会場と時間を調整する | 譲れないことを聞いて順番を決められる |
| 予約や当番の仕組みをオンラインで見える化する | 始めた後に出る問題を直す経験ができる |

## 進め方

関係する相手（よく使う人・たまに使う人・管理する人）ごとに、困っていることと譲れないことを先に聞いて記録します。全員に同じルールを出す前に、場所や時間を分けて選べる形にできないかを考えます。

始めた後に出た問題は「誰が、何に困ったか」を残します。ルールを足して直した場合は、直す前と後で何が変わったかを本人が数えられる範囲で書いておくと、面接で説明しやすくなります。

## インターンシップの時期・応募準備

三井不動産の新卒採用（総合職）は、2027年4月入社の場合、2025年12月にエントリー受付が始まり、2026年1月にエントリーシートと適性検査（2種類）の締切、その後に個人面談3回（一次はオンライン、二次・最終は東京で対面）という日程でした。インターンシップ・キャリアイベントの日程と選考は年度で変わるため、公式採用サイトで確認する必要があります。他社の実施時期・応募時期・テスト内容の見方は、[インターンシップ時期・応募・選考一覧](../../../docs/internship-timeline-and-strategy.md)にまとめています。

## 面接で深掘りしたい質問

1. 三者の事情を聞いたとき、最初に誰の話を聞きましたか。なぜですか。
2. 先着順をやめて枠を分けると決めたのは、どの事情を優先した判断ですか。
3. 固定枠を取ったまま使わない団体が出たとき、ルールを足す以外に考えた案はありますか。
4. 次の役員に渡した手順書には、何を書きましたか。
5. 三菱地所や住友不動産ではなく三井不動産を選ぶ理由を、この経験とつなげて話せますか。

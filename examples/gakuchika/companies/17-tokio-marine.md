# 東京海上日動を想定したガクチカ例

想定職種: **総合職**

基本例: [教育・学習支援](../09-education.md)

## この会社・職種で意識したい経験

この職種を想定するなら、**結果が出ない状況で相手の不安を聞く → 変えられない条件と変えられる条件を分ける → 小さな改善を続ける → 関係を維持する**経験が話しやすいです。

## 修正前のガクチカ

> 個別指導塾のアルバイト講師として、中学三年生一人を一年間担当し、保護者との面談を続けることに力を入れました。成績が伸びず保護者が塾に不信感を持っていたため、教室長に相談して毎月の面談を自分から申し出ました。初回の面談で、家庭では宿題の時間が取れない曜日があること、保護者が塾で何をしているか分からないと感じていることが分かりました。授業時間と宿題の量の規定は変えず、宿題を曜日ごとに分けて出し、毎回の授業内容を一枚の記録にして保護者に渡し、教室長と他の講師に相談して苦手な単元の順番を組み直しました。成績は一部の科目で上がりましたが、志望校の判定は年度末まで変わりませんでした。それでも面談を続け、保護者からは何をしているかは分かるようになったと言われました。規定を守りながら変えられる部分を探すこと、結果が出ない期間こそ相手と会い続けることを学びました。

## 何を改善したか

修正前は学習計画の工夫が中心に見えました。改善版では、保護者の不信感を成績だけの問題とせず、面談から「塾で何をしているか分からない」ことも原因だと捉え直した点を中心にしました。学習成果が十分に伸びなかった結果も残し、成果が出ない期間に関係を続けた行動を明確にしています。

## 改善版ガクチカ

> 個別指導塾で中学3年生一人を1年間担当し、学習成果が伸びない期間も保護者との対話を続けました。保護者が塾に不信感を持っていたため、私は教室長に相談し毎月の面談を申し出ました。話を聞くと、家庭では宿題時間を取れない曜日があり、塾で何をしているか分からないことも不安の原因でした。授業時間や宿題量の規定は変えず、曜日別に宿題を分け、毎回の授業内容を記録して渡しました。一部の学習成果は改善しましたが、年度末まで目標水準には届きませんでした。それでも面談を続け、保護者から「何をしているか分かるようになった」と言われました。結果がすぐ出ないときほど、相手の不安を聞き、変えられる部分を探して関係を続けることを学びました。

## この例の強いところ

華やかな成果ではなく、結果がすぐ出ない相手と1年間関わっています。規定上変えられない条件を守りながら、宿題の出し方や情報共有など変えられる部分を探し、相手の不安を減らしています。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| 長期の学習支援を行う | 成果が出ない期間も関係を続ける経験になる |
| 保護者面談を改善する | 本人以外の関係者の不安も理解できる |
| 新人のメンターを担当する | 成長速度に合わせた支援を考えられる |
| 学生相談窓口を手伝う | 曖昧な不安を具体化する経験になる |
| 地域高齢者を継続支援する | 長期関係の中で変化を観察できる |
| 外国人生活支援を行う | 制度上変えられない条件と代替策を考えられる |
| 顧客の継続フォローを改善する | 短期成果だけでなく信頼を記録できる |
| 寄付者対応を改善する | 説明責任と関係維持を経験できる |
| 後輩のキャリア支援をする | 相手自身の意思決定を支える経験になる |
| チーム面談を改善する | 表面化していない不安を聞き取れる |

## 進め方

成果指標だけでなく、相手が何を不安に感じているかを定期的に聞きます。制度・時間・予算など変えられない条件と、説明・順番・頻度など変えられる条件を分けます。結果が出ない期間も記録を止めず、目標未達と次に変える点まで整理します。

## 面接で深掘りしたい質問

1. 保護者の不信感の原因をどう確認しましたか。
2. なぜ毎月の面談を続けたのですか。
3. 変えられない条件と変えられる条件をどう分けましたか。
4. 目標水準に届かなかったことをどう評価しますか。
5. 同じ生徒をもう1年担当するなら何を変えますか。

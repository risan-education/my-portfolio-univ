# 味の素を想定したガクチカ例

想定職種: **R&D職**

基本例: [メーカー](../02-manufacturing.md)

## この会社・職種で意識したい経験

この職種を想定するなら、**慣例に疑問を持つ → いきなり全体を変えず小さく試す → 結果を示す → 周囲を巻き込む → 検証の限界も残す**経験が話しやすいです。

## 修正前のガクチカ

> 食品化学の研究室で、官能評価のばらつきを減らす手順を提案し、続けることに力を入れました。だしの塩味の感じ方を調べる課題研究で、評価の結果が評価者や日によって大きくばらつき、試料の提示順と温度、前の試料からの間隔が評価者ごとに違うことに気づきました。手順をそろえる提案は、先輩から時間がかかると最初は受け入れられませんでした。そこで自分の担当分だけで、提示順を無作為にして温度と間隔を記録する小さな試行を二週間行い、ばらつきが減った結果を見せました。手順は研究室で採用され、評価者を増やすために他の研究室の学生五人に手順書を渡して協力を頼みました。ばらつきは減りましたが、比べたかった二つの試料の差は人数では有意とは言えませんでした。報告会では手順の効果と言えないことを分けて説明し、必要な人数の見積もりを残しました。当たり前のやり方に疑問を持ち、小さな試行で示してから周りを巻き込むことを学びました。

## 何を改善したか

修正前は研究手順を改善した出来事が詳しく書かれていましたが、反対を受けてからどう進め方を変えたかが埋もれていました。改善版では、手順統一への反対に対して議論を続けるのではなく、**自分の担当分だけで小さく試し、結果を示してから協力者を増やしたこと**を中心にしました。人数不足で試料差を言い切れない点も残しています。

## 改善版ガクチカ

> 食品化学の研究室で、官能評価のばらつきを減らす手順改善に取り組みました。評価者や日によって結果が大きく異なり、提示順、温度、試料間隔が統一されていないことに気づきました。手順統一を提案しましたが、先輩から時間がかかると反対されました。そこで自分の担当分だけで2週間、提示順を無作為化し、温度と間隔を記録しました。ばらつきが減った結果を示すと手順が採用され、他研究室の学生5人にも協力を依頼できました。一方、比較した2試料の差は人数不足で有意とは言えませんでした。慣例を変えるときは主張だけでなく、小さく試して根拠を示してから周囲を巻き込むことを学びました。

## この例の強いところ

慣例を否定するだけでなく、反対された後に実行可能な小さな試行へ切り替えています。結果を示してから他研究室まで協力を広げる一方、統計的に言えないことは言い切っていません。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| 官能評価のばらつきを減らす | 人による評価差を条件設計で扱える |
| 実験結果のばらつきを減らす | 再現性を高める手順改善を経験できる |
| 食品保存条件を比較する | 温度・時間など条件を分けて検証できる |
| 調理条件を比較する | 身近なテーマで反復実験できる |
| アンケート設計を改善する | 質問順や表現の影響を検討できる |
| 研究手順を標準化する | 慣例を検証可能な手順へ変えられる |
| 小規模な予備実験を行う | 大きく変える前に根拠を作れる |
| 共同研究の役割を調整する | 専門の違う相手を巻き込める |
| 文献の再現実験をする | 既報との差から新しい仮説を作れる |
| 必要サンプル数を検討する | 結果を言い切るために必要な条件を考えられる |

## 進め方

慣例に疑問があっても、最初から全員へ変更を求めず、自分の担当範囲で比較できる小さな試行を作ります。変更前後を同じ指標で比べ、結果を共有してから協力者を増やします。

改善したことと、本来知りたかった研究結果を分けます。サンプル数などの限界があれば明示し、次に必要な検証を残します。

## 面接で深掘りしたい質問

1. なぜ提示順・温度・間隔に注目したのですか。
2. 先輩に反対されたとき、なぜ小さな試行へ切り替えたのですか。
3. ばらつきが減ったことをどう確認しましたか。
4. 試料差を有意と言えなかった理由は何ですか。
5. 次に協力者を増やすなら、何を標準化しますか。

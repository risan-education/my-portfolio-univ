# 商船三井を想定したガクチカ例

想定職種: **陸上職（事務系）**

基本例: [鉄道・交通インフラ](../08-infrastructure.md)

※架空の学生の例です。本人の実績には数えません。作成日: 2026-10-01。

## この会社・職種で意識したい経験

この職種を想定するなら、**人手も時間も足りない場面で自分の持ち場を決める → 相手の違う人たちと手順をそろえる → 安全の線を引く → 途中の問題を自分で引き受けて直す**経験が話しやすいです。公式採用サイトは「自律自責型の素養を持つ人財」を求めると書き、行動規範には「自律自責」「TEAMWORK」「SAFETY」があります。

## 修正前のガクチカ

> 学園祭の実行委員で、物品搬入の進行を担当したことに力を入れました。前年は搬入日に業者のトラックと各団体の車が同じ時間に集まり、通路がふさがって開始が遅れたと聞きました。私は搬入係として、業者と団体に時間を指定する案を出しましたが、団体からは授業の都合で時間を守れないという声があり、業者からは荷降ろしの場所が決まっていないと動けないと言われました。そこで荷降ろし場所を3か所に分け、場所ごとに担当を置き、団体には時間帯を2つ用意して選んでもらう形に変えました。当日は雨で予定していた場所の1つが使えなくなりましたが、担当と相談して屋根のある通路側に変更し、台車の通り道に人が入らないようロープを張りました。遅れは30分ほどで収まり、けがもありませんでした。関係する人の事情を先に聞き、自分で決めた持ち場を最後まで持つことを学びました。

## 何を改善したか

修正前でも段取りの改善は伝わりますが、本人が何を自分で決めたのかが出来事の中に埋もれていました。改善版では、反対や事情を聞いたあとに「場所を分ける」「選べる時間帯を用意する」と自分で判断したこと、雨で予定が崩れた当日に自分の持ち場で原因を絞って変更したこと、人の通り道を先に分けた安全の線を中心にしました。

## 改善版ガクチカ

> 学園祭の実行委員で、物品搬入の遅れを減らしました。前年は業者と各団体の車が同時に集まり通路がふさがったと聞き、私は搬入係として時間指定の案を出しました。しかし団体からは授業で時間を守れない、業者からは荷降ろし場所が決まらないと動けないと言われました。そこで荷降ろし場所を3か所に分けて担当を置き、団体には2つの時間帯から選んでもらう形に変えました。当日は雨で1か所が使えなくなりましたが、担当と相談して屋根のある通路側に移し、台車の通り道にロープを張って人を入れないようにしました。遅れは30分で収まり、けがはありませんでした。相手ごとの事情を先に聞き、自分で決めた持ち場と安全の線を最後まで持つことが、全体を動かすうえで重要だと学びました。

## この例の強いところ

時間を守らせる話ではなく、相手ごとの事情を聞いたうえで場所と選択肢を自分で決めています。当日の雨という想定外にも、自分の持ち場で原因を絞って変更し、人の通り道を分ける安全の線を先に引いています。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| 物品搬入の進行を改善する | 相手の違う人たちの事情と時間の制約を扱える |
| 大会やイベントの会場設営を改善する | 場所・順序・担当を自分で決められる |
| 合宿の移動と荷物の手配をまとめる | 車両・人・荷物の組み合わせを考えられる |
| 部活動の用具管理を立て直す | 持ち場を決めて最後まで持つ経験ができる |
| 地域の清掃活動の安全手順を作る | 安全の線を先に引く練習になる |
| 文化祭の屋台の仕入れと在庫を管理する | 届く量と使う量のずれを調整できる |
| 留学生との共同イベントを運営する | 言葉や前提の違う相手と手順をそろえられる |
| 雨天など想定外の変更手順を作る | 当日の判断と原因の絞り込みを経験できる |
| 来場者の動線を設計する | 人と物の通り道を分ける考え方を学べる |
| 業者との打ち合わせを担当する | 外部の相手と条件を詰める経験ができる |

## 進め方

関係する相手（業者・団体・大学）ごとに、できないことと譲れないことを先に聞いて記録します。全員に同じ指示を出す前に、場所や時間を分けて選べる形にできないかを考えます。

当日の想定外は「誰が何を見て決めたか」を残します。安全に関わる判断（通り道・重い物・雨）は、遅れよりも優先した理由を書いておくと、面接で説明しやすくなります。

## インターンシップの時期・応募準備

商船三井のインターンは1day形式のオープンカンパニーが中心で、応募年度の日程と選考は公式採用サイトで確認する必要があります。他社の実施時期・応募時期・テスト内容の見方は、[インターンシップ時期・応募・選考一覧](../../../docs/internship-timeline-and-strategy.md)にまとめています。

## 面接で深掘りしたい質問

1. なぜ時間指定ではなく、場所を分けて選べる形に変えたのですか。
2. 団体と業者の事情を聞いたとき、どこまで譲ると決めましたか。
3. 雨で場所が使えなくなったとき、何を見て通路側への変更を決めましたか。
4. ロープを張る判断は、誰に相談しましたか。
5. 日本郵船や川崎汽船ではなく商船三井を選ぶ理由を、この経験とつなげて話せますか。

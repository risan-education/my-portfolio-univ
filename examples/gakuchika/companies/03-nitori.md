# ニトリを想定したガクチカ例

想定職種: **総合職（店舗マネジメント）**

企業研究: [令和就活ラボ・ニトリ](https://risan.jpn.org/?p=13317) ／ 基本例: [小売・流通](../05-retail.md)

## この会社・職種で意識したい経験

店舗や小売の仕事を想定するなら、**顧客や働く人の行動を観察し、現場の小さな不便を見つけ、仕組みにして改善する経験**が話しやすいです。

## 修正前のガクチカ

> 飲食店のアルバイトで、開店準備の抜けを減らすことに力を入れました。備品の補充や案内表示の抜けが日によって起き、初めは新人の不慣れが原因だと思っていましたが、観察すると長年のパートの方の手順も互いに違っていました。私は店長に準備チェック表の作成を提案し、パートの方には作業中に一つずつ理由を聞き、新人には分からなかった点を書き出してもらい、順番と確認欄を一枚にまとめて1か月試しました。抜けは減りましたが繁忙日には残ったため、起きた日と項目を記録して店長に報告し、繁忙日だけ確認を二人で行う形に直しました。相手の経験に合わせて聞き方を変えると本音が集まることを学び、次の学期に新人が入ったときも、この表を最初に渡しています。

## 何を改善したか

修正前はよくまとまっていますが、「抜けが減った」が中心で、問題発見のプロセスが短めでした。修正後は、最初に「新人の不慣れが原因」と考えたものの、**1週間観察して自分の仮説を修正した**という試行錯誤を強調しました。また、ベテランには理由、新人には迷った点を聞くという聞き分けを明示し、「人を責める前に仕事の流れを見る」という再現性のある学びに変更しました。

## 改善版ガクチカ

> 飲食店のアルバイトで、開店準備の抜けを減らす改善に取り組みました。備品補充や案内表示の準備漏れが週に何度か起きており、私は当初、新人の不慣れが原因だと考えていました。しかし1週間、準備の流れを観察すると、経験の長いスタッフ同士でも作業順と確認方法が異なることに気づきました。そこで店長に改善を提案し、ベテランには「なぜその順番なのか」、新人には「どこで迷ったか」を聞き、作業順と確認欄を1枚のチェック表にまとめました。1か月試すと通常日の漏れはほぼなくなりましたが、繁忙日には残りました。そこで発生した項目と時間帯を記録し、繁忙日だけ最後の確認を2人で行う方法に変更しました。私はこの経験から、問題を人の能力のせいにする前に、仕事の流れを観察し、誰でも実行できる仕組みに変えることの重要性を学びました。その後、新人が入るたびにチェック表を使いながら改善点を聞いています。

## この例の強いところ

「新人が原因」という最初の思い込みを観察で修正しています。ベテランと新人で質問を変え、チェック表を1か月試し、繁忙日に残った問題を再改善しています。個人の頑張りを再利用できる仕組みに変えた点も説明しやすいです。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| 品出し・開店準備の漏れを減らす | 現場観察と標準化を経験できる |
| 店内でよく聞かれる質問を減らす案内を作る | 顧客視点で課題を見つけられる |
| 新人が覚えにくい作業をマニュアル化する | 教える側・学ぶ側の両方を考えられる |
| 廃棄・食品ロスを記録して減らす | 数字で前後比較しやすい |
| レジ待ちが長い時間帯の原因を調べる | 時間帯・人員・動線を分析できる |
| サークル備品の収納場所を改善する | 身近な環境でも現場改善を経験できる |
| フリーマーケットの売場配置を改善する | 顧客行動を観察し配置を試せる |
| 大学祭模擬店の仕入れ量を改善する | 需要予測、欠品、余剰を考えられる |
| 学生向けレンタル品の貸出手順を改善する | 利用者と運営者双方の不便を扱える |
| 高齢者・子どもにも分かりやすい案内を試す | 多様な利用者を観察して改善できる |

## 進め方

まず「誰が困っているか」を決めます。顧客、新人、ベテラン、店長など、立場によって問題の見え方は違います。1週間程度、回数・時間帯・場所・作業者などを記録すると、印象だけで原因を決めにくくなります。

改善案は小さく試します。チェック表、表示、配置変更、声かけ方法など、すぐ戻せる方法から始め、試行前後で同じ指標を測ります。うまくいかなければ「誰にとって使いにくかったか」を聞き、もう一度直します。

## 面接で深掘りしたい質問

1. なぜ最初は新人が原因だと思ったのですか。
2. 観察して考えが変わった決定的な場面は何ですか。
3. ベテランと新人で質問を変えた理由は何ですか。
4. 繁忙日に漏れが残った原因をどう考えましたか。
5. 別の店舗なら、チェック表をそのまま使いますか。最初に何を確認しますか。

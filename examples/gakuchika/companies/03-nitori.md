## 業種・職種から考える着眼点

想定職種は総合職（店舗マネジメント）。この例では「経験の違う人が混ざる現場で、相手に合わせて聞き取り、手順を共有して改善を続けた過程」に着目します。上の公式情報と[小売・流通のガクチカ例](../05-retail.md)を参考にした教材独自の解釈です。業界共通の採用基準ではなく、実際の応募先の設問・職種で見直します。

## 採用選考で見られそうなBig Fiveの読み替え

ブログ記事の「採用選考で見られそうなBig Five」は、配転を前提とする育成方針・リクルーター面談・複数回面接・選考型インターンから令和就活ラボが立てた**予想**です。記事は協調性（多様な従業員がいる現場でチームを動かした経験）を特に高く、開放性（未知の配属を成長機会と捉える）を高く読み、誠実性・外向性・情緒安定性を続けています。

この教材では、その予想を「文章のどこを詳しく書くか」の補助線として使います。

| 記事の予想 | この例で詳しく書く場面 |
| --- | --- |
| 協調性（多様な人と現場を動かす） | F3で、パート従業員と新人それぞれに聞き方を変えて意見を集めたこと |
| 開放性（環境の変化を学びにする） | F1からF2で、自分より経験の長い人の手順を観察して違いに気づいたこと |
| 誠実性（改善を積み上げる） | F3からF4で、1か月試して記録し、抜けが残る日を確かめ続けたこと |
| 外向性（自分から働きかける） | F3で、店長へ提案した場面 |
| 情緒安定性（環境変化への適応） | F4で、繁忙日に抜けが残っても仕組みをやめずに直したこと |

企業が公表した合否基準ではなく、性格を偽るためのものでもありません。本人の材料を会社の人物像に合わせて作り替えず、本人のBig Fiveを点数化しません。本人の傾向を整理するときは[参考自己分析](../../../docs/self-analysis.md)の表示方法に従います。

## これから取り組むなら

問いの例: 「経験の違う人が同じ作業をするとき、何をそろえると抜けが減るか」。

アルバイトやサークルで、人によって結果が変わる作業を一つ選ぶ。誰がどう違うかを観察し、経験の長い人にも聞いてから、共有できる手順を一つ試す。

これは**未実施の計画例**です。実際に行ったことだけを原記録へ残します。下の実施済み設定が自動的に自分の経験になるわけではありません。

## 架空の材料

以下は文章作成のために置いた架空の実施済み設定です。現物の原記録・調査データはありません。「読めた実資料」として報告せず、このページの設定だけを参照します。

| 材料 | 架空の事実・当時の考え・振り返り |
| --- | --- |
| F1 | 大学2年の2025年10月〜2026年3月。飲食店のホールのアルバイト（リーダーではない）。開店準備を長年のパート従業員2人、新人アルバイト3人、本人で分担していた。 |
| F2 | 開店直後に備品の補充や案内表示の抜けが日によって起き、本人は「担当者ごとに準備の順番と確認の仕方が違う」と気づいた。当初は新人の不慣れが原因だと思っていたが、パート従業員の手順も互いに違っていた。 |
| F3 | 本人が店長に準備チェック表の作成を提案。パート従業員には作業中に一つずつ理由を聞き、新人には分からなかった点を書き出してもらい、順番と確認欄を一枚にまとめて1か月試した。表の置き場所と記入の担当は店長が決めた。 |
| F4 | 抜けは減ったが、繁忙日には残った。本人は抜けが起きた日と項目を記録して店長に報告し、繁忙日だけ確認を二人で行う形に直した。相手の経験に合わせて聞き方を変えると本音が集まることを学び、次の学期に新人が入ったときも表を最初に渡した。 |

実際の活動で残すとよい資料の例: チェック表、試行期間の記録、店長との相談メモ。売上や客数の増加、表彰の設定はない。これらの現物がこの教材に添付されているわけではありません。資料は本人と関係者の許可範囲で管理し、面接のために原本を外部公開する必要はありません。

## 材料から文章にする

結論・動機＝F1 → 気づいた原因＝F2 → 本人の提案と聞き取り＝F3 → 残った抜け・直し方・学びと継続＝F4。

「チームワーク」「改善力」といった言葉を増やすより、誰にどう聞き、何を一枚にまとめ、どこが残ったかを具体化します。企業の求める人物像に合わせて動機や役割を作り替えません。

## 架空の文章

飲食店のアルバイトで、開店準備の抜けを減らすことに力を入れました。備品の補充や案内表示の抜けが日によって起き、初めは新人の不慣れが原因だと思っていましたが、観察すると長年のパートの方の手順も互いに違っていました。私は店長に準備チェック表の作成を提案し、パートの方には作業中に一つずつ理由を聞き、新人には分からなかった点を書き出してもらい、順番と確認欄を一枚にまとめて1か月試しました。抜けは減りましたが繁忙日には残ったため、起きた日と項目を記録して店長に報告し、繁忙日だけ確認を二人で行う形に直しました。相手の経験に合わせて聞き方を変えると本音が集まることを学び、次の学期に新人が入ったときも、この表を最初に渡しています。

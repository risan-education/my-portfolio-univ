# サカタのタネを想定したガクチカ例

想定職種: **研究・技術系（育種・研究）**

企業研究: [令和就活ラボ・サカタのタネ](https://risan.jpn.org/?p=13799) ／ 基本例: [メーカー](../02-manufacturing.md)

## この会社・職種で意識したい経験

研究・技術系を想定するなら、**観察する → 欠測やばらつきの偏りを見つける → 人の注意力ではなく条件を疑う → 測定方法を変える → データの限界も説明する**経験が話しやすいです。

## 修正前のガクチカ

> 農学部の圃場実習で、班の生育記録を欠測なく続けることに力を入れました。5人で葉物野菜を育て、草丈と葉数を交代で記録しましたが、3週目から欠測が続きました。記録を見返すと、欠測は特定の曜日に集中し、朝の授業と重なる日は時間が取れず、測る位置も人によって違っていました。そこで当番を変え、測る位置を図で示した様式に作り直しました。欠測は減りましたが、長雨で生育が止まり、肥料量による差は確かめられませんでした。

## 何を改善したか

修正前は「記録漏れを減らした話」に見えやすい構成でした。改善版では、欠測の分布を見て**担当者の注意不足ではなく、記録条件に原因がある**と判断した場面を明確にしました。長雨で本来の仮説を検証できなかったことも残し、研究ではデータを集める仕組み自体を設計する必要があるという学びにつなげています。

## 改善版ガクチカ

> 圃場実習で、5人班の生育記録の欠測を減らしました。3週目から記録漏れが増えたため、私は担当者の注意不足ではなく記録条件に原因があると考え、データを見返しました。欠測は朝の授業と重なる曜日に集中し、測定位置も人によって異なっていました。そこで当番を授業のない時間帯に再配置し、測定位置を図示した様式と、忙しい日は写真を残す手順を提案しました。欠測は減りましたが、長雨で生育が止まり、肥料量による差は確認できませんでした。発表では記録方法の改善と、天候のため検証できなかった仮説を分けて説明しました。この経験から、良いデータを得るには、対象だけでなく記録を続けられる条件まで設計する必要があると学びました。

## この例の強いところ

植物を育てた経験そのものではなく、データの欠測という研究上の問題を発見し、欠測が起こる条件まで調べています。仮説どおりの研究結果が出なかったことも隠さず、データ品質と研究の限界を説明できます。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| 植物の生育条件を比較する | 観察・仮説・測定を一連で経験できる |
| 水やり方法を比較する | 条件を一つずつ変える実験を作りやすい |
| 欠測を減らす記録方法を作る | データ品質そのものを改善できる |
| 発芽率を条件別に測る | 結果を数値で比較しやすい |
| 病害発生を記録する | 環境条件との関係を考えられる |
| 家庭菜園の収量を比較する | 身近な環境でも継続データを取れる |
| 種子の保存条件を試す | 保存条件と結果を対応させられる |
| 圃場写真の記録法を改善する | 定性的観察を比較可能な記録へ変えられる |
| 班の測定誤差を減らす | 測定者による差を検証できる |
| 気象データと生育を比較する | 自分で制御できない要因も分析できる |

## 進め方

最初に測る項目・場所・時刻・担当者を決め、欠測もデータとして残します。欠測が出たら「誰が忘れたか」だけでなく、曜日、授業時間、天候、測定方法など条件との偏りを見ます。

改善後も、本来調べたかった仮説と「記録方法が改善したこと」を混同しません。天候などで結論が出なかった場合も、何が言えて何が言えないかを残します。

## 面接で深掘りしたい質問

1. なぜ担当者の注意不足ではないと考えたのですか。
2. 欠測の偏りをどのように見つけましたか。
3. 写真で後から記録する方法にはどんな弱点がありますか。
4. 肥料量の差を確認できなかった結果をどう評価しますか。
5. 次に同じ実験をするなら、記録条件をどう設計しますか。

# 三菱UFJ銀行を想定したガクチカ例

想定職種: **オープンコース**

基本例: [金融・銀行](../03-finance.md)

## この会社・職種で意識したい経験

この職種を想定するなら、**トラブルを予想する → 判断ルールを先に決める → 二重確認できる仕組みにする → 食い違いを原因まで追う → 次の担当へ引き継ぐ**経験が話しやすいです。

## 修正前のガクチカ

> 留学生支援団体の交流旅行で、約三十人分の参加費の集金と精算に力を入れました。前年は返金の決まりがなくキャンセル時にもめたと聞き、集金を始める前にキャンセルの期限と返金の割合、領収の出し方を一枚の決まりにして代表と確認し、参加者全員に説明しました。現金と送金が混ざるため、受け取るたびに帳簿へ記入し、毎日、領収の控えと照合しました。手伝う仲間二人とは、受け取った人が帳簿に書き、私が控えで確認する分担にしました。期限後のキャンセルが一件あり、決まりどおり一部返金とすることを代表と確認して説明しました。精算の最終確認で帳簿と控えに一件の食い違いが見つかり、送金分を現金の欄に書いた記入ミスだと確かめてから、代表に経緯と直し方を報告しました。決まりを先に共有すると判断がぶれないこと、食い違いは原因まで追って報告することを学び、次年度の担当へ手順を渡しました。

## 何を改善したか

修正前でも正確な会計処理は伝わりますが、「慎重に管理した」という個人の注意力の話にも見えました。改善版では、前年のトラブルを踏まえて**問題が起きる前に返金ルールを決めたこと**、現金と送金が混ざるため別の人が確認する仕組みを作ったことを中心にします。最後の食い違いも、数字を合わせるだけでなく原因まで追った行動として示します。

## 改善版ガクチカ

> 留学生支援団体の交流旅行で、約30人分の参加費管理を担当しました。前年にキャンセル返金でもめたと聞き、集金前に期限、返金割合、領収方法を代表と決め、全員に共有しました。現金と送金が混在するため、受領時の帳簿記入と領収控えを別の人が確認する方法にしました。期限後のキャンセルが出た際も、事前ルールに沿って説明できました。最終精算では帳簿と控えに1件の差があり、送金を現金欄へ記入したミスまで追跡して修正しました。単に間違えないよう注意するのではなく、判断がぶれないルールと、ミスを発見できる確認方法を先に作ることの重要性を学びました。

## この例の強いところ

お金を扱った責任感だけでなく、例外が起きる前にルールを決め、ミスを検出する仕組みを作っています。実際にキャンセルと帳簿差異が発生したため、その仕組みがどう機能したかまで説明できます。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| サークル会計を改善する | 正確性と継続可能なルールを経験できる |
| 旅行参加費を管理する | 集金・キャンセル・返金まで扱える |
| 学園祭売上を精算する | 現金と記録の照合を経験できる |
| 寄付金管理ルールを作る | 透明性と説明責任を考えられる |
| 備品購入申請を改善する | 承認と記録の流れを設計できる |
| 立替精算を整理する | 書類と取引の対応を改善できる |
| 会費未納を減らす | 周知・期限・支払方法を検討できる |
| 予算と実績を比較する | 計画と結果の差を分析できる |
| 領収書管理を改善する | 証拠と帳簿を対応させる経験になる |
| キャンセル返金ルールを作る | 例外時の公平な判断基準を考えられる |

## 進め方

お金を扱う前に、期限、返金、承認者、記録方法を決めます。「注意する」だけでなく、別の人が確認できる記録を残します。

差額が出たら帳尻だけ合わせず、いつ・どの取引で・なぜずれたかを追います。例外処理をした場合は判断理由も残し、次の担当者が同じ基準で処理できるよう引き継ぎます。

## 面接で深掘りしたい質問

1. なぜ集金前に返金ルールを決める必要があると考えたのですか。
2. 二重確認で、役割をどう分けましたか。
3. 期限後のキャンセルにはどのように説明しましたか。
4. 帳簿の差をどのように原因まで追いましたか。
5. 次年度の担当者へ最も伝えたいルールは何ですか。

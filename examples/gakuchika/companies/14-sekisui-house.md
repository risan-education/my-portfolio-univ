# 積水ハウスを想定したガクチカ例

想定職種: **営業職**

企業研究: [令和就活ラボ・積水ハウス](https://risan.jpn.org/?p=14490) ／ 基本例: [医療・福祉・介護](../10-welfare.md)

## この会社・職種で意識したい経験

この職種を想定するなら、**相手の言葉をそのまま要望と決めない → 生活を聞く → 本当の目的を見つける → 相手に合わせて方法を変える → 小さな達成へ目標を組み替える**経験が話しやすいです。

## 修正前のガクチカ

> 地域の高齢者向けスマートフォン教室のボランティアで、受講者一人に三か月間付き添うことに力を入れました。初回、その方は使い方を覚えたいとしか言いませんでしたが、生活の話を聞くと、離れて住む家族とビデオ通話をしたい、写真を送りたいという希望が分かり、目標をその二つに絞って合意しました。一般の手順書では教えた操作を翌週には忘れられていたため、その方の画面の写真に手書きで番号を付けた一枚の手順書を作り、家族にも同じものを渡してもらいました。他のボランティアの助言で、最初の目標を写真を一枚送ることに組み替え、通話は後回しにしました。三か月目に写真を送ることができ、通話も一度できましたが、私がいない日に一人でできたかは確認できていません。相手の言葉の奥にある希望を先に聞き取ること、うまくいかないときは目標の順番を変えることを学び、手順書の作り方を教室の共有資料に残しました。

## 何を改善したか

修正前は丁寧な支援経験ですが、手順書を工夫したことが中心に見えました。改善版では、最初の「スマホの使い方を覚えたい」という言葉から、生活を聞いて**家族へ写真を送り、通話したいという本当の目的を見つけたこと**を中心にしました。さらに、一般手順書が機能しなかったため個別化し、それでも難しいときに目標を小さくした判断を明確にしています。

## 改善版ガクチカ

> 地域の高齢者向けスマートフォン教室で、一人の受講者に3か月間付き添いました。初回は「使い方を覚えたい」と話していましたが、生活の話を聞くと、本当の希望は離れて住む家族へ写真を送り、ビデオ通話をすることだと分かりました。そこで目標をその2つに絞りました。一般の手順書では翌週に操作を忘れていたため、本人の画面写真に番号を書いた個別手順書を作りました。それでも難しかったため、他のボランティアの助言を受け、まず写真を1枚送ることに目標を小さくしました。3か月目には写真送信と通話を一度実現できました。相手の表面的な要望ではなく、生活の中で実現したいことを聞き、難しければ目標の順番を組み替えることを学びました。

## この例の強いところ

「親切に教えた」という話ではなく、相手の希望を聞き直して目標そのものを定義しています。3か月という継続的な関係の中で方法を変え、相手に合わせて目標の順番まで変更した過程を説明できます。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| 高齢者向けスマホ教室を支援する | 生活上の本当の目的を聞く経験になる |
| 学習支援を継続する | 相手に合わせて説明方法を変えられる |
| 高齢者の買物支援を行う | 表面的な依頼の背景を理解できる |
| 子どもの学習会を運営する | 年齢や理解度に応じた提案ができる |
| 外国人向け生活案内を改善する | 言葉だけでなく生活背景を考えられる |
| 地域住民への聞き取りを行う | 本人の価値観からニーズを発見できる |
| 新入生相談を担当する | 曖昧な悩みを具体的な課題へ整理できる |
| 福祉イベントを改善する | 多様な参加方法を考えられる |
| 長期メンター活動を行う | 一度の成果でなく関係の変化を記録できる |
| 住環境の困りごとを調査する | 生活動線から本人も気づかない課題を探せる |

## 進め方

最初に相手の「欲しいもの」だけでなく、「それができると生活で何が変わるか」を聞きます。支援方法は一度で決めず、実際に使えたかを次回確認します。

難しい場合は、相手の能力の問題にせず、手順、説明、目標の大きさを変えます。小さな達成と、まだ一人ではできないことの両方を記録します。

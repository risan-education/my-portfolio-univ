# INPEXを想定したガクチカ例

想定職種: **技術総合職（貯留層）**

基本例: [メーカー](../02-manufacturing.md)

※架空の学生の例です。本人の実績には数えません。作成日: 2026-10-01。

## この会社・職種で意識したい経験

この職種を想定するなら、**条件がそろわずばらつく測定に向き合う → 原因を一つに絞って条件を決め直す → 班の分担を変えて再測定まで続ける → 残った誤差を分けて報告する**経験が話しやすいです。

## 修正前のガクチカ

> 地下水の測定実習で、観測井の水位データのばらつきを減らすことに力を入れました。実習では大学構内の三本の観測井で水位を週二回測り、降雨との関係を整理する課題が出ましたが、班員五人の測定値が同じ日でも数センチずれ、降雨の影響なのか測り方の差なのか分からなくなりました。私は各自の測定記録を集めて見比べ、巻尺の基準点の取り方と測定時刻が人によって違うことに気づきました。そこで基準点を井戸枠の刻印に固定し、測定時刻を午前中に統一し、記録用紙に基準点と時刻の欄を足す案を班に提案しました。最初は手間が増えると言われましたが、一週間だけ試すことにし、二人一組で確認しながら測る分担に変えました。試した週はずれが一センチ以内に収まり、以後の実習では降雨後の水位上昇をはっきり読み取れるようになりました。ただし一本の井戸は周囲の工事の影響とみられる変動が残り、原因を分けて報告書に書きました。測り方をそろえてから結果を見ることの大切さを学びました。

## 何を改善したか

修正前は実習の手順が細かく書かれ、本人の判断が埋もれていました。改善版では、ずれの原因を「基準点と時刻が人によって違うこと」と捉え、条件を固定して一週間だけ試した判断を中心にしました。残った変動を測り方の問題と分けて報告した点も残しています。

## 改善版ガクチカ

> 地下水の測定実習で、観測井の水位データのばらつきを減らしました。3本の井戸を5人で週2回測りましたが、同じ日でも数cmずれ、降雨の影響と測り方の差が区別できませんでした。各自の記録を見比べると、巻尺の基準点と測定時刻が人によって違っていました。そこで基準点を井戸枠の刻印に固定し、時刻を午前中に統一し、記録用紙に基準点と時刻の欄を足す案を出しました。手間が増えると言われたため1週間だけ試し、2人1組で確認する分担に変えました。結果、ずれは1cm以内に収まり、降雨後の水位上昇を読み取れるようになりました。1本の井戸には工事の影響とみられる変動が残り、測り方の問題と分けて報告しました。結果を見る前に測り方をそろえることと、残る誤差を言い切らず分けて伝えることを学びました。

## この例の強いところ

ばらつきを「もっと丁寧に測る」で片づけず、記録を見比べて原因を基準点と時刻に絞っています。反対された後も一週間の試行に切り替えて続け、最後に残った変動を測り方の問題と分けて報告しています。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| 観測井の水位測定をそろえる | 測定条件の統一と再測定を経験できる |
| 河川の流量観測を続ける | 自然条件の変動と測り方の差を分けられる |
| 土壌サンプルの採取手順を決める | 現場で手順を固定する判断を扱える |
| 地質図の読み取りを班で統一する | 解釈のばらつきを基準で減らせる |
| 実験装置の温度管理を改善する | 条件を固定して再現性を高められる |
| 測定記録の様式を作り直す | 記録の欠けを仕組みで防げる |
| 班の測定分担を組み直す | 確認役を置く効果を測れる |
| 野外実習の安全手順を点検する | 安全を優先して段取りを変える経験になる |
| 長期の観測データを整理する | 季節変動と異常値を分けて考えられる |
| 外部の施設見学で質問を準備する | 現場の制約を知ってから課題を選べる |

## 進め方

測定値がばらついたら、まず各自の記録を並べて、人によって違う条件を探します。条件を一つずつ固定し、短い期間で試してから全体に広げます。固定しても残る変動は、測り方の問題と対象そのものの変化に分けて記録し、言い切れないことは言い切らずに書きます。

## インターンシップの時期・応募準備

INPEXの新卒採用サイトでは、募集要項（応募資格・職種・初任給）とFAQ（職種併願不可、専攻は資源系に限らない、選考段階で英語力は重視しない）が公開されています。インターンの実施時期・応募時期・選考内容は年度で変わるため、応募時に公式の募集要項で確認します。

## 面接で深掘りしたい質問

1. なぜ基準点と測定時刻に原因を絞ったのですか。
2. 手間が増えると言われたとき、なぜ一週間の試行に切り替えたのですか。
3. 二人一組の分担にして、何が変わりましたか。
4. 工事の影響とみられる変動を、測り方の問題と分けた根拠は何ですか。
5. 海外の現場で同じ実習をするなら、最初に何をそろえますか。

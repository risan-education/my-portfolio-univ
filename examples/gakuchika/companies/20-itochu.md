# 伊藤忠商事を想定したガクチカ例

想定職種: **総合職**

基本例: [商社](../04-trading.md)

## この会社・職種で意識したい経験

この会社・職種を想定するなら、**買う人の困りごとを自分で見に行く → 仕入れ・値段・売り方の一つを変える → 結果を数字で確かめる → うまくいかなかった点を次に直す**経験が話しやすいです。会社は経営方針に「利は川下にあり」「マーケットインの発想」を掲げており、消費者に近い場所から考えた経験と相性があります。

## 修正前のガクチカ

> 学園祭の模擬店で、焼き菓子の売れ残りを減らすことに力を入れました。一年目は前年と同じ量を仕入れて同じ値段で売り、昼過ぎに客足が減って最後の二時間で三割近くが残り、班で廃棄しました。二年目は班長として、前年のレシートと時間ごとの売上を集計し、午後に減るのは量ではなく、持ち帰りにくい形で売っていたからだと考えました。そこで仕入れを前年の八割に減らし、午後からは二個入りの袋を作って帰り際の人に向けて売り、値段は据え置きにしました。班員に時間ごとの売上を記録してもらい、途中で袋の数を増やしました。結果、売れ残りは一割未満になり、売上は前年より少し増えました。ただ、午前中に一度品切れが出て、その時間の客を逃しました。反省会で仕入れの減らし方と品切れの時間を共有し、次年度の班に記録を渡しました。買う人の様子を見てから変えることの大切さを学びました。

## 何を改善したか

修正前でも工夫は伝わりますが、やったことの列挙が中心で、本人の判断の根拠が埋もれていました。改善版では、午後に売れ残る原因を「量」ではなく「買う人が持ち帰りにくい売り方」と捉え直した判断を中心にしました。仕入れを減らした結果として起きた品切れも隠さず、記録を次の班に渡したことまで含めて、判断と検証の流れが見えるようにしています。

## 改善版ガクチカ

> 学園祭の模擬店で、焼き菓子の売れ残りを減らしました。1年目は前年と同じ量・同じ値段で売り、最後の2時間で3割が残りました。2年目に班長として前年のレシートを時間ごとに集計すると、午後の客は帰り際で、1個ずつ買う売り方が合っていないと考えました。そこで仕入れを前年の8割にし、午後は2個入りの袋を同じ単価で売ることにしました。班員に時間ごとの売上を記録してもらい、途中で袋の数を増やしました。売れ残りは1割未満になり、売上は前年を少し上回りました。一方、午前に一度品切れを出し、客を逃しました。反省会で仕入れの減らし方と品切れの時間を記録し、次年度の班に渡しました。買う人の行動を先に見てから売り方を変えることが、結果につながると学びました。

## この例の強いところ

「頑張って売った」ではなく、レシートという身近な記録から買う人の行動を読み、売り方を変えています。仕入れを減らした副作用の品切れを隠さず、次年度に記録を渡しているので、面接で判断の根拠と反省を深掘りできます。海外経験や大きな実績がなくても、消費者に近い場所から考えた経験として話せます。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| 模擬店の売れ残りを減らす | 仕入れ・値段・売り方の判断と結果を数字で確かめられる |
| アルバイト先の売れ筋を時間帯で分ける | 買う人の行動を記録から読む練習になる |
| サークルの物販の在庫を管理する | 発注量と品切れのバランスを経験できる |
| フリーマーケットで仕入れ値と売値を決める | 小さな商いの一連の流れを一人で回せる |
| 学食や売店の混雑を減らす提案をする | 使う人の困りごとを観察から見つけられる |
| 留学生向けに商品説明を作り直す | 買う人の違いに合わせて売り方を変えられる |
| 寄付や協賛の集め方を変える | 相手の利益を考えた提案を経験できる |
| 地域の店の販促を手伝う | 学外の相手との約束と結果の確認を経験できる |
| 食品ロス削減の企画を運営する | 作る側・売る側・買う側の三者を同時に考えられる |
| 海外の商品を取り寄せて小さく売る | 仕入れ先・輸送・価格の違いを実感できる |

## 進め方

買う人がいつ・何を・どう買っているかを、レシートや売上の記録から先に調べます。変える要素は一度に一つに絞り、変える前と後を同じ指標で比べます。

仕入れを減らす、値段を変えるなどの判断には副作用があります。品切れや苦情など、うまくいかなかった点も記録し、次に何を直すかまで残します。

## 面接で深掘りしたい質問

1. 午後に売れ残る原因を「量」ではなく「売り方」と考えた根拠は何ですか。
2. 仕入れを8割に減らす判断に、班員はどう反応しましたか。
3. 午前の品切れが分かったとき、その場で何をしましたか。
4. 2個入りの袋を同じ単価にした理由は何ですか。
5. 次の年の班に渡した記録には、何を書きましたか。

# リクルートを想定したガクチカ例

想定職種: **ビジネスグロースコース（営業・顧客接点）**

企業研究: [令和就活ラボ・リクルート](https://risan.jpn.org/?p=13615) ／ 基本例: [IT・情報通信](../01-it.md)

## この会社・職種で意識したい経験

利用者が離れた理由を聞き、**最初の思い込みを修正する → 企画そのものを変える → 自分が抜けても続く仕組みを考える**経験が話しやすいです。

## 修正前のガクチカ

> 授業で扱わない統計ソフトを学ぶ自主ゼミを立ち上げました。初回は12人が集まりましたが、4回目には4人に減りました。内容が難しいのだと思っていましたが、来なくなった人に聞くと、自分の課題に使えない、毎週は続かないという理由が多くありました。そこで各自のデータを持ち寄る隔週の会に変え、進行役を回り持ちにしました。学期末の参加者は7人で、私が抜けても続く仕組みはまだできていませんでした。

## 何を改善したか

修正前でも立ち上げと改善は伝わりますが、「参加者が減った」という失敗から何を学んだかが埋もれていました。改善版では、最初の「内容が難しい」という仮説が、離脱者への聞き取りで外れたことを中心にしました。参加者数が完全には戻らず、運営の自走も未完成だった点を残し、次の改善まで説明できる構成にしています。

## 改善版ガクチカ

> 授業外で統計ソフトを学ぶ自主ゼミを立ち上げました。初回は12人集まりましたが、4回目には4人まで減りました。私は内容が難しすぎると考えましたが、離脱した学生に聞くと「自分の課題に使えない」「毎週は続かない」という声が中心でした。そこで一方向の勉強会をやめ、各自の研究やレポートのデータを持ち寄る隔週相談会へ変更し、進行役も回り持ちにしました。学期末には7人まで戻りました。一方、私が抜けても続く仕組みには至らなかったため、翌期は運営役を複数人にする案を残しました。この経験から、自分のアイデアに固執せず、利用者が離れた理由から企画の形を変えることを学びました。

## この例の強いところ

「自主ゼミを立ち上げた」という行動力だけでなく、参加者減少という失敗を直視し、離れた人に聞いて企画そのものを変えています。成果が完全ではないため、次にどう改善するかまで面接で話せます。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| 自主ゼミを立ち上げる | ゼロから参加者を集め、継続率まで見られる |
| 新入生支援企画を作る | 利用者の困りごとを聞いて内容を変えられる |
| 学生向け勉強会を改善する | 参加率・継続率を測りやすい |
| 地域イベントを企画する | 学外の利用者から反応を得られる |
| サークルの新企画を試す | 小さく始めて改善を繰り返せる |
| 学内情報メディアを運営する | 閲覧・反応からニーズを検証できる |
| 学生相談会を作る | 相談者の声からサービスを変えられる |
| アルバイト研修を改善する | 新人の離脱・つまずきを観察できる |
| 教材交換会を運営する | 需要と供給の両側を考えられる |
| オンラインコミュニティを運営する | 参加だけでなく継続の仕組みを考えられる |

## 進め方

小さく企画を始め、参加者数だけでなく「2回目も来た人」「途中で離れた人」を記録します。参加者だけでなく、来なくなった人に理由を聞くことが重要です。

自分の予想と違う理由が出たら、内容・頻度・役割分担のどこを変えるか決めて試します。最後は「自分がいなくても続くか」まで考えます。

## 面接で深掘りしたい質問

1. なぜ自主ゼミを始めようと思ったのですか。
2. 参加者が減ったとき、なぜ内容の難しさが原因だと思ったのですか。
3. 離脱した人へどんな質問をしましたか。
4. 7人まで戻ったことを成功と考えますか。
5. 自分が抜けても続く仕組みにするなら、次に何を変えますか。

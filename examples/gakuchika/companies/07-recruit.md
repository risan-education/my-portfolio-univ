## 採用選考で見られそうなBig Fiveの読み替え

ブログ記事の「採用選考で見られそうなBig Five」は、公式の4つのスタンスと選考設計（成果を出した経験を問うエントリーシート・面接2〜3回・事業立案インターン）から令和就活ラボが立てた**予想**です。記事は開放性（新しい価値の創造、好奇心のまま駆けだす）を特に高く読み、誠実性（考え抜く・やり抜く）、外向性、情緒安定性を高く、協調性を中〜高としています。

この教材では、その予想を「文章のどこを詳しく書くか」の補助線として使います。

| 記事の予想 | この例で詳しく書く場面 |
| --- | --- |
| 開放性（自分で始める） | F1で、誰にも頼まれずに自主ゼミを立ち上げた動機 |
| 誠実性（やり抜く） | F3で、参加者が減っても形を変えて続けたこと。F4で、続く仕組みが未完成だと認めたこと |
| 外向性（働きかける） | F1からF3で、参加者に声をかけ、要望を聞いて回ったこと |
| 協調性（協働と個の両立） | F3で、自分の当初の形にこだわらず参加者の要望で変えたこと |
| 情緒安定性（問われ続ける環境） | F2で、参加者が減った時点で自分の見立てを改めたこと |

企業が公表した合否基準ではなく、性格を偽るためのものでもありません。本人の材料を会社の人物像に合わせて作り替えず、本人のBig Fiveを点数化しません。本人の傾向を整理するときは[参考自己分析](../../../docs/self-analysis.md)の表示方法に従います。

| 材料 | 架空の事実・当時の考え・振り返り |

| F1 | 大学2年の2025年10月〜2026年2月。授業で扱わない統計ソフトを学ぶ自主ゼミを本人が発起人として立ち上げた。週1回、初回は12人が参加。本人は教える立場ではなく、進行と場所の確保を担った。 |
| F2 | 4回目には参加者が4人に減った。本人は「内容が難しい」と見立てていたが、来なくなった人に個別に聞くと「自分の課題に使えない」「毎週は続かない」という理由が多かった。 |
| F3 | 本人は形を変え、各自が自分のレポートや研究のデータを持ち寄って相談する隔週の会にし、進行役を回り持ちにした。参加者の一人がソフトに詳しく、説明役を引き受けた。本人は日程調整と、持ち寄る材料の事前確認を続けた。 |
| F4 | 学期末の参加者は7人で、初回の人数には戻らなかった。本人が抜けても続く仕組みは未完成で、次の学期の進行役は決まっていない。本人は「自分の見立てより、来なくなった人の理由が形を決める」ことと、続けるには自分以外の役割が要ることを学んだ。 |

## 材料から文章にする

結論・動機＝F1 → 減った事実と聞いた理由＝F2 → 形の変更と役割の分担＝F3 → 結果と未完成な点・学び＝F4。

「当事者意識」「巻き込み力」といった言葉を増やすより、何を自分で決め、誰に何を聞き、何を変え、何がまだできていないかを具体化します。企業の求める人物像に合わせて動機や役割を作り替えません。

## 修正前のガクチカ

> 授業で扱わない統計ソフトを学ぶ自主ゼミを立ち上げ、続く形に変えることに力を入れました。発起人として週一回の会を始め、初回は十二人が集まりましたが、四回目には四人に減りました。内容が難しいのだと思っていましたが、来なくなった人に個別に聞くと、自分の課題に使えない、毎週は続かないという理由が多くありました。そこで各自のレポートや研究のデータを持ち寄って相談する隔週の会に変え、進行役を回り持ちにしました。ソフトに詳しい参加者が説明役を引き受け、私は日程調整と持ち寄る材料の事前確認を続けました。学期末の参加者は七人で初回には戻らず、私が抜けても続く仕組みはまだできていません。自分の見立てより来なくなった人の理由が形を決めること、続けるには自分以外の役割が要ることを学びました。

## 何を改善するか

自分で始めた企画の失敗から、離れた利用者の声を聞いて形を変えた過程を前面に出す。

## 改善版ガクチカ

授業外で統計ソフトを学ぶ自主ゼミを立ち上げました。初回は12人集まりましたが、4回目には4人まで減りました。私は内容が難しすぎると考えましたが、離脱した学生に聞くと「自分の課題に使えない」「毎週は続かない」という声が中心でした。そこで一方向の勉強会をやめ、各自の研究やレポートのデータを持ち寄る隔週相談会へ変更し、進行役も回り持ちにしました。学期末には7人まで戻りました。一方、私が抜けても続く仕組みには至らなかったため、翌期は運営役を複数人にする案を残しました。自分のアイデアに固執せず、利用者が離れた理由からサービスの形を変えることを学びました。

## 進め方

最初に現状と困っている人を確認し、改善前の数字・観察・相手の声を残します。次に原因を一つに決めつけず候補を出し、小さな変更を試します。結果が予想と違った場合こそ、何を見て判断を変えたかを記録してください。チームの成果と自分の担当を分け、成功だけでなく残った課題も保存します。

## 面接で確かめる質問

会社の公式情報（4つのスタンス、「あなたはどうしたい？」）と、ブログが予想した面接の話題（成果を出した経験の深掘り、自分で決めて動いたこと）に寄せた質問です。会社が実際に聞く質問ではありません。

1. なぜ自分で始めようと思いましたか。始めなくても困らなかったのでは、と聞かれたら何と答えますか。
2. 参加者が減ったとき、やめる選択肢はありましたか。続けると決めた理由は何ですか。
3. 次の学期に本人がいなくても続くようにするなら、今日から何をしますか。

答えが材料にない場合は補って創作せず、「この架空設定では未確認」とします。実際の本人には、覚えている範囲で確認します。

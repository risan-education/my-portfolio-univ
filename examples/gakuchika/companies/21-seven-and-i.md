# セブン‐イレブン・ジャパンを想定したガクチカ例

想定職種: **総合職（OFC：オペレーション・フィールド・カウンセラー）**

基本例: [小売・流通](../05-retail.md)

## この会社・職種で意識したい経験

この職種を想定するなら、**困りごとを記録して原因を一つに絞る → 自分より経験の長い人に案を出す → 小さく試して数字で確かめる → 相手が続けられる形に直す**経験が話しやすいです。

## 修正前のガクチカ

> コンビニのアルバイトで、夕方のおにぎりの欠品と翌朝の廃棄を減らすことに力を入れました。店では夕方に棚が空く日と、朝に売れ残りを捨てる日が交互にあり、私は発注を担当する社員の方に「もっと多く頼んだ方がいい」と言いましたが、廃棄が増えるからと断られました。そこで二週間、曜日と天気、近くの学校の行事と、夕方五時と閉店前の残り数をノートに書き、欠品は火曜と金曜の夕方に集中し、廃棄は雨の日に多いことを見つけました。社員の方にノートを見せ、火曜と金曜だけ二つの商品を三個ずつ増やし、雨の予報の日は減らす案を出しました。一か月試すと、夕方の欠品はほぼなくなり、廃棄は週に数個減りました。その後、店長が記録の表を他の商品にも広げ、私はその表を新しく入ったアルバイトにも説明しました。数字を見せると意見が通ること、相手の心配を先に数字で確かめることを学びました。

## 何を改善したか

修正前も記録と提案の流れは伝わりますが、「断られた理由」をどう扱ったかが埋もれていました。改善版では、相手の心配（廃棄が増える）をそのまま検証の項目にし、増やす曜日と減らす日を分けて提案した判断を中心にしました。試した後に残った問題（雨の日の予報が外れると廃棄が出ること）も残し、言い切らない形にしています。

## 改善版ガクチカ

> コンビニのアルバイトで、おにぎりの夕方の欠品と翌朝の廃棄を減らしました。発注担当の社員に増やす提案をしましたが、廃棄が増えると断られました。そこで2週間、曜日・天気・近くの学校の行事と、17時と閉店前の残り数を記録しました。欠品は火曜と金曜の夕方に集中し、廃棄は雨の日に多いと分かりました。記録を見せ、火曜と金曜だけ2品を3個ずつ増やし、雨の予報の日は減らす案を出して1か月試しました。夕方の欠品はほぼなくなり、廃棄は週に数個減りましたが、予報が外れた日は廃棄が残りました。その後、店長が記録の表を他の商品にも広げました。相手の心配を先に数字で確かめてから提案すると、意見が通りやすいと学びました。

## この例の強いところ

提案を一度断られた後に、相手の心配を検証項目に変えています。増やす曜日と減らす日を分けた判断、1か月の結果、残った問題の順に書かれており、「分析→仮説→実施→検証」の形で話せます。自分の案が店の仕組みとして残った点も、短く説明できます。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| アルバイト先の発注を記録して提案する | 欠品と廃棄の両方を数字で扱える |
| 品出しの順番を変えて売れ方を見る | 小さな変更と検証をくり返せる |
| 廃棄の多い時間帯を記録する | 感覚ではなく記録で原因を探せる |
| レジ待ちが長い時間帯を調べる | 時間帯・人員・動線を分けて考えられる |
| 新人向けの作業手順表を作る | 相手が続けられる形に直す経験になる |
| サークルの備品の在庫表を作る | 身近な場所で在庫管理を試せる |
| 大学祭の模擬店の仕入れ量を決める | 需要の予想と結果の差を扱える |
| 店の掲示物を直して反応を見る | 相手（お客）の行動を観察できる |
| 年上の人に提案して断られた理由を聞く | 相手の心配を検証に変える練習になる |
| 一度直した手順をもう一度直す | 残った問題を次の改善につなげられる |

## 進め方

困りごとを「いつ・どこで・どれだけ」の形で2週間ほど記録し、原因を一つに絞ります。提案が断られたら、相手が心配していることを記録の項目に加えて、小さく試します。

試した後は、良くなった数字と残った問題を分けて書きます。店長や社員の方が仕組みとして採用した場合は、自分の役割がどこまでだったかを正確に残します。

## インターンシップの時期・応募準備

セブン‐イレブン・ジャパンの新卒採用は総合職（OFC）の1職種で、公式の採用フローはエントリー→会社説明会→エントリーシート・適性検査→面接（複数回）です。インターンシップと説明会はエントリー後のマイページで案内されます。応募年度の設問・字数・AI利用条件は未確認なので、[公式の募集要項](https://www.sej.co.jp/recruit/new/)で確認してください。

## 面接で深掘りしたい質問

1. なぜ曜日と天気と学校の行事を記録したのですか。
2. 断られたとき、なぜ主張を続けずに記録に切り替えたのですか。
3. 増やす曜日と減らす日を分けた根拠は何ですか。
4. 予報が外れた日の廃棄に、次はどう対応しますか。
5. 自分がいなくなった後も、この表は続くと思いますか。

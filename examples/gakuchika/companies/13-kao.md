# 花王を想定したガクチカ例

想定職種: **研究職**

企業研究: [令和就活ラボ・花王](https://risan.jpn.org/?p=14537) ／ 基本例: [メーカー](../02-manufacturing.md)

## この会社・職種で意識したい経験

この職種を想定するなら、**予想と違うデータを捨てない → ずれ方を観察する → 原因候補を分解する → 一条件ずつ検証する → 言えないことも残す**経験が話しやすいです。

## 修正前のガクチカ

> 化学の学生実験で、文献値と合わない測定値の原因を追い続けることに力を入れました。界面活性剤水溶液の表面張力を濃度ごとに測ると、低濃度の値が文献値より大きくずれました。班では外れ値として除く案が出ましたが、ずれが同じ方向に出ていたため、私は値を捨てずに記録し、原因を確かめる提案をしました。原因の候補を器具の洗浄不足、試薬の劣化、測定時の温度の三つに分け、班員と分担して条件を一つずつ変えて再実験しました。二回目までは改善せず、三回目に洗浄手順を変えた組だけが文献値に近づきました。発表では、洗浄手順の変更で改善したことと、温度の影響は未確認であることを分けて説明しました。合わない値を捨てずに条件を一つずつ変えて追うこと、言えないことを言い切らないことを学びました。

## 何を改善したか

修正前でも再実験の丁寧さは伝わりますが、「外れ値を除かなかった」という行動の理由がやや短めでした。改善版では、複数回とも同じ方向にずれたことから**偶然ではなく共通条件に原因があるのではないか**と考えた判断を明示しました。さらに、一度に1条件だけ変えたことと、洗浄の影響は示唆できても温度は未検証だと区別しています。

## 改善版ガクチカ

> 化学の学生実験で、文献値と合わない測定値の原因を追いました。界面活性剤水溶液の低濃度データが、複数回とも同じ方向にずれていました。班では外れ値として除く案が出ましたが、私は偶然ならずれ方はばらつくはずだと考え、共通する測定条件に原因があるのではないかと提案しました。原因候補を器具の洗浄、試薬の劣化、測定温度の3つに分け、一度に1条件だけ変えて再実験しました。2回目までは改善しませんでしたが、3回目に洗浄手順を変えた組だけが文献値に近づきました。発表では「洗浄手順が影響した可能性」は示す一方、温度の影響は十分に検証できていないと説明しました。予想と違う値を捨てる前に、ずれ方を観察して原因候補を分解し、一つずつ確かめることを学びました。

## この例の強いところ

結果を文献値へ合わせる話ではなく、予想外のデータから新しい仮説を立てています。2回改善しなくても検証を続け、最後も結論を言い切りすぎないため、研究での判断と再現性への姿勢を説明できます。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| 測定値のずれの原因を調べる | 外れ値を捨てず仮説検証する経験になる |
| 実験器具の洗浄条件を比較する | 手順の違いと結果を対応させられる |
| 試薬の保存条件を比較する | 品質管理と再現性を考えられる |
| 測定温度を管理する | 環境条件の影響を検証できる |
| 実験手順を標準化する | 人による差を減らす仕組みを作れる |
| 官能評価のばらつきを調べる | 人を含む測定の難しさを扱える |
| 文献の再現実験を行う | 既報と違う結果の原因を考えられる |
| データ入力ミスを減らす | 研究データの品質を改善できる |
| 研究ノートの記録法を改善する | 後から検証可能な記録を作れる |
| 複数人の測定誤差を比較する | 測定者差を数値で確認できる |

## 進め方

予想と違うデータが出たら、すぐ除外せず「ずれはランダムか、同じ方向か」を見ます。原因候補を複数挙げ、一度に一条件だけ変えると、何が影響したか説明しやすくなります。

結果が改善しても、検証していない条件まで原因から外さないことが重要です。研究ノートには成功した条件だけでなく、改善しなかった試行も残します。

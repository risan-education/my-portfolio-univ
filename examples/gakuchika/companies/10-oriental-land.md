## 採用選考で見られそうなBig Fiveの読み替え

ブログ記事の「採用選考で見られそうなBig Five」は、公式の求める人材像5つ・有報の「自立した人材」・選考設計（OLCチャレンジシート・総合能力検査）から令和就活ラボが立てた**予想**です。記事は協調性（一丸となって、多人数のオペレーション）と誠実性（やり切る、倫理観、決められた品質と安全を毎日守る）を特に高く読み、情緒安定性を高く、開放性・外向性を中〜高としています。

この教材では、その予想を「文章のどこを詳しく書くか」の補助線として使います。

| 記事の予想 | この例で詳しく書く場面 |
| --- | --- |
| 協調性（一丸となって） | F3で、誘導班10人が持ち場を交代し合い、連絡の言葉をそろえたこと |
| 誠実性（やり切る、毎日守る） | F1からF2で、毎週の準備確認を最後まで続けたこと。F3で、当日を最後までやり切ったこと |

| 外向性（接客・声かけ） | F3で、来場者に自分から声をかけて案内したこと |

## 架空の材料

| 材料 | 架空の事実・当時の考え・振り返り |
| --- | --- |
| F1 | 大学2年の2025年8〜10月。地域の子ども向け運動会の運営ボランティアで、誘導班（10人）の一員。班長ではない。本人は準備期間に、会場図・持ち場・連絡方法の確認を毎週の打ち合わせで続ける係を担当した。 |
| F2 | 準備の途中で、雨天時の屋内会場の案内経路が決まっていないことに本人が気づき、班長に相談して屋内用の持ち場表と案内文を事前に作った。当時は「使わないかもしれない」と思いながら続けた。 |
| F3 | 当日の朝に雨で屋内開催に変更された。本人は屋内用の持ち場表を配り、班長と相談して混雑する入口に人を寄せ、持ち場を交代し合う順番を決めた。来場者には自分から声をかけて案内し、班内の連絡の言葉をそろえた。 |
| F4 | 運営は最後まで行えたが、屋内の入口で一時的に列が伸び、子どもが待つ時間ができた。本人は列が伸びた時間帯と原因の候補（受付と誘導の位置が近すぎた）を記録し、次回の配置案を班長へ渡した。仲間と役割を交代し合えば予定変更にも対応できること、事前の確認は使わなくても続ける価値があることを学んだ。 |

## 架空の文章

地域の子ども向け運動会の運営ボランティアで、誘導班の一員として当日の雨天変更をやり切ることに力を入れました。準備期間は、会場図・持ち場・連絡方法の確認を毎週の打ち合わせで続ける係を担当し、その中で雨天時の屋内の案内経路が決まっていないことに気づき、班長に相談して屋内用の持ち場表と案内文を事前に作りました。当日の朝、雨で屋内開催に変わりました。私は持ち場表を配り、班長と相談して混雑する入口に人を寄せ、十人で持ち場を交代し合う順番を決め、来場者には自分から声をかけて案内しました。運営は最後まで行えましたが、入口で一時的に列が伸び、子どもが待つ時間ができました。列が伸びた時間帯と原因の候補を記録し、次回の配置案を班長に渡しました。仲間と役割を交代し合えば予定変更にも対応できること、事前の確認は使わなくても続ける価値があることを学びました。

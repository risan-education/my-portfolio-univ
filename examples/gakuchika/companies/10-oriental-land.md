# オリエンタルランドを想定したガクチカ例

想定職種: **テーマパークマネジメント職**

企業研究: [令和就活ラボ・オリエンタルランド](https://risan.jpn.org/?p=14179) ／ 基本例: [小売・流通](../05-retail.md)

## この会社・職種で意識したい経験

この職種を想定するなら、**利用者の安全と体験を考える → 起こり得る変更を事前に想定する → 仲間が動ける準備を作る → 当日の状況で配置を変える → 次回へ改善を残す**経験が話しやすいです。

## 修正前のガクチカ

> 地域の子ども向け運動会の運営ボランティアで、誘導班の一員として当日の雨天変更をやり切ることに力を入れました。準備期間は、会場図・持ち場・連絡方法の確認を毎週の打ち合わせで続ける係を担当し、その中で雨天時の屋内の案内経路が決まっていないことに気づき、班長に相談して屋内用の持ち場表と案内文を事前に作りました。当日の朝、雨で屋内開催に変わりました。私は持ち場表を配り、班長と相談して混雑する入口に人を寄せ、十人で持ち場を交代し合う順番を決め、来場者には自分から声をかけて案内しました。運営は最後まで行えましたが、入口で一時的に列が伸び、子どもが待つ時間ができました。列が伸びた時間帯と原因の候補を記録し、次回の配置案を班長に渡しました。仲間と役割を交代し合えば予定変更にも対応できること、事前の確認は使わなくても続ける価値があることを学びました。

## 何を改善したか

修正前でも当日の対応は伝わりますが、「雨が降ったので臨機応変に対応した」という成功談に見えやすい文章でした。改善版では、雨天時の導線が未設計だと**事前に気づいて準備したこと**を起点にし、その準備を使って当日の配置を変えた流れを明確にします。待ち時間が残ったことも記録し、次回の配置案までつなげます。

## 改善版ガクチカ

> 地域の子ども向け運動会で誘導班を担当しました。準備中、雨天時の屋内導線が決まっていないことに気づき、班長に相談して屋内用の持ち場表と案内文を事前に作りました。当日は雨で急きょ屋内開催となり、入口に来場者が集中しました。私は持ち場表を基に10人の配置を組み替え、混雑する入口へ人員を増やし、交代順も決めました。運営は最後まで行えましたが、一時的に子どもの待ち時間が長くなりました。そこで混雑した時間と原因を記録し、次回は開始直後から入口を厚くする案を残しました。想定外への対応力は、その場の機転だけでなく、事前にリスクを考え、仲間が動ける準備を作ることで高まると学びました。

## この例の強いところ

雨天変更への対応だけでなく、事前のリスク発見、準備、当日の再配置、事後改善まで一連で説明できます。「想定外に強い」を性格として主張するのではなく、想定外に備える仕組みを作った行動として示せます。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| 地域イベントの誘導を改善する | 利用者の安全と分かりやすさを同時に考えられる |
| 学園祭の待ち列を改善する | 混雑を観察して配置を変えられる |
| 子ども向け企画を運営する | 年齢に応じた安全・案内を考えられる |
| 雨天時の代替導線を作る | 通常時と例外時の両方を設計できる |
| 受付の混雑を減らす | 時間帯別に人員配置を検討できる |
| 高齢者向け案内を改善する | 多様な利用者の行動を観察できる |
| 迷子対応手順を作る | 例外時の連絡と役割分担を考えられる |
| イベントの交代表を改善する | サービスを継続する運営を経験できる |
| 会場サインを改善する | 利用者が迷う場所を観察できる |
| 来場者アンケートから体験を改善する | 運営側の想定と利用者評価を比較できる |

## 進め方

まず通常時だけでなく、雨天、混雑、欠員など「予定どおりにいかない条件」を一つ想定します。誰が判断し、誰へ連絡し、どこへ人を動かすかを簡単な表にします。

当日は混雑時間、待ち時間、問い合わせ内容などを記録します。無事に終わっただけで成功とせず、利用者に負担が残った場所を確認し、次回の初期配置まで改善します。

## 面接で深掘りしたい質問

1. なぜ雨天時の導線が必要だと気づいたのですか。
2. 持ち場表は、当日変更しやすいようにどんな工夫をしましたか。
3. 入口に人員を増やす判断は何を見て行いましたか。
4. 待ち時間が残った原因をどう考えましたか。
5. 次回、開始前から変えることは何ですか。

# 商社のガクチカ例

想定職種: **営業・調達の調整業務**

## この業種・職種で意識したい経験

この職種を想定するなら、**最安値だけで決めない → 関係者の制約を聞く → 譲れない条件を整理する → 複数案を作る → 実行できる案へまとめる**経験が話しやすいです。

## 修正前のガクチカ

> 大学祭の模擬店で、備品の調達計画を組み直した経験です。私の担当は紙容器の調達でしたが、安さで選んだ第一候補が希望日に届かないと分かりました。予算と開店準備を両立するため、私は価格だけでなく納期、必要数、保管場所を表にし、会計担当と使用担当に譲れない条件を聞きました。その上で、共通して使える容器を必要分だけ先に確保し、不足分は近隣店で調達する案を作りました。追加費用と受取の分担を説明して責任者の承認を得た結果、班として開店時に必要な容器をそろえられました。最安値を実現したわけではありませんが、条件を共有して実行できる案にまとめたことが私の貢献です。相手の事情を確かめ、複数の選択肢を持つ大切さを学びました。

## 何を改善したか

修正前でも複数条件の調整は伝わりますが、第一候補が使えなくなってから何を優先したかがやや埋もれていました。改善版では、価格だけでなく納期・必要数・保管場所を可視化し、関係者へ譲れない条件を聞いて「開店時の必要数確保」を最優先にした判断を中心にしました。

## 改善版ガクチカ

> 大学祭の模擬店で紙容器の調達を担当しました。私は当初、最安値の業者を選べばよいと考えていましたが、第一候補が必要日に届かないと分かりました。そこで価格だけでなく、納期、必要数、保管場所を一覧にし、会計担当と使用担当に「絶対に譲れない条件」を聞きました。その結果、開店時に必要な数量の確保を最優先とし、共通容器を先に発注し、不足分だけ近隣店で調達する案を作りました。追加費用と受取分担を説明して承認を得て、開店時に必要数をそろえました。最安値にはなりませんでしたが、複数の制約を可視化し、何を優先するかを関係者と決めれば実行可能な案を作れると学びました。

## この例の強いところ

単に安く仕入れた話ではなく、複数の制約が衝突した状況で優先順位を決めています。最安値を達成できなかったことも隠さず、実行可能性を重視した判断を説明できます。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| 学園祭の調達を改善する | 価格・納期・数量を同時に考えられる |
| 合宿の交通と宿を手配する | 複数の条件から実行案を作れる |
| 協賛企業と条件交渉する | 相手側の利益も考える経験になる |
| 仕入先を比較する | 価格以外の品質・納期も評価できる |
| 地域店舗との共同企画を作る | 学外関係者との調整を経験できる |
| イベント会場を調整する | 費用・場所・時間の制約を扱える |
| 国際交流企画を運営する | 文化・食事・時間など異なる条件を調整できる |
| 備品調達を改善する | 代替案を用意する経験になる |
| フードロス企画を行う | 店舗と利用者双方の条件を考えられる |
| 複数団体の日程を調整する | 利害の異なる相手から合意を作れる |

## 進め方

関係者ごとに、目的・期限・譲れない条件・相談できる条件を整理します。一つの案に固執せず、価格、時間、リスクを比較できるA案・B案を作ります。最終的に何を優先し、何を諦めたかを記録します。

## 面接で深掘りしたい質問

1. なぜ最安値を優先し続けなかったのですか。
2. 関係者の譲れない条件をどう聞きましたか。
3. 近隣店で補う案の弱点は何ですか。
4. 追加費用をどう説明しましたか。
5. 次回ならどの時点で代替案を準備しますか。

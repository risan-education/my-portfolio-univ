# 小売・流通のガクチカ例

想定職種: **店舗運営・販売企画**

## この業種・職種で意識したい経験

この職種を想定するなら、**利用者が迷う場面を観察する → 質問を記録する → 自分の案を同僚にも見てもらう → 情報を削って分かりやすくする → 効果の限界も認める**経験が話しやすいです。

## 修正前のガクチカ

> 書店のアルバイトで、参考書売場の案内を分かりやすくすることに取り組みました。場所を聞かれることが続き、自分で探したい方も迷っているのではないかと考えたためです。店長の許可を得て、質問された棚の種類を個人が分からない形で記録しました。分類名が初めて来る方に伝わりにくいと考え、既存表示に補足する案内を提案しました。当初の案は文字が多いと同僚から指摘され、短い言葉と矢印に直し、店長の確認後に設置しました。その後、分かりやすいとの声をいただきました。ただし、質問件数や売上への効果は測れていません。この経験から、気づきをすぐ成果と決めつけず、利用する方と一緒に働く人の視点を取り入れて改善することを学びました。

## 何を改善したか

修正前は案内表示を改善した出来事が中心でした。改善版では、表示を増やすという最初の考えから、質問記録を見て「分類名そのものが伝わらない」と課題を捉え直したことを中心にしました。同僚から文字が多いと指摘され、さらに情報を削った過程も明確にしています。

## 改善版ガクチカ

> 書店のアルバイトで、参考書売場の案内を改善しました。同じ場所を尋ねられることが続き、私は案内表示を増やせばよいと考えましたが、質問内容を記録すると、初めて来る方には既存の分類名そのものが分かりにくいと気づきました。そこで分類名を増やすのではなく、短い言葉と矢印で補足する案を作りました。最初の案は文字が多いと同僚に指摘されたため、さらに情報を削り、店長確認後に設置しました。利用者から分かりやすいとの声は得ましたが、質問件数や売上への効果は測れていません。自分が伝えたい情報を増やすのではなく、利用者がどこで迷うかを観察し、同僚の視点も入れて改善することを学びました。

## この例の強いところ

顧客視点を抽象的に語らず、どこで迷い、何を質問したかを記録しています。また、自分だけで完成させず同僚の視点を取り入れ、売上効果までは測れていないことも認めています。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| 売場案内を改善する | 顧客が迷う場所を直接観察できる |
| 品出しを改善する | 従業員側の作業動線を考えられる |
| 新人マニュアルを作る | 経験差を仕組みで補える |
| 食品ロスを減らす | 廃棄数を前後比較できる |
| レジ待ちを分析する | 時間帯と人員配置を考えられる |
| 売場配置を改善する | 顧客行動を見て配置を試せる |
| 模擬店の仕入れを改善する | 需要予測と在庫を経験できる |
| 在庫管理を改善する | 欠品と余剰の両方を考えられる |
| 高齢者向け表示を改善する | 多様な利用者の見え方を考えられる |
| 貸出手順を改善する | 利用者と運営者双方の不便を扱える |

## 進め方

まず「誰がどこで迷っているか」を記録します。顧客の質問、時間帯、場所などを集め、自分の印象と違う点を探します。改善案は同僚にも見てもらい、小さく試します。売上など測っていない成果を後から付け足さないことも重要です。

## 面接で深掘りしたい質問

1. なぜ案内表示を増やせばよいと思ったのですか。
2. 質問記録から何が分かりましたか。
3. 文字を削るとき何を残しましたか。
4. 利用者の声だけで効果を判断する弱点は何ですか。
5. 次はどんな数字を測りますか。

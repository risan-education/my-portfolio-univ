# 鉄道・交通インフラのガクチカ例

想定職種: **運営・利用者サービス**

## この業種・職種で意識したい経験

この職種を想定するなら、**利用者が迷う場所を観察する → 個人の案内力ではなく運用を疑う → 表示と説明をそろえる → 持ち場と連絡も整える → 残る課題を確認する**経験が話しやすいです。

## 修正前のガクチカ

> 大学の公開講座で、受付への案内を整えることに取り組みました。案内係として参加した際、受付とは別の入口へ進む方がおり、初めて来る方にも分かる案内にしたいと考えました。私は説明を求められた場所と内容を記録し、表示とスタッフの説明が一致していない点を責任者に伝えました。その上で案内文を統一する案を作り、許可された範囲で表示位置を調整しました。通路や設備は変えず、スタッフ同士で持ち場と混雑時の連絡先も確認しました。次の開催でも場所を尋ねる方はいましたが、同じ説明で対応できました。事故防止の効果まで示せるものではありません。利用する方の迷いを想定し、自分だけで判断せず、役割と連絡手順をそろえる大切さを学びました。

## 何を改善したか

修正前は案内文を整えた話が中心でした。改善版では、案内係が丁寧に説明すればよいという最初の考えから、質問記録を見て「表示とスタッフ説明が一致していない」という運用上の問題へ捉え直した点を中心にしました。

## 改善版ガクチカ

> 大学の公開講座で、受付への案内を改善しました。別の入口へ進む来場者がいたため、私は案内係が丁寧に説明すれば解決すると考えました。しかし質問された場所と内容を記録すると、表示とスタッフの説明が一致していないことが分かりました。そこで責任者に共有し、案内文を統一し、許可範囲で表示位置を調整しました。さらに混雑時に説明がばらつかないよう、スタッフの持ち場と連絡先も確認しました。次回も場所を尋ねる方はいましたが、全員が同じ説明で対応できました。利用者の迷いを個人の接客で補うのではなく、表示・説明・役割・連絡をそろえて運用にすることの重要性を学びました。

## この例の強いところ

利用者の迷いを個人の接客で補うのではなく、表示・説明・役割・連絡をそろえています。設備自体を変えられない制約の中で運用を改善した経験として話せます。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| 受付導線を改善する | 利用者が迷う地点を観察できる |
| 混雑誘導を改善する | 安全と利便性を同時に考えられる |
| 安全点検を改善する | 継続できる確認手順を作れる |
| 避難経路を確認する | 非常時の利用者行動を考えられる |
| イベント案内を改善する | 表示とスタッフ説明をそろえられる |
| 交通案内を改善する | 初めての利用者視点を考えられる |
| 持ち場表を改善する | 役割の抜けや重複を減らせる |
| 連絡手順を改善する | 異常時の情報伝達を設計できる |
| バリアフリーを確認する | 多様な利用者の動線を観察できる |
| 雨天導線を設計する | 通常時と例外時を比較できる |

## 進め方

利用者が質問した場所と内容を記録し、「案内係が足りない」以外の原因も考えます。表示、説明、持ち場、連絡先を一つの運用として確認します。改善後にも迷う人がいれば、その場所と理由を次の課題として残します。

## 面接で深掘りしたい質問

1. なぜ案内係の説明だけでは解決しないと考えたのですか。
2. 表示と説明の不一致をどう確認しましたか。
3. 設備を変えられない中で何を変えましたか。
4. 次回も質問が残ったことをどう評価しますか。
5. 混雑時の連絡手順をさらに改善するならどうしますか。

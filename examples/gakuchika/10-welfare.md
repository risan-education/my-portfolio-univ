# 医療・福祉・介護のガクチカ例

想定職種: **生活支援・サービス企画**

## この業種・職種で意識したい経験

この職種を想定するなら、**支援する側の成功像を疑う → 本人の希望を聞く → 選択肢を増やす → 自分の役割範囲を守る → 本人が選べる状態を重視する**経験が話しやすいです。

## 修正前のガクチカ

> 地域交流会のボランティアで、参加する方が過ごし方を選べる案内に取り組みました。当初は全員で同じゲームを楽しむことがよいと思い、席で見ている方にも参加を勧めていました。しかし希望を聞くと、見て楽しみたい方や途中から入りたい方がいると分かりました。私は運営スタッフと相談し、見学のままでもよいことや途中参加できることを案内する方法へ変えました。説明を急がず希望を聞き、判断できない依頼はスタッフへ引き継ぎました。その後、見学から途中参加した方もいましたが、満足度や健康への効果を確認したわけではありません。この経験から、参加人数だけを成果と捉えず、一人ひとりが方法を選べることを大切にし、自分の役割の範囲で支える姿勢を学びました。

## 何を改善したか

修正前は参加方法を柔軟にした話でしたが、「全員参加がよい」という支援者側の前提を捨てた意味が弱めでした。改善版では、見学したい人・途中参加したい人の希望を聞き、参加人数を増やすこと自体を目標にしない判断を中心にしました。

## 改善版ガクチカ

> 地域交流会のボランティアで、参加者が過ごし方を選べる案内に変えました。私は当初、全員が同じゲームに参加することが交流の成功だと考え、見学している方にも参加を勧めていました。しかし希望を聞くと、「見て楽しみたい」「途中から入りたい」という人もいました。そこで参加人数を増やすことを目標にするのをやめ、見学のままでもよいこと、途中参加もできることを案内しました。説明を急がず本人の希望を確認し、自分で判断できない依頼はスタッフへ引き継ぎました。見学から途中参加した方もいましたが、満足度までは測っていません。支援する側の考える成功ではなく、本人が選べることを大切にする姿勢を学びました。

## この例の強いところ

支援する側が考える成功を押し付けず、本人の選択を尊重しています。また、自分で判断できない依頼はスタッフへ引き継ぎ、善意だけで役割範囲を超えない点も説明できます。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| 地域交流会を改善する | 参加者ごとの希望の違いを観察できる |
| 高齢者スマホ支援を行う | 本人の生活目標から支援を考えられる |
| 子ども交流を支援する | 年齢や性格に応じた参加方法を考えられる |
| 外国人生活支援を行う | 文化・言語の違いを踏まえて選択肢を作れる |
| 買物支援を行う | 本人ができることと支援範囲を考えられる |
| 見守り活動を改善する | 介入しすぎない支援を考えられる |
| 福祉イベント案内を改善する | 多様な参加方法を伝えられる |
| バリアフリー調査を行う | 利用者本人の視点から環境を見られる |
| 傾聴ボランティアを行う | 解決を急がず希望を聞く経験になる |
| 参加方法を選べる企画を作る | 一律のサービスから選択型へ変えられる |

## 進め方

活動前に「参加させる」「できるようにする」など支援者側の目標だけになっていないか確認します。本人へ希望を聞き、参加しないことも含めて選択肢を用意します。判断できない依頼は専門スタッフへ引き継ぎ、自分の役割範囲も記録します。

## 面接で深掘りしたい質問

1. なぜ最初は全員参加がよいと思ったのですか。
2. 本人の希望をどう確認しましたか。
3. 見学も選択肢だと伝えることで何が変わりましたか。
4. 自分で判断せずスタッフへ引き継ぐ基準は何ですか。
5. 満足度を確認するならどんな方法を使いますか。

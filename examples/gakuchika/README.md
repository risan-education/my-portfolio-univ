# 業種別のガクチカ：作り方と架空の文章10例

**全例が架空の教材です。実在の学生・応募先・選考通過例ではありません。** 各ページは別の学生という設定です。本人の実績には数えず、自分の原記録にコピーしません。作成日: 2026-09-27。

## 読み方

1. [テーマ選び](../../docs/choosing-gakuchika-theme.md)で自分の経験を候補にする。業種と同じ名前の活動をしている必要はありません。
2. [基本の作り方](../../docs/gakuchika.md)で設問・対象期間・字数・AI条件を確認する。
3. 下の例から、興味のある業種と自分の経験に近い活動をそれぞれ読む。
4. 「これからの計画」「架空の実施済み材料」「完成文」を分けて読む。本人の文章は自分の材料から作る。

各ページには、着眼点、問いと計画、架空の材料F1〜F4、材料から文章にする順序、400字以内の文章、字数、面接質問を載せています。学部別の例ではなく、業種内の一つの職種を想定した例です。同じ業種でも営業・研究・経理などで仕事は異なります。

## 架空の応募条件と実際の応募の区別

全例の共通設定は「架空G社の2028年卒向け練習、設問は大学入学以降に力を入れたこと、400字以内、教材作成でのAI利用は許可」です。**実在の企業・職種・年度のAI利用条件は、この例では確認していません。** 参照した企業へ応募した文書でもありません。

実際の応募では企業・職種・年度・設問・字数・対象期間・AI条件と出典を確認します。条件付きなら許された操作の範囲も確認し、禁止・未確認ならAIによる提出本文の生成へ進まず、自分用の事実整理にとどめます。架空例を本人用に置換して、この確認を省略してはいけません。

本文は句読点・数字を含め、空白・改行を除く文字数です。400字は練習用の上限であり、全国共通のES規定ではありません。実際のフォームの仕様を優先します。

## 同じ経験を別の業種に使う場合

例えば[ゼミの進行改善](06-consulting.md)は、IT企業でも、メーカーでも、教育サービスでも話せる経験です。変えるのは設問に応じて詳しく説明する場面で、8人の班・本人は進行係・構成案の共有はできたが最終資料の遅れは残った、という事実は固定します。

| 想定する仕事の問い | 同じ材料から掘り下げること | 変えてはいけないこと |
| --- | --- | --- |
| ITで利用者の困りごとをどう理解するか | F2の聞き取りと最初の仮説の変更 | システムを開発したことにしない |
| メーカーで工程をどう改善するか | F3の途中確認、F4の残った遅れ | 納期遵守率や製造経験を作らない |
| 教育で相手に応じてどう支援するか | F2の完成度への迷い、F3の見本 | 成績向上や指導資格を作らない |

これは比較学習用の例です。実応募の本文案は、その応募先のAI条件を確認してから別版として作ります。同じ経験を複数社で使っても実績件数は増えません。

## 強いガクチカの基本

見るべきなのは経験の派手さではなく、次の流れです。

**課題 → 本人の判断 → 具体的な行動 → 試行錯誤 → 確かめた結果 → 次にも使える学び**

特に「なぜそう考えたか」「自分は何をしたか」「途中で何を変えたか」を具体的にします。結果は、人数・時間・率・回数・前後比較・利用者の反応など、実際に確認できるものを使います。

## 同じ経験を複数社で使う

同じ経験を複数社で使って構いません。変えるのは、仕事内容や設問に応じて詳しく説明する場面です。事実、本人の役割、数字、結果は変えません。

例えばゼミの進行改善なら、ITでは利用者の困りごとの把握、メーカーでは工程改善、教育では相手に応じた支援を詳しく話せます。しかし「システムを開発した」「納期遵守率を改善した」「成績を上げた」など、実際にしていない実績は追加しません。

## これからガクチカの体験を作るなら

就活用に特別な肩書を集めるより、今いる場所で**一つの困りごとを見つけ、小さく改善し、記録する**ことから始めます。

活動開始時に「現状・目標・期限・関係者・自分の担当」を記録し、途中で「仮説→行動→結果→修正」を残します。最後に前後比較と、うまくいかなかった点も書きます。これがESと面接の両方の材料になります。

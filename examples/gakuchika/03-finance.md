# 金融・銀行のガクチカ例

想定職種: **法人・個人向けの相談業務**

## この業種・職種で意識したい経験

この職種を想定するなら、**曖昧な処理を見つける → 人の注意力ではなくルールを疑う → 記入方法をそろえる → 別の人が確認できる仕組みにする → 例外を記録する**経験が話しやすいです。

## 修正前のガクチカ

> サークルの会計補助として、立替精算を確認しやすくすることに取り組みました。半年間の担当で、領収書と一覧の対応を探す手間があり、次の担当者にも分かる形にしたいと考えました。照合すると、日付や使途の書き方がそろっていないことが原因の一つでした。私は会計担当と相談し、記入例付きの提出用紙と2人で照合する手順を作りました。負担が増えるという意見には、確認に必要な項目に絞って対応しました。半年分の対応を確認する中で、判断できない支出は責任者に相談し、経緯を別に残しました。確認時間の短縮は測っていませんが、曖昧な点を独断で処理せず、引き継げる形にできました。正確さを守るには、相手が続けられる手順も必要だと学びました。

## 何を改善したか

修正前は丁寧な会計処理の話でしたが、「正確さ＝注意深く作業する」と読める部分がありました。改善版では、半年分の記録から書き方そのものが不統一だと気づき、個人の注意ではなく記入ルールと二重確認へ変えた判断を中心にしました。

## 改善版ガクチカ

> サークルの会計補助として、立替精算を確認しやすい仕組みに変えました。領収書と一覧の対応を探す作業が多く、当初は担当者が注意すればよいと考えましたが、半年分を照合すると、日付や使途の書き方自体が人によって異なっていました。そこで会計担当と相談し、記入例付きの提出用紙と、提出者とは別の人が領収書と照合する手順を作りました。負担が増えるという意見には、確認に必要な項目だけに絞りました。判断できない支出は独断で処理せず責任者へ確認し、経緯も残しました。正確さは個人の注意力だけに頼るのではなく、迷いにくく間違いを見つけられる仕組みにすることが重要だと学びました。

## この例の強いところ

正確性を性格ではなく仕組みで担保しています。判断できない支出を独断処理せず、責任者へ確認して経緯を残すため、例外時の行動も説明できます。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| サークル会計を改善する | 正確性と引継ぎを同時に考えられる |
| 立替精算を整理する | 証拠と記録の対応を改善できる |
| 学園祭売上を管理する | 現金と帳簿を照合する経験になる |
| 旅行参加費を管理する | 集金から返金まで扱える |
| 寄付金管理を改善する | 透明性と説明責任を考えられる |
| 会費未納を減らす | 周知・期限・支払方法を分析できる |
| 領収書管理を改善する | 記録の抜けを仕組みで防げる |
| 予算と実績を比較する | 計画との差を分析できる |
| 購入申請を改善する | 承認手順を明確にできる |
| 返金ルールを作る | 例外時の公平な判断基準を考えられる |

## 進め方

最初に、どこで迷い・漏れ・確認作業が発生しているかを記録します。注意喚起より先に、記入例や確認者など仕組みを変えます。判断できない例外は独断で処理せず、誰に確認し、何を根拠に決めたかを残します。

## 面接で深掘りしたい質問

1. なぜ担当者の注意力だけでは解決しないと考えたのですか。
2. 記入項目をどのように絞りましたか。
3. 二重確認で役割をどう分けましたか。
4. 判断できない支出はどう扱いましたか。
5. 次の担当者が迷わないために何を残しますか。

# メーカーのガクチカ例

想定職種: **設計・生産技術**

## この業種・職種で意識したい経験

この職種を想定するなら、**予想と違う結果を観察する → 測定条件を疑う → 条件をそろえる → 再実験する → 残る誤差も説明する**経験が話しやすいです。

## 修正前のガクチカ

> 実験授業で、保温容器の比較方法を見直すことに力を入れました。飲み物が冷めやすい経験から、材料が厚いほど保温できると予想しましたが、初回の結果はそろいませんでした。4人班で測定を担当した私は、手順を見返し、水の量と測定開始までの時間が容器ごとに違うことに気づきました。そこで再実験を提案し、水量と開始温度をそろえる手順表を作りました。班員に計時をお願いし、私は温度の記録を担いました。再実験でもばらつきが残り、厚さだけで優劣を決める結論には至りませんでしたが、班では比較できる条件と残る誤差を分けて報告できました。予想に合わない結果を隠さず、方法を疑って条件を共有することが、検討を前に進めると学びました。

## 何を改善したか

修正前は再実験の流れが中心でした。改善版では「材料が厚いほど保温できる」という予想が外れたと決めつける前に、測定方法そのものを疑った判断を前面に出しました。再実験後もばらつきが残ったため、無理に結論を出さず誤差要因を分けています。

## 改善版ガクチカ

> 実験授業で、保温容器の比較方法を見直しました。私は材料が厚いほど保温できると予想しましたが、初回は同じ種類の容器でも結果がそろいませんでした。予想が外れたと結論づける前に測定条件を確認すると、水量と測定開始までの時間が容器ごとに違っていました。そこで4人班に再実験を提案し、水量、開始温度、測定時刻をそろえる手順表を作りました。再実験でもばらつきは残り、厚さだけで優劣を決める結論には至りませんでした。そこで報告では、条件をそろえて比較できた部分と、残る誤差要因を分けました。予想と違う結果ほど、結果を都合よく解釈せず、まず方法と条件を疑って検証することを学びました。

## この例の強いところ

期待した結論を出すことより、比較できる条件を作ることを優先しています。結果がそろわなかったことも研究・改善材料として扱えます。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| 保温性能を比較する | 条件統一と再実験を経験できる |
| 材料の強度を比較する | 設計条件と結果を数値化できる |
| 3Dプリンタ条件を比較する | 設定変更と品質を対応させられる |
| 測定誤差を減らす | 再現性そのものを改善できる |
| 作業手順を標準化する | 人による差を仕組みで減らせる |
| 故障原因を切り分ける | 原因候補を一つずつ検証できる |
| 組立時間を短縮する | 工程観察とボトルネック発見ができる |
| 材料を比較選定する | 性能・価格・加工性を同時に考えられる |
| 品質チェックを改善する | 不良を検出する基準を作れる |
| 実験再現性を改善する | 条件管理と記録の重要性を経験できる |

## 進め方

比較前に、水量、温度、時間、測定者など結果へ影響しそうな条件を書き出します。予想外の結果が出たら一度に全部を変えず、条件をそろえて再測定します。改善後も残った誤差と次に確かめる条件を記録します。

## 面接で深掘りしたい質問

1. なぜ予想が間違っていたとすぐ判断しなかったのですか。
2. 最も影響が大きいと考えた測定条件は何ですか。
3. 手順表を班員にどう使ってもらいましたか。
4. 再実験でもばらついた理由をどう考えますか。
5. 次の実験では何を追加でそろえますか。

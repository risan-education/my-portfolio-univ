# 教育・学習支援のガクチカ例

想定職種: **教材・学習サービスの企画運営**

## この業種・職種で意識したい経験

この職種を想定するなら、**学習者のつまずきを観察する → 説明不足と決めつけない → 本人に聞く → 質問を表明できる仕組みを作る → 学習成果との違いも認識する**経験が話しやすいです。

## 修正前のガクチカ

> 大学内の初年次向け学習会で、質問しやすい進め方を作ることに力を入れました。支援スタッフとして参加する中で、分からない点を残したまま帰る学生がいたためです。当初は説明を詳しくしようと考えましたが、参加者に聞くと、皆の前では質問しにくいとの声がありました。そこで運営者と相談し、説明を短く区切り、個別に質問を書けるカードを試しました。私は集まった質問から同じ箇所で迷う人がいると気づき、別の例を使って説明しました。振り返りでは質問を書きやすかったとの感想がありましたが、成績や理解の定着まで確認したわけではありません。この経験から、説明の量を増やすだけでなく、相手が困っている点を表せる方法を整えることが大切だと学びました。

## 何を改善したか

修正前でも質問カードの工夫はありますが、「説明を詳しくすれば解決する」という最初の仮説を捨てた意味が弱めでした。改善版では、参加者への聞き取りから問題を「説明量」ではなく「皆の前で質問できないこと」と再定義した判断を中心にしました。

## 改善版ガクチカ

> 大学の初年次向け学習会で、質問しやすい進め方を作りました。分からない点を残して帰る学生がいたため、私は当初、説明を詳しくすればよいと考えました。しかし参加者に聞くと、「皆の前では質問しにくい」という声があり、問題は説明量ではなく質問を表明する方法だと考え直しました。そこで運営者と相談し、説明を短く区切り、匿名で質問を書けるカードを試しました。集まった質問から同じ箇所で迷う人が複数いると分かり、別の例で説明し直しました。質問しやすかったとの感想は得ましたが、学習成果の定着までは確認していません。教える側の説明を増やす前に、学ぶ側が困りごとを表せる仕組みを作ることを学びました。

## この例の強いところ

教える側が説明を増やすのではなく、学ぶ側が困りごとを表現できる環境を作っています。質問しやすくなったことと、成績・定着が改善したことを混同していません。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| 学習会を改善する | 複数の学習者のつまずきを観察できる |
| 質問カードを導入する | 質問しにくさを仕組みで補える |
| 個別指導を改善する | 相手ごとに説明方法を変えられる |
| 教材を改善する | どこで誤解するか確認できる |
| 新人学習支援を行う | 初学者の視点を理解できる |
| オンライン学習会を改善する | 対面と異なる質問障壁を考えられる |
| 読書会を改善する | 参加者の理解差を扱える |
| 学習記録を改善する | 本人がつまずきを振り返れる |
| ピアサポートを行う | 同世代同士の質問しやすさを考えられる |
| 説明動画を改善する | 視聴者が止まる場所を確認できる |

## 進め方

まず学習者が「分からない」と言える状態かを確認します。説明を増やす前に、質問しにくい、どこが分からないか分からない、時間がないなど原因を分けます。改善後は質問数だけでなく、理解や定着を別の指標として扱います。

## 面接で深掘りしたい質問

1. なぜ説明不足が原因だと思ったのですか。
2. 参加者への聞き取りで何が変わりましたか。
3. 匿名カードにした理由は何ですか。
4. 質問しやすさと理解度はどう違いますか。
5. 学習成果まで確認するなら何を測りますか。

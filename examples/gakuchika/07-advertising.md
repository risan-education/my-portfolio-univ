# 広告・メディアのガクチカ例

想定職種: **企画・コミュニケーション**

## この業種・職種で意識したい経験

この職種を想定するなら、**自分が伝えたいことを書く → 受け手に見せる → 最初の疑問を知る → メッセージの入口を変える → 効果を言い切りすぎない**経験が話しやすいです。

## 修正前のガクチカ

> 写真サークルの学内展示で、初めて見る人に届く案内作りに力を入れました。写真経験のない人にも面白さを伝えたい一方、初稿は専門用語の多い作品紹介になっていました。同級生3人に見てもらうと、何を楽しめる展示か分かりにくいとの意見がありました。私は詳しく説明することを優先しすぎたと気づき、通学路の見慣れた景色など身近な題材を入口に変えました。日時、場所、予約不要の情報も整理し、部員と作者の了承を得て写真と短い説明を組み合わせました。当日は初めて来た学生から、案内で内容を想像できたとの感想を聞けました。集客への効果は切り分けられませんが、伝えたい内容を並べるだけでなく、受け手の疑問から表現を見直すことを学びました。

## 何を改善したか

修正前でも第三者の意見を取り入れていますが、「専門用語を減らした話」に見えやすい構成でした。改善版では、詳しく説明すれば魅力が伝わるという本人の前提が、学生3人の反応で崩れたことを中心にし、「何を楽しめる展示か」を最初に伝える設計へ変えています。

## 改善版ガクチカ

> 写真サークルの学内展示で、初めて見る学生向けの案内を作り直しました。私は当初、作品の背景を詳しく説明すれば魅力が伝わると考え、専門用語の多い紹介文を書きました。しかし写真経験のない学生3人に見てもらうと、「何を楽しめる展示か分からない」と言われました。そこで説明量を増やすのをやめ、通学路の見慣れた景色という身近な入口に変更し、日時・場所・予約不要も短く整理しました。部員と作者の了承を得て写真と組み合わせ、当日は初来場者から内容を想像できたとの声を得ました。集客効果までは測れていません。伝えたいことではなく、受け手が最初に抱く疑問から表現を設計することを学びました。

## この例の強いところ

表現力を自己評価するのではなく、受け手が何を理解できなかったかから表現を変えています。集客効果までは測れていないため、コピー改善と来場増を混同していません。

## これから経験を作るなら：課題設定10例

| 課題 | おすすめする理由 |
| --- | --- |
| 展示案内を改善する | 受け手の第一印象を直接確認できる |
| SNS投稿を比較する | 表現と反応を数字で比べられる |
| イベント告知を改善する | 誰に何を伝えるか整理できる |
| 動画の離脱を分析する | 受け手が興味を失う地点を見られる |
| ポスターを改善する | 情報量と視認性を試せる |
| 新歓コピーを改善する | 対象者の疑問から表現を変えられる |
| 地域広報を作る | 異なる年代への伝え方を考えられる |
| 学内メディアを運営する | 継続的な反応から企画を改善できる |
| アンケート表現を改善する | 言葉による回答差を検討できる |
| Webページを改善する | 閲覧行動と情報設計を対応させられる |

## 進め方

初稿を同じ分野の人だけでなく、対象に近い第三者へ見せます。「分かりやすい？」ではなく「何の案内だと思った？」「何ができると思った？」と聞きます。表現変更後も、反応と集客・売上など別の成果を混同しません。

## 面接で深掘りしたい質問

1. なぜ詳しく説明すれば伝わると思ったのですか。
2. 学生3人の反応で最も重要だったものは何ですか。
3. 身近な題材を入口にした理由は何ですか。
4. 集客効果を言い切れない理由は何ですか。
5. 次に効果を測るなら何を記録しますか。
